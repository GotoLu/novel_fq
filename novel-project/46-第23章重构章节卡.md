## 四、核心决策

最优决策：第 23 章让周强“足够可疑但证据不足”，而不是让他成为确定犯人。

核心依据：

- C005 的第 24 章需要团队按饭点规律设伏，第 23 章必须给他们一个看似合理的目标。
- 第 25 章要反转“周强是诱饵”，因此本章必须提前埋下“过于符合”的不安。
- 苏晚的程序线要在第二卷继续发挥作用，本章最适合让她用合法调取获得阶段高光。

执行边界：

- 周强可以有前科、灰夹克、维修路线重合、记录缺失，但不能出现入室收益链。
- 蒋河可以隐瞒电梯维保时间外泄，但本章不揭示卢俊真犯路径。
- 陆行舟必须说出“太像凶手的人，有时只是别人给他穿了凶手的衣服”一类判断，但只能作为风险提示。

## 六、详细场景设计

### 场景一：调取清单

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所会议室，调取申请单、物业电话记录和第 22 章白板并列 |
| 镜头顺序 | 苏晚列清单 -> 物业电话推诿 -> 秦墨寒拆变量 -> 陆行舟写“谁能看见饭点” |
| 动作节拍 | 苏晚逐项打电话，秦墨寒标注优先级，陆行舟盯着灰夹克影子 |
| 功能道具 | 调取申请单承担程序高光；电话忙音承担阻碍 |
| 主导感官 | 电话忙音和打印机声，形成程序推进的现实压力 |

推进卡：

- 人物目标：团队要合法拿到外来人员出入记录。
- 主要阻碍：物业担心背锅，不愿主动提供完整资料。
- 冲突升级：饭点案从生活规律转向权限和记录漏洞。
- 代价后果：苏晚需要承担调取压力，不能让团队越界。
- 局面变化：调查入口从饭点转为“谁能接触楼栋和住户生活空档”。
- 章末追读：物业记录里谁最可疑。

### 场景二：物业办公室

| 项目 | 内容 |
|------|------|
| 场景空间 | 康平片区物业办公室，墙上挂外包合同，桌上堆维修单和投诉本 |
| 镜头顺序 | 投诉本 -> 维修单 -> 蒋河遮住缺页 -> 苏晚要求复印留档 |
| 动作节拍 | 蒋河推说资料在外包公司，苏晚亮程序，秦墨寒核对编号，陆行舟注意缺页位置 |
| 功能道具 | 投诉本承担群众压力；缺页维修单承担遮掩线索 |
| 主导感官 | 办公室闷热和旧纸味，突出管理混乱 |

推进卡：

- 人物目标：确认近期进入楼栋的维修、物业和外包人员。
- 主要阻碍：蒋河担心外包合同出问题，隐瞒记录缺漏。
- 冲突升级：电梯维保表缺页，灰夹克维修工多次出入案发楼栋。
- 代价后果：苏晚顶住物业和群众双向压力，必须留下正式调取痕迹。
- 局面变化：灰夹克维修工从群众描述变为记录中的具体人。
- 章末追读：这个维修工是谁。

### 场景三：维修店的周强

| 项目 | 内容 |
|------|------|
| 场景空间 | 老街维修店，空调外机、工具包、灰夹克和临时工签到本形成职业现场 |
| 镜头顺序 | 灰夹克挂在椅背 -> 工具包 -> 周强手背旧伤 -> 签到本路线重合 |
| 动作节拍 | 苏晚询问工作记录，秦墨寒核路线，陆行舟观察周强反应 |
| 功能道具 | 工具包承担误导；签到本承担路线证据；灰夹克承担嫌疑识别 |
| 主导感官 | 机油味和金属工具碰撞声，形成粗粝现实感 |

推进卡：

- 人物目标：团队要确认周强是否能接触案发楼栋和住户作息。
- 主要阻碍：周强有前科，天然紧张，部分临时维修没有完整记录。
- 冲突升级：周强路线与三处案发楼栋重合，穿灰夹克，且熟悉老楼门禁。
- 代价后果：他的旧前科让所有人更容易相信他就是犯人。
- 局面变化：周强浮出，但证据仍不足。
- 章末追读：周强是真嫌疑人，还是被推出来的人。

### 场景四：快递站和记录交叉

| 项目 | 内容 |
|------|------|
| 场景空间 | 小区快递站，货架、取件码屏幕、代收登记和楼栋分拣表并列 |
| 镜头顺序 | 取件高峰 -> 楼栋分拣表 -> 卢俊一闪而过 -> 秦墨寒只记录变量 |
| 动作节拍 | 秦墨寒调取取件时段，苏晚核合法边界，陆行舟发现取件高峰也卡在饭点 |
| 功能道具 | 快递取件记录承担真规律暗线；取件码屏幕承担信息噪声 |
| 主导感官 | 快递站胶带撕拉声和扫码提示声，形成数据噪声感 |

推进卡：

- 人物目标：排除或确认快递站是否也能观察住户空档。
- 主要阻碍：取件记录量大，且不能直接证明入室行为。
- 冲突升级：快递记录与饭点高度重合，但没有周强那么“像凶手”。
- 代价后果：团队可能因为周强更显眼而忽略快递站变量。
- 局面变化：真犯路径被暗埋，读者暂时更注意周强。
- 章末追读：为什么快递线索看起来不如维修工显眼。

### 场景五：太像凶手的人

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所证据板，周强路线、维修单、快递记录、饭点时间轴同时上墙 |
| 镜头顺序 | 周强照片 -> 路线重合 -> 无收益链空白 -> 陆行舟停笔 |
| 动作节拍 | 秦墨寒列周强可疑点，苏晚补证据缺口，陆行舟把“诱饵？”写进待证 |
| 功能道具 | 证据板空白处承担“不足”；红笔问号承担诱饵伏笔 |
| 主导感官 | 白板笔停顿声，形成“太顺了”的不安 |

推进卡：

- 人物目标：团队要决定是否围绕周强继续推进。
- 主要阻碍：周强可疑点很多，但缺少入室收益和作案闭环。
- 冲突升级：群众和物业都希望警方快点锁人，团队却不能定罪。
- 代价后果：陆行舟必须再次压住漂亮结论，也让苏晚继续承受程序压力。
- 局面变化：周强成为表层目标，第 24 章设伏逻辑成立。
- 章末追读：周强是不是被摆出来的诱饵。
