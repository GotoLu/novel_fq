## 一、章节定位

| 项目 | 内容 |
|------|------|
| 章节 | 第 022 章 |

| 标题闸门 | 通过 |

## 四、核心决策

最优决策：第 22 章以“确认规律但降低结论等级”为核心，不急着推出周强。

核心依据：

- C005 的误导层级需要饭点规律先成立，否则第 24 章设伏失败没有打击力。
- 但饭点如果在第 22 章就能锁定人，会违背第二卷“被投喂异常”的主题。
- 本章最重要的成长爽不是破案，而是陆行舟能忍住“顺口漂亮歪理”，让饭点从结论降级为可验证方向。

执行边界：

- 周强可以通过“灰夹克维修工”作为背景影子出现，但不在本章正式锁定为嫌疑人。
- 旧账本只保留心理余震，不增加新信息。
- 饭点规律必须既有吸引力，又有统计陷阱感。

## 六、详细场景设计

### 场景一：白板上的四个饭点

| 项目 | 内容 |
|------|------|
| 场景空间 | 清晨派出所会议室，白板上留着四个红圈和旧账本证物袋编号 |
| 镜头顺序 | 四个饭点 -> 陆行舟三栏笔记 -> 苏晚分派走访表 -> 旧账本证物袋被收进柜子 |
| 动作节拍 | 苏晚分表，秦墨寒列变量，陆行舟把红圈旁边写上“待证” |
| 功能道具 | 走访表承担程序推进；证物柜门关闭承担旧账本低频退场 |
| 主导感官 | 清晨打印纸和冷掉的茶，形成疲惫后的现实感 |

推进卡：

- 人物目标：团队要把饭点从白板规律落到可验证信息。
- 主要阻碍：旧账本压力仍在，陆行舟容易把饭点看成被摆出来的题。
- 冲突升级：四起案子都与饭点相关，但每户离家的理由不完全一样。
- 代价后果：陆行舟不能在会议室里用一句歪理带走全案。
- 局面变化：调查从白板转入实地走访。
- 章末追读：受害者作息是否真能支持饭点规律。

### 场景二：老李家的空饭桌

| 项目 | 内容 |
|------|------|
| 场景空间 | 东槐苑老李家，饭桌上有半碗汤、两双筷子和一张面馆小票 |
| 镜头顺序 | 空饭桌 -> 被翻抽屉 -> 老李夫妻争执 -> 陆行舟看见门口鞋印被踩乱 |
| 动作节拍 | 苏晚安抚并问笔录，秦墨寒检查门锁，陆行舟观察饭桌和门口动线 |
| 功能道具 | 面馆小票证明离家时间；空饭桌形成生活被打断的情绪点 |
| 主导感官 | 剩菜味和楼道消毒水味，增强入室案的日常侵犯感 |

推进卡：

- 人物目标：确认第一户是否因饭点离家造成空档。
- 主要阻碍：老李夫妻互相埋怨，口供带情绪偏差。
- 冲突升级：饭点确实存在，但“谁知道他们去面馆”变成新问题。
- 代价后果：受害者安全感被破坏，团队不能只把他们当时间数据。
- 局面变化：饭点规律获得第一枚生活证据。
- 章末追读：这个饭点空档是偶然，还是被提前知道。

### 场景三：买醋的人和排队的人

| 项目 | 内容 |
|------|------|
| 场景空间 | 康平小区楼下熟食店、单元楼道、受害者厨房三点切换 |
| 镜头顺序 | 灶上的砂锅 -> 买醋小票 -> 熟食店排队监控 -> 回家发现首饰盒空了 |
| 动作节拍 | 秦墨寒调取店内付款时间，苏晚核离家时长，陆行舟观察“临时离家”也被命中 |
| 功能道具 | 醋瓶和砂锅承担饭点生活痕迹；熟食店排队监控承担时间校正 |
| 主导感官 | 砂锅热气和熟食店油味，形成强饭点记忆 |

推进卡：

- 人物目标：验证短时间离家是否也被作案者利用。
- 主要阻碍：受害者觉得自己只离开二十分钟，不愿承认门锁和生活习惯暴露了空档。
- 冲突升级：饭点不只包含出门吃饭，也包含买醋、排队、取餐等短暂离家。
- 代价后果：饭点规律更诱人，也更宽泛。
- 局面变化：饭点从固定晚饭扩展为一组生活空档。
- 章末追读：如此宽的饭点还能不能锁人。

### 场景四：每个人都要吃饭

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所白板前，受害者作息表、店铺小票、监控截图并列 |
| 镜头顺序 | 陆行舟写“贼也要吃饭” -> 秦墨寒划掉“锁定” -> 苏晚补“待证” |
| 动作节拍 | 陆行舟提出歪理，秦墨寒用人群数据反驳，苏晚把结论压回流程 |
| 功能道具 | 白板擦承担“降级结论”的动作；作息表承担规律与误导双重功能 |
| 主导感官 | 白板擦划过字迹的声音，形成漂亮判断被压回去的触感 |

推进卡：

- 人物目标：陆行舟想用饭点解释四起案子。
- 主要阻碍：秦墨寒指出饭点覆盖面太广，几乎每个住户都可能在这段时间离家。
- 冲突升级：越能解释一切的规律，越不能直接证明某个人。
- 代价后果：陆行舟失去立刻打出漂亮歪理的机会。
- 局面变化：饭点从“结论”正式降级为“方向”。
- 章末追读：如果饭点不能锁人，下一步靠什么缩小范围。

### 场景五：推断，不是事实

| 项目 | 内容 |
|------|------|
| 场景空间 | 会议室收尾，走访表、物业电话、快递站位置和维修记录申请单同时出现 |
| 镜头顺序 | 陆行舟写“推断，不是事实” -> 苏晚列调取清单 -> 灰夹克维修工被群众提及 |
| 动作节拍 | 苏晚打电话给物业，秦墨寒列出需核验变量，陆行舟把“谁知道饭点”写入待证 |
| 功能道具 | 调取申请单承担第 23 章程序入口；灰夹克只做影子，不定性 |
| 主导感官 | 电话忙音和纸页翻动声，形成调查继续推进的现实节奏 |

推进卡：

- 人物目标：团队要找到谁能长期知道住户饭点。
- 主要阻碍：合法调取物业、维修、快递记录需要程序和时间。
- 冲突升级：饭点规律不能定罪，但它指向“谁能观察生活空档”的新入口。
- 代价后果：苏晚承担调取资料的程序压力，陆行舟继续压住指认冲动。
- 局面变化：第 23 章“修空调的人”入口建立。
- 章末追读：谁能长期观察住户饭点。

## 八、爽点链与压抑阈值

| 环节 | 设计 |
|------|------|
| 压抑铺垫 | 四起案子饭点重合，主角的歪理几乎呼之欲出 |

| 主角反制 | 他接受秦墨寒反驳，把饭点写成“推断，不是事实” |
| 公开见证 | 苏晚、秦墨寒、钱凤英和受害者看到他不急于定罪 |

| 余波升级 | 饭点越成立，越像有人故意摆出显眼规律 |

本章小爽点是方法成熟，不是抓人。读者获得的是“主角会歪，但不会再随便拿歪理砸人”的信任感。
