**开头设计（承接第23章）**：
```
时间：竞争第三天上午
地点：幸福派出所，周明远办公室
氛围：紧张凝重，周明远脸色不好
```

**情节展开**：

1. **案件升级**（300字）

   - "又出事了，第11起案件。"
   - 昨天下午3点，阳光公寓7栋，退休教师外出，回来发现被盗

2. **压力升级**（300字）
   - 周明远："11起案件，影响越来越大，媒体开始关注了。"
   - 两人压力加大，竞争白热化

周明远的办公室里，墙上又多了一个红圈。

### 场景二：现场勘查（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 勘查第11起案件现场，发现关键线索 |
| **情绪曲线** | 专注→兴奋 |
| **出场人物** | 陆行舟、秦墨寒、技术科人员 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

1. **现场勘查**（400字）
   - 两人来到阳光公寓7栋，第11起案件现场
   - 技术科人员已经勘查完毕：技术开锁，无撬痕，无指纹，无脚印
   - 监控拍到模糊人影，但看不清脸
   - 秦墨寒记录现场数据，陆行舟观察环境

2. **监控分析**（400字）
   - 秦墨寒调取监控录像，分析嫌疑人的行动轨迹
   - 监控显示：下午2:50，一个穿灰色夹克的男人出现在楼道
   - 下午3:15，男人离开，手里多了一个背包
   - 但监控角度不好，看不清脸，只能看到背影和侧影
   - 陆行舟盯着监控，突然发现一个细节：男人在楼道里停了一下，看了看手表

#### 对话设计

**技术科汇报**：
```
技术科："技术开锁，无撬痕，无指纹，无脚印。"
"监控拍到嫌疑人，但角度不好，看不清脸。"
```

**监控分析对话**：
```
秦墨寒："下午2:50出现，3:15离开，作案时间25分钟。"
陆行舟："他在楼道里停了一下，看了看手表。"
秦墨寒："看手表？"
陆行舟："对，像是在确认时间。"
```

#### 环境描写

```
阳光公寓7栋，三楼，受害者家门口。
门锁完好，没有撬痕，技术开锁的痕迹很轻微。
屋内翻得乱七八糟，抽屉被拉开，柜子被翻过。
监控室里，屏幕上播放着模糊的画面。
```

### 场景三：受害者询问（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 验证"饭点作案"假设 |
| **情绪曲线** | 期待→兴奋 |
| **出场人物** | 陆行舟、受害者（退休教师） |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

1. **询问受害者**（400字）
   - 陆行舟找到受害者，一位退休教师
   - "您昨天下午3点外出，是固定习惯吗？"
   - "对，我每天中午12点去老年活动中心，下午2点回家，3点再出去买菜。"
   - 陆行舟眼睛一亮：又是饭点外出！

2. **假设验证**（400字）
   - 陆行舟继续问："您每天都是这个时间外出吗？"
   - "差不多，习惯了，改不了。"
   - 陆行舟在笔记本上写下：**第11起案件受害者符合"饭点外出"规律**
   - 假设得到验证！嫌疑人确实踩点发现了受害者的饭点外出习惯

#### 对话设计

**询问对话**：
```
陆行舟："您昨天下午3点外出，是固定习惯吗？"
受害者："对，我每天中午12点去老年活动中心，下午2点回家，3点再出去买菜。"
陆行舟："每天都是这个时间吗？"
受害者："差不多，习惯了，改不了。"
```

**陆行舟内心**：
```
"又是饭点外出！"
"假设得到验证：嫌疑人踩点发现了受害者的饭点外出习惯。"
"现在需要找到嫌疑人踩点的证据。"
```

#### 环境描写

```
受害者的家里，虽然被盗，但老人很平静。
"丢了一些现金和首饰，不多。"老人说，"幸好没丢证件。"
陆行舟在笔记本上记录，心里越来越兴奋。
```

### 场景四：关键发现（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 找到嫌疑人踩点证据 |
| **情绪曲线** | 兴奋→紧张 |
| **出场人物** | 陆行舟、秦墨寒、周明远、苏晚 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

1. **监控回溯**（400字）
   - 陆行舟想到：嫌疑人既然踩点，应该会提前出现在现场
   - 他让技术科调取过去一周的监控录像
   - 发现：案发前三天，同一个穿灰色夹克的男人多次出现在楼道里
   - 每次都是在饭点前后（中午12点、下午3点、晚上6点）
   - 男人每次都假装修空调，在楼道里转悠

2. **锁定嫌疑人**（400字）
   - 陆行舟兴奋地找到秦墨寒："我找到了！"
   - "嫌疑人踩点的画面，监控拍到了。"
   - 秦墨寒过来看监控，皱眉："修空调？"
   - 陆行舟："对，他假装修空调，在楼道里踩点，观察受害者外出时间。"
   - 秦墨寒沉默，意识到陆行舟又领先了一步

#### 对话设计

**陆行舟发现**：
```
陆行舟："我找到了！嫌疑人踩点的画面，监控拍到了。"
"案发前三天，他多次出现在楼道里，假装修空调。"
"每次都是饭点前后，观察受害者外出时间。"
```

**秦墨寒反应**：
```
秦墨寒："修空调？"
陆行舟："对，他假装修空调，在楼道里踩点。"
秦墨寒沉默。
```

**苏晚观察**：
```
苏晚心想：第三次交锋，陆行舟又领先了。
秦墨寒的数据分析还在困境中，陆行舟已经找到关键线索。
```

#### 环境描写

```
监控室里，屏幕上播放着过去一周的录像。
灰色夹克的男人，一次又一次出现在楼道里。
每次都是饭点前后，每次都假装修空调。
陆行舟盯着屏幕，心里有了答案。
```
