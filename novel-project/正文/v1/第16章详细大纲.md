**开头设计（承接第15章）**：
```
时间：第二天早上七点
地点：幸福派出所
氛围：清晨的阳光透过窗户，派出所内安静
```

**情节展开**：

1. **周明远接电话**（100字）
   - 周明远正在看昨天的案件报告
   - 桌上电话突然响起
   - 分局来电，语气急促
   - 周明远表情逐渐凝重

2. **了解案情**（150字）
   - 周明远挂断电话，召集陆行舟和秦墨寒
   - 介绍案情：城北别墅发生盗窃案

3. **人物反应**（150字）

4. **出发铺垫**（100字）
   - 陆行舟拿起外套
   - 秦墨寒整理装备
   - 周明远叮嘱："这个案子不简单。"
   - 两人离开派出所

#### 对话设计

**核心对话**：
```
周明远："城北别墅发生盗窃案，但情况很奇怪。"
周明远："监控什么都没拍到，门窗完好，没有任何入侵迹象。"
陆行舟眉头一皱："没有入侵迹象？那怎么偷的？"
秦墨寒："有意思。走，去看看。"

有意思。

### 场景二：现场勘查（1000字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 展示密室案现场，制造"不可能"感 |
| **情绪曲线** | 好奇→困惑→紧张 |
| **出场人物** | 陆行舟、秦墨寒、周明远、赵先生 |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

**到达现场**（100字）：
```
时间：早上七点半
地点：城北别墅区，赵先生别墅
环境：高档别墅区，安保严密，绿化良好
氛围：安静，只有几只鸟在枝头鸣叫
```

**情节展开**：

1. **了解基本情况**（200字）
   - 赵先生介绍：昨晚10点睡觉，花瓶还在
   - 今早7点起床，发现花瓶消失
   - 期间无任何人进入
   - 花瓶价值200万，古董，有收藏证书

2. **陆行舟勘查现场**（300字）
   - 观察展示柜：玻璃完好，但花瓶消失
   - 观察窗户：全部锁死，无撬痕
   - 观察门：防盗门完好，猫眼正常
   - 发现异常：客厅地毯有一处轻微压痕
   - 蹲下仔细观察压痕：圆形，直径约30厘米

3. **秦墨寒检查监控**（300字）
   - 检查监控设备：最新型号，高清夜视
   - 检查监控录像：12小时无异常
   - 检查报警记录：未触发
   - 检查门禁记录：只有主人进出
   - 发现异常：监控在凌晨3点有1秒卡顿

4. **两人交流发现**（100字）
   - 陆行舟："地毯有压痕。"
   - 秦墨寒："监控凌晨3点有卡顿，只有1秒。"
   - 两人对视一眼，都感到困惑

#### 案件特点展示

**密室案特点**（通过对话和描写展示）：
```
├─ 监控：全覆盖，24小时录像，显示无人进入
├─ 门窗：全部完好，无撬痕
├─ 报警器：未触发，说明无人闯入
├─ 花瓶位置：客厅展示柜，无防护
└─ 失踪时间：昨晚10点至今早7点
```

**现场描写**：
```
客厅宽敞明亮，落地窗外是精心修剪的花园。
展示柜靠墙摆放，玻璃门完好无损，但里面的古董花瓶已经消失。
地毯是米白色的羊毛地毯，柔软厚实。
陆行舟蹲下身，发现地毯上有一处轻微的压痕，圆形，直径约30厘米。
```

#### 对话设计

**赵先生介绍案情**：
```
赵先生："昨晚10点，我亲自锁的门，检查过花瓶，一切正常。"
赵先生："今早7点起床，发现花瓶不见了。"
赵先生："期间没有任何人进来，报警器也没响。"
陆行舟："您确定昨晚检查过花瓶？"
赵先生："确定，我每晚都会检查，这是习惯。"
```

**陆行舟勘查对话**：
```
陆行舟走到展示柜前，仔细观察。
玻璃完好，没有撬痕。
花瓶凭空消失了。

陆行舟："窗户呢？"
赵先生："全部锁死，您看，锁舌还在里面。"
陆行舟检查窗户，确实全部锁死，没有撬动的痕迹。

陆行舟："门呢？"
赵先生："防盗门，昨晚我亲自锁的，今早也是我开的。"
陆行舟检查门，防盗门完好，猫眼正常。
```

**秦墨寒检查监控对话**：
```
秦墨寒打开监控设备，开始回放录像。
屏幕上显示昨晚10点至今早7点的画面，客厅空无一人。

秦墨寒："监控显示，这12小时内，无人进入。"
秦墨寒："等等……"
秦墨寒定格画面，凌晨3点。
秦墨寒："监控卡顿了1秒。"
陆行舟："1秒？"
秦墨寒："凌晨3点整，监控画面卡顿了1秒，然后恢复正常。"
陆行舟："1秒能做什么？"
秦墨寒："这就是问题所在。"
```

#### 环境描写

**别墅外观**：
```
城北别墅区是本市的高档住宅区，每栋别墅都有独立的院子和安保系统。
赵先生的别墅是三层小楼，欧式风格，外墙是浅黄色的石材。
院子里的草坪修剪整齐，几棵观赏树错落有致。
```

**客厅内部**：
```
客厅宽敞明亮，落地窗外是精心修剪的花园。
阳光透过落地窗洒进来，在地板上投下明亮的光斑。
展示柜靠墙摆放，是红木玻璃柜，里面原本放着古董花瓶。
地毯是米白色的羊毛地毯，柔软厚实，踩上去几乎没有声音。
```

#### 人物心理

**陆行舟心理**：
```
展示柜玻璃完好，窗户锁死，防盗门正常。
监控显示无人进入。
那花瓶怎么消失的？

地毯上有压痕……
圆形，直径30厘米……
这是什么造成的？

这个案子，不简单。
```

**秦墨寒心理**：
```
监控全覆盖，高清夜视，最新型号。
凌晨3点卡顿1秒，这是系统维护。
1秒时间，就算有人进入，也不可能拿走花瓶再离开。

除非……
有人提前准备好了？
```

### 场景三：不可能的犯罪（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 强化"不可能"感，制造悬念 |
| **情绪曲线** | 困惑→紧张 |
| **出场人物** | 陆行舟、秦墨寒、周明远、赵先生 |
| **场景时长** | 约20分钟（故事时间） |

#### 详细情节

**情节展开**：

1. **赵先生详细介绍**（200字）
   - 昨晚10点：亲自锁门，检查花瓶，一切正常
   - 夜间：未听到任何声音，报警器未响
   - 今早7点：起床发现花瓶消失
   - 疑问：花瓶怎么消失的？

2. **报警器检查**（150字）
   - 秦墨寒检查报警器
   - 报警器是最新型号，红外感应
   - 触发记录：昨晚10点至今早7点，无触发
   - 结论：无人闯入

3. **门禁检查**（150字）
   - 秦墨寒检查门禁记录
   - 门禁是刷卡+密码双重验证
   - 记录显示：昨晚10点至今早7点，只有主人进出
   - 结论：无人进入

4. **"不可能"总结**（300字）
   - 周明远总结：监控无人、门窗完好、报警未触发
   - 陆行舟："这不可能啊。"
   - 秦墨寒："监控显示无人进入，但花瓶消失了。"
   - 秦墨寒："这是密室案。"
   - 气氛凝重

#### 对话设计

**赵先生证词**：
```
陆行舟："您昨晚睡觉前，有没有听到什么异常声音？"
赵先生："没有，我一觉睡到今早7点。"
陆行舟："报警器呢？有没有响？"
赵先生："没有，报警器一直正常，如果有人闯入，肯定会响。"
秦墨寒："您确定昨晚检查过花瓶？"
赵先生："确定，我每晚都会检查，这是我的习惯。"
赵先生："昨晚10点，我检查完花瓶，锁好门，就上楼睡觉了。"
赵先生："今早7点起床，下楼一看，花瓶不见了。"
```

**报警器检查对话**：
```
秦墨寒走到报警器前，检查设备。
秦墨寒："红外感应报警器，最新型号，灵敏度很高。"
秦墨寒查看触发记录。
秦墨寒："昨晚10点至今早7点，无触发记录。"
陆行舟："也就是说，昨晚没有人闯入？"
秦墨寒："至少报警器没检测到。"
```

**门禁检查对话**：
```
秦墨寒检查门禁系统。
秦墨寒："门禁是刷卡加密码双重验证，安全性很高。"
秦墨寒查看进出记录。
秦墨寒："昨晚10点至今早7点，只有您的刷卡记录。"
赵先生："对，昨晚是我锁的门，今早是我开的门。"
秦墨寒："也就是说，昨晚没有人进出？"
赵先生点头："对，只有我。"
```

**"不可能"总结对话**：
```
周明远："监控显示无人进入，门窗完好，报警器未触发。"
周明远："但花瓶消失了。"
周明远："这是不可能的犯罪。"
陆行舟皱眉："这不可能啊。"
陆行舟："花瓶不会凭空消失，一定有人拿走了。"
陆行舟："但监控显示无人进入……"
秦墨寒："这就是密室案。"
秦墨寒："表面上看，不可能发生。"
秦墨寒："但实际上，发生了。"
```

#### 环境描写

```
客厅里，阳光越来越亮，但气氛却越来越凝重。
展示柜空荡荡的，玻璃门完好，但里面的花瓶已经消失。
监控屏幕上，凌晨3点的画面定格，那1秒的卡顿显得格外刺眼。
