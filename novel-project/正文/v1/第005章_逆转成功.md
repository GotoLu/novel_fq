# 第005章 逆转成功

当天上午十点，陆行舟和苏晚开始暗中调查珠宝店的内部人员。

珠宝店有三个人能接触到储物柜：店长、仓库管理员、保安。

店长是个五十多岁的老实人，姓李，在珠宝店工作了十五年，本本分分，口碑很好。陆行舟观察了一上午，发现店长的生活规律，没有任何异常。

保安是个三十多岁的退伍军人，姓赵，为人正直，也没有异常。他每天按时巡逻，下班后直接回家，生活简单。

仓库管理员老张，四十多岁，负责仓库管理和储物柜的日常维护。这是陆行舟重点观察的对象。

上午十点半，陆行舟注意到老张有些不对劲。

老张开着一辆崭新的SUV来上班，车是刚买的，牌照还是临时的。他手里拿着最新款的手机，耳朵上戴着无线耳机，一身行头加起来至少十万。

陆行舟暗中观察："老张的工资我查过了，一个月六千多。这车、这手机、这耳机...哪来的钱？"

苏晚也注意到了："确实有点反常。"

陆行舟继续观察，发现老张经常接神秘电话。每次电话响起，他都会避开人，走到角落里小声说话。说完回来，表情有些紧张。

"他在和谁联系？"陆行舟记下了老张接电话的时间点。

苏晚开始调查老张的财务状况。她通过正规渠道查询了老张最近的银行流水和消费记录。

半小时后，苏晚拿着调查结果回来，表情有些复杂："你的直觉...好像又对了。"

陆行舟："怎么说？"

苏晚："老张最近三个月消费了五万多，远超他的工资收入。他买了新车、新手机，还在网上买了一些高档电子产品。"

苏晚继续说："而且，他最近经常和一个陌生号码联系，这个号码没有实名登记，是张黑卡。"

陆行舟眼神变得锐利："这个号码，就是他的同伙。"

苏晚点头："很有可能。但我需要更多证据才能确定。"

陆行舟："我有办法。"

他拿出手机，翻出昨天拍的照片——储物柜挂钩的划痕、秦墨寒鞋底的泥土、储物柜附近的红色泥土。

"这些照片，加上老张的财务记录、通话记录，已经足够说明问题了。"陆行舟说，"但我们需要抓到他的同伙，才能人赃并获。"

苏晚："你想怎么做？"

陆行舟："引蛇出洞。"

下午两点，陆行舟向周明远汇报调查结果。

周明远听完，神色严肃："你确定老张是内鬼？"

陆行舟拿出证据："储物柜的划痕方向是往里拉，说明是从里面递出来，有内部接应。能接触到储物柜的只有三个人，店长和保安都没有异常，只有老张最近财务状况反常。"

周明远翻看证据："确实很有说服力。"

陆行舟："我有个计划。我们让老张'配合调查'，打电话给他的同伙，就说赃物要转移，看他的同伙会不会来接应。"

周明远："这是引蛇出洞。有风险，如果同伙不上钩，就会打草惊蛇。"

陆行舟："我有把握。老张已经被我们盯上了，他肯定会联系同伙商量对策。我们只要给他一个'机会'，他就会上钩。"

周明远思考片刻："好，我批准这个计划。但一定要确保安全，不能让嫌疑人逃脱。"

陆行舟："放心，我会安排人在珠宝店附近埋伏。"

秦墨寒一直在旁边听着，此时冷笑一声："又是你的直觉？"

陆行舟转头看他："不是直觉，是证据。"

秦墨寒："证据？你所谓的证据，不过是一些照片和财务记录。这能证明什么？老张可能只是借了钱买车，不能说明他是罪犯。"

陆行舟平静地说："那我们就看看，今晚会不会有人来接应赃物。"

秦墨寒冷哼："我拭目以待。不过，如果今晚没人来，你打算怎么收场？"

陆行舟："如果今晚没人来，我会承认我推理错了。但如果今晚有人来..."

他看向秦墨寒："秦侦探，你打算怎么收场？"

秦墨寒脸色一沉，没有说话。

下午四点，计划开始执行。

警察找到老张，把他带到派出所。

周明远："老张，我们怀疑你和珠宝店盗窃案有关。"

老张脸色一变，但强装镇定："我...我没有！我在珠宝店工作了八年，从来没问题！"

周明远："我们查到你的财务状况异常，最近三个月消费了五万多，远超你的工资。你买车、买手机的钱，是哪来的？"

老张额头开始冒汗："我...我那是借钱买的...朋友借的..."

周明远："哪个朋友？能提供借条或转账记录吗？"

老张支支吾吾："这...这是现金借的，没借条..."

周明远："还有，你最近经常和一个陌生号码联系，这个号码没有实名登记。你在和谁联系？"

老张的脸色越来越白，汗水顺着额头流下来。

周明远："老张，现在给你一个机会。配合我们，打电话给你的同伙，就说赃物要转移，看他会不会来接应。如果你配合，我们可以考虑从轻处理。"

老张沉默了很久，双手不停地颤抖。

最终，他低声说："好...我配合。"

晚上八点，老张按照计划打电话给"阿龙"。

电话接通，老张的声音有些颤抖："阿龙，赃物...赃物要转移了，你今晚来接应..."

电话那头传来一个粗犷的声音："好，老地方见，十点。"

老张挂断电话，整个人瘫坐在椅子上，脸色苍白如纸。

周明远："安排埋伏。"

警察迅速行动，在珠宝店附近布下天罗地网。

陆行舟和苏晚也在现场，躲在暗处观察。

苏晚："你觉得阿龙会来吗？"

陆行舟："会来。老张已经被我们控制了，阿龙如果不上钩，就永远拿不到赃物。他一定会冒险。"

晚上十点，街道上空无一人，路灯昏暗。

珠宝店后巷，一个黑影悄无声息地出现。

他左右张望，确认没人后，快步走向储物柜。

就在他伸手要打开储物柜的瞬间——

"不许动！警察！"

埋伏的警察一拥而上，将黑影按倒在地。

黑影想挣扎，但被死死压住，动弹不得。

警察从他身上搜出了部分赃物——几件翡翠首饰，正是珠宝店丢失的。

"人赃并获！"周明远宣布。

黑影被押回派出所，老张也被控制。

经审讯，黑影交代自己叫阿龙，是珠宝店盗窃案的主谋。

阿龙："是我策划的。老张是我的内部接应。"

阿龙交代了作案手法："作案前两天，我让老张配了储物柜的钥匙。作案当晚，老张从里面把珠宝递出来，我在外面接应。然后老张把珠宝藏在钱阿姨的音响里，因为钱阿姨跳广场舞，经常不在家，容易下手。"

陆行舟的推理完全正确！

消息传回派出所，围观群众一片哗然。

"陆行舟真的破案了！"

"我就说他有本事！"

"之前还说他不行，现在打脸了吧？"

群众的眼神，从质疑变成了佩服。

钱凤英激动地握住陆行舟的手："小陆，我就知道你能行！之前是我动摇了，对不起啊！"

陆行舟："没关系，钱阿姨，我理解。"

苏晚也走过来，眼神中带着认可："你确实变了，这次推理很专业。之前我质疑你，现在看来，你真的有侦探天赋。"

周明远拍拍陆行舟的肩膀："陆行舟，这次做得好！你用证据说话，这才是真正的侦探。"

但陆行舟没有立刻回应，他看向秦墨寒。

秦墨寒站在角落，脸色铁青，一言不发。

他没想到陆行舟真的破案了。而且是用他之前嘲笑的"歪理推理"——虽然陆行舟这次用的是证据，但最初的线索，依然是那个荒谬的"秦墨寒鞋底泥土"。

秦墨寒走到陆行舟面前，声音有些僵硬："这只是运气。你的推理过程依然不科学。"

陆行舟平静地看着他："秦侦探，推理的目的是找到真相，不是证明自己有多科学。"

秦墨寒："你所谓的线索——我的鞋底泥土，那只是巧合。我确实去过储物柜附近调查，但我没有隐瞒，只是没必要汇报每一个细节。"

陆行舟："那您为什么在会议上说，您一直在查监控和问话，没有去过储物柜？"

秦墨寒愣住了。他确实说过这句话。

陆行舟继续说："您隐瞒了去过储物柜的事实。也许您有自己的考虑，但这让我产生了怀疑。正是这个怀疑，让我决定去验证储物柜的线索。"

秦墨寒："那只是你的臆测！"

陆行舟："但我的臆测找到了真相。"

他拿出证据链："储物柜划痕方向→内部接应→老张财务异常→引蛇出洞→人赃并获。每一步都有证据支撑。"

陆行舟看向秦墨寒："秦侦探，您的精密推理很强，但您忽略了一个细节——划痕的方向。您一直在查监控、问话、记录时间线，但您没有仔细观察储物柜本身。"

秦墨寒脸色更加难看。他确实忽略了这一点。

陆行舟："我的方法确实不科学，我承认。但有时候，不科学的方法，能发现科学方法忽略的线索。"

秦墨寒沉默了很久。

最终，他低声说："这次是你赢了。"

但他的语气中，依然带着不甘："但我不会认输的。你的方法只是碰巧有效，下次，我会证明精密推理才是正道。"

陆行舟点头："好，我等着。"

他伸出手："秦侦探，虽然我们方法不同，但我们的目标是一样的——找到真相。也许以后，我们可以互相学习。"

秦墨寒看着陆行舟的手，犹豫了一下，最终握了握："也许吧。"

周明远看着两人，笑了："看来你们两个，以后会成为很好的对手。"

陆行舟："对手，也是最好的老师。"

案件告破，陆行舟证明了自己。

他拿起推理书，翻开一页，但没有像以前那样说"书告诉我了"。

他只是默默看着书页，然后合上，放进怀里。

苏晚注意到这个细节："你不翻书了？"

陆行舟笑了笑："书只是参考，真正的线索，在现场，在证据里。"

苏晚也笑了："你真的变了。"

陆行舟看向窗外，夜色已深，但派出所的灯还亮着。

他依然会翻推理书，依然会有那些荒谬的直觉。

但现在，他多了一份理性，多了一份对证据的尊重。

下次，当直觉出现时，他会先用证据验证，再说出来。
