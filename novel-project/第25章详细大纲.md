## 📝 详细场景设计

### 场景一：作案频率分析（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 分析作案时间规律 |
| **情绪曲线** | 专注→紧张 |
| **出场人物** | 秦墨寒、陆行舟、周明远 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

**开头设计（承接第24章）**：
```
时间：竞争第四天上午
地点：幸福派出所，周明远办公室
氛围：紧张专注，墙上11个红圈
```

**情节展开**：

1. **作案时间列表**（400字）
   - 秦墨寒列出11起案件的作案时间
   - 7月1日：1起（第1起）
   - 7月2日：2起（第2、3起）
   - 7月3日：2起（第4、5起）
   - 7月4日：3起（第6、7、8起）
   - 7月5日：3起（第9、10、11起）
   - 作案频率加快，从每天1起增加到每天3起

2. **作案间隔分析**（400字）
   - 秦墨寒分析作案间隔
   - 最初间隔1天，后来同日作案
   - "嫌疑人越来越大胆，作案频率加快。"
   - 周明远："这说明他越来越自信，或者越来越急。"

#### 对话设计

**秦墨寒分析**：
```
秦墨寒："作案频率明显加快。"
"7月1日1起，2日2起，3日2起，4日3起，5日3起。"
"从每天1起增加到每天3起，嫌疑人越来越大胆。"
```

**周明远反应**：
```
周明远："这说明什么？"
秦墨寒："嫌疑人越来越自信，或者越来越急。"
周明远："急？为什么急？"
秦墨寒："可能是时间压力，或者目标压力。"
```

#### 环境描写

```
周明远的办公室里，墙上挂着辖区地图，11个红圈散落各处。
秦墨寒在白板上画出作案时间轴，红色的标记越来越密集。
陆行舟在旁边看着，心里想着另一件事：排查空调维修工。
```

### 场景二：地点规律分析（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 分析作案地点规律 |
| **情绪曲线** | 专注→困惑 |
| **出场人物** | 秦墨寒、陆行舟 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

1. **地点分布分析**（400字）
   - 秦墨寒在地图上标出11起案件的地点
   - 幸福小区3起、幸福花园2起、阳光公寓3起、康乐小区3起
   - 分布在整个辖区，无明显聚集特征
   - "地点分散，无热点区域。"

2. **住宅类型分析**（400字）
   - 11起案件中，有别墅、公寓、老小区
   - 受害者有退休教师、年轻夫妻、上班族、小商贩
   - 无明显目标偏好
   - 秦墨寒皱眉："地点、住宅类型、受害者职业，都无规律。"

#### 对话设计

**秦墨寒分析**：
```
秦墨寒："地点分散，无热点区域。"
"幸福小区、幸福花园、阳光公寓、康乐小区，分布在整个辖区。"
"住宅类型：别墅、公寓、老小区，无偏好。"
"受害者职业：退休教师、年轻夫妻、上班族、小商贩，无规律。"
```

**陆行舟观察**：
```
陆行舟："地点无规律，但作案手法有规律。"
秦墨寒："什么规律？"
陆行舟："技术开锁、饭点作案、踩点观察。"
```

#### 环境描写

```
地图上，11个红圈散落各处，像一张没有规律的网。
秦墨寒用不同颜色标注不同住宅类型，试图找出规律。
但所有分析都指向同一个结论：分散，无规律。
```

### 场景三：排查空调维修工（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 排查嫌疑人身份 |
| **情绪曲线** | 期待→紧张 |
| **出场人物** | 陆行舟、社区工作人员 |
| **场景时长** | 约2小时（故事时间） |

#### 详细情节

1. **排查辖区维修工**（400字）
   - 陆行舟联系社区，排查辖区内的空调维修工
   - 辖区内有3家空调维修店，共12名维修工
   - 陆行舟逐一走访，询问他们过去一周的工作记录
   - 大部分维修工都有明确的工作记录，可以排除

2. **发现可疑人员**（400字）
   - 陆行舟走访第三家维修店时，老板说："有个临时工，叫周强，最近经常在幸福辖区修空调。"
   - "他不是我们店里的正式员工，只是临时帮忙的。"
   - "过去一周，他经常出去修空调，但我没记录他的具体工作地点。"
   - 陆行舟眼睛一亮：周强，临时工，符合嫌疑人特征！

#### 对话设计

**排查对话**：
```
陆行舟："你们店里有穿灰色夹克、身高一米七五左右的维修工吗？"
老板："有个临时工，叫周强，符合这个特征。"
陆行舟："他最近的工作记录有吗？"
老板："他是临时工，我没记录他的具体工作地点。"
```

**陆行舟内心**：
```
"周强，临时工，灰色夹克，一米七五。"
"过去一周经常在幸福辖区修空调。"
"符合嫌疑人特征！"
```

#### 环境描写

```
第三家空调维修店，店面不大，墙上挂着各种空调品牌的海报。
老板是个中年人，看着陆行舟的证件，有些紧张。
陆行舟在笔记本上记下：周强，临时工，需进一步调查。
```

### 场景四：汇报进展（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 第四次交锋，两人各有进展 |
| **情绪曲线** | 紧张→期待 |
| **出场人物** | 陆行舟、秦墨寒、周明远、苏晚 |
| **场景时长** | 约15分钟（故事时间） |

#### 详细情节

1. **下午5点汇报**（300字）
   - 周明远办公室，两人按时汇报
   - 秦墨寒："作案频率加快，从每天1起增加到每天3起。但地点、住宅类型、受害者职业都无规律。"
   - 周明远点头："有进展，但还不够。"

2. **陆行舟汇报**（300字）
   - 陆行舟："我排查了辖区内的空调维修工，发现一个可疑人员：周强，临时工。"
   - "他符合嫌疑人特征：灰色夹克、一米七五、过去一周经常在幸福辖区修空调。"
   - 周明远眼睛一亮："能锁定他吗？"
   - 陆行舟："需要进一步调查，确认他是否就是嫌疑人。"

#### 对话设计

**汇报对话**：
```
秦墨寒："作案频率加快，但其他维度无规律。"
周明远："有进展，但还不够。"

陆行舟："我发现一个可疑人员：周强，临时工。"
"他符合嫌疑人特征，需要进一步调查。"
周明远："好，继续调查。"
```

**苏晚观察**：
```
苏晚心想：第四次交锋，两人各有进展。
秦墨寒分析出作案频率加快，陆行舟找到可疑人员。
竞争白热化，谁能先破案？
```

#### 环境描写

```
周明远的办公室里，夕阳透过窗户照进来。
秦墨寒和陆行舟各坐一边，气氛微妙。
苏晚靠在墙边，观察着两人的表情。
两人都有进展，但都还没有决定性突破。
```
