## 五、核心推理

| 类型 | 内容 |
|------|------|
| 歪理入口 | 留下太多痕迹的人不是想消失，而是在防止别人替她解释消失 |
| 事实链 | C-12 留言、后巷便签、后街监控、便利店证词、旧印社发现许念 |
| 行为链 | 邵启明借名单接近许念，使用晴心身份话术，准备让许念签离校说明；许念逃离后留下半句求助和便签 |
| 遮挡链 | 马成推 B07 遮挡监控，事后回填蓝杯子和请假条，制造“正常请假/暂时离校”假象 |
| 责任链 | 邵启明为直接操作者，马成为执行协助者，学校名单流转和低调处理构成制度性伤害 |

## 七、通过标准

- 第一屏必须确认许念安全方向，不能继续拖生死悬念。
- 必须解释“不要替我道歉”的对象和含义。
- 必须回收蓝杯子、请假条、B07、名单导出、邵启明假身份。
- 必须让许念拥有完整表达，不让警方、母亲或学校替她总结。
- 必须完成 C003 表层闭环，同时只轻量保留幕后观察长线。
