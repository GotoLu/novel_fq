## 📝 详细情节设计

### 场景一：分头调查（800字）

**时间**：第二天上午
**地点**：幸福派出所、各调查地点
**人物**：陆行舟、苏晚、秦墨寒、周明远

**场景功能**：开始分头调查，展示竞争

**具体情节**：

1. **周明远的部署**（200字）：
   - 周明远："今天你们分头调查。"
   - 周明远："秦侦探，你继续验证不在场证明。"
   - 周明远："陆行舟，你继续观察林小伟。"
   - 两人点头，竞争气氛浓厚

2. **秦墨寒的调查计划**（200字）：
   - 秦墨寒在白板上画出调查计划
   - 第一步：调取朋友家完整监控
   - 第二步：分析监控盲区
   - 第三步：验证林小伟是否可能离开
   - 苏晚点头："思路很清晰。"

3. **陆行舟的调查计划**（200字）：
   - 陆行舟没有写计划
   - 他直接说："我去观察林小伟。"
   - 秦墨寒冷笑："又是直觉？"
   - 陆行舟："直觉加验证。"

4. **分头行动**（200字）：
   - 秦墨寒留在派出所，调取监控
   - 陆行舟带着苏晚，去找林小伟
   - 两人对视一眼，都带着竞争的意味
   - 周明远叹气："别打起来就行。"

**幽默点**：
- 秦墨寒的白板计划vs陆行舟的"没有计划"
- 周明远的担心

**钩子设计**：
- 竞争钩子：谁能先找到线索？
- 悬念钩子：监控有没有盲区？

### 场景二：秦墨寒的进展（800字）⭐核心场景

**时间**：第二天上午至中午
**地点**：幸福派出所
**人物**：秦墨寒、周明远

**场景功能**：展示秦墨寒的精密分析，发现线索

**具体情节**：

1. **调取完整监控**（200字）：
   - 秦墨寒调取朋友家的完整监控
   - 监控覆盖客厅、餐厅、厨房
   - 但没有覆盖卫生间和阳台
   - 秦墨寒："有盲区。"

2. **分析监控画面**（200字）：
   - 秦墨寒仔细分析监控画面
   - 林小伟确实在客厅聚会
   - 但中途离开过两次
   - 一次去卫生间，一次去阳台
   - 每次离开约5-10分钟

3. **计算时间窗口**（200字）：
   - 秦墨寒在白板上计算
   - 朋友家到林太太家：开车约15分钟
   - 如果林小伟从阳台离开，爬墙出去
   - 10分钟不够往返
   - 但如果他有同伙接应……

4. **发现疑点**（200字）：
   - 秦墨寒："林小伟的不在场证明有漏洞。"
   - "监控有盲区，他可能从阳台离开。"
   - "但时间不够，除非有同伙。"
   - 周明远："继续查！"

**幽默点**：
- 秦墨寒的精密计算
- 白板上的公式和箭头

**钩子设计**：
- 悬念钩子：林小伟有没有同伙？
- 竞争钩子：秦墨寒先找到线索

---

### 场景三：陆行舟的发现（800字）⭐核心场景

**时间**：第二天上午至中午
**地点**：林小伟出现的地点
**人物**：陆行舟、苏晚、林小伟

**场景功能**：展示陆行舟的直觉观察，发现关键线索

**具体情节**：

1. **跟踪林小伟**（200字）：
   - 陆行舟和苏晚跟踪林小伟
   - 林小伟上午出门，去了网吧
   - 在网吧待了两小时，然后去便利店
   - 陆行舟观察他的行为，没有异常

2. **再次查看朋友圈**（200字）：
   - 陆行舟再次查看林小伟的朋友圈
   - 那张有树洞的照片
   - 他把照片放大，仔细观察树洞的形状
   - 树洞呈椭圆形，边缘有苔藓
   - 这个特征很独特

3. **赶往林太太家**（200字）：
   - 陆行舟突然说："去林太太家！"
   - 苏晚："干什么？"
   - 陆行舟："我要看看那棵大树。"
   - 两人赶往林太太家

4. **关键发现**（200字）：
   - 陆行舟来到林太太家院外
   - 隔着围栏，观察那棵大树
   - 树干上的树洞，呈椭圆形，边缘有苔藓
   - 和朋友圈照片里的树洞，一模一样！
   - 陆行舟："这张照片，是在林太太家拍的！"

**幽默点**：
- 陆行舟的突然行动
- 苏晚的困惑

**钩子设计**：
- 悬念钩子：朋友圈照片是在林太太家拍的？
- 竞争钩子：陆行舟也找到线索

### 场景四：第一次交锋（600字）

**时间**：第二天下午
**地点**：幸福派出所会议室
**人物**：陆行舟、苏晚、秦墨寒、周明远

**场景功能**：两人都有发现，竞争白热化

**具体情节**：

1. **秦墨寒汇报**（150字）：
   - 秦墨寒："我的调查有进展了。"
   - "林小伟的不在场证明有漏洞。"
   - "监控有盲区，他可能从阳台离开。"
   - 周明远点头："很好的发现。"

2. **陆行舟汇报**（150字）：
   - 陆行舟："我也有发现。"
   - 秦墨寒："哦？说来听听。"
   - 陆行舟："朋友圈照片里的树洞，和林太太家的树洞一模一样。"
   - "那张照片，可能是在林太太家拍的。"

3. **秦墨寒的质疑**（150字）：
   - 秦墨寒："可能？这不是证据。"
   - 陆行舟："我明天去验证。"
   - 秦墨寒："我的发现更直接，监控有盲区。"
   - 陆行舟："我的发现更关键，照片造假。"

4. **竞争白热化**（150字）：
   - 两人对视，火花四溅
   - 周明远赶紧打圆场："你们都有发现，很好。"
   - "明天继续，看谁先找到证据。"
   - 陆行舟和秦墨寒同时点头

**幽默点**：
- 两人的针锋相对
- 周明远的打圆场

**钩子设计**：
- 竞争钩子：明天继续，看谁先找到证据
- 悬念钩子：谁先破案？
