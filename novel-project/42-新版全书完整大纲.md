调用技能：`plot-architect` 主导多卷结构、案件池、伏笔体系和卷级防塌；参考旧版 `大纲.md`、重构后第一卷正文、`小说资产库.md`、`09-创意重构方案.md`、`10-人物压力测试与群像轮转.md`、`29-前20章重构质量复核.md`。

## 一、设计结论

新版全书采用 100 章、5 卷、20 个五章案件组结构。

核心升级：

- 保留旧版“100 章五卷”和双侦探竞技的长篇框架。
- 放弃旧版后期“能力觉醒、封神、正式侦探”的空泛升级线。
- 延续重构后第一卷已成立的规则：歪理只能指路，证据才能判人。
- 每 5 章完成一个阶段案件闭环，每 20 章完成一次卷级认知反转。
- 幕后主线不压过单元案，但每卷必须改变陆行舟、苏晚、秦墨寒、周明远的关系状态。

最优方案：以“有人研究并投喂陆行舟的异常判断”为全书主线。

核心理由：

- 与第一卷第 6-20 章已经埋下的“幕后记录者、旧账本样本、封闭现场观察”直接接轨。
- 能自然制造后续强冲突：当异常是被人故意摆出来的，陆行舟还能不能相信自己的直觉。
- 能避免旧版中段只是换案子、打分数、升级称号的疲软。
- 终局能偿付主题：真相不属于直觉或证据任何一方，属于愿意为判断负责的人。

## 二、爆款结构标准

| 标准 | 本大纲执行方式 |
|------|----------------|
| 第一眼钩子 | 每卷首案都用强异常物件或强异常状态开场 |
| 五章闭环 | 每 5 章完成一个案件阶段闭环，降低追读疲劳 |
| 章末追读 | 每章结尾留下具体问题，不用作者式求追读 |
| 爽点链 | 每案都有公开压制、证据翻面、当众反制和余波升级 |
| 人物压力 | 陆行舟误判、苏晚程序风险、秦墨寒证据盲区、周明远旧案债轮流上桌 |
| 案件换气 | 社区、诈骗、校园、公寓、展馆、医院、工厂、直播、舆论、终局旧案不断换空间 |
| 主线节制 | 幕后记录者每卷 2-3 次低频推进，不抢单元案 |
| 完结偿付 | F001-F047、周明远旧案、秦墨寒冤案、苏晚程序线、陆行舟方法论全部回收 |

## 三、全书高概念

一个被全警局嘲笑的编外协查员，靠荒唐歪理不断抓住案件异常；可当有人开始研究他的判断方式、故意摆出“他一定会看见”的异常，他必须学会否定自己的直觉，和证据至上的对手一起，把歪理变成能被所有人复核的方法。

顾闻策定位：

- 曾参与旧案咨询和城市异常行为研究。
- 相信“证据、直觉、程序都只是人类偏见的包装”。
- 他不是无脑反派，而是主角主题的反面：陆行舟学会为判断负责，顾闻策则用实验逃避责任。
