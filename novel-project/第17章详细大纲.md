## 📝 详细场景设计

### 场景一：秦墨寒调查监控系统（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 秦墨寒深入调查监控，查明卡顿原因 |
| **情绪曲线** | 专注→困惑→困境 |
| **出场人物** | 秦墨寒、周明远 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

**开头设计（承接第16章）**：
```
时间：上午8点
地点：赵先生别墅客厅
氛围：秦墨寒蹲在监控设备前，专注检查
状态：陆行舟已离开去调查人员
```

**情节展开**：

1. **检查监控设备**（200字）
   - 秦墨寒打开设备外壳，检查内部线路
   - 连接笔记本电脑，读取系统日志
   - 查看设备型号：安达科技AD-8000系列
   - 确认设备运行正常，无故障

2. **分析凌晨3点卡顿**（300字）
   - 查看系统维护日志
   - 发现凌晨3点是系统自动维护时间
   - 维护内容：系统重启、数据校验
   - 维护时长：1秒，正常范围
   - 结论：卡顿是系统自动维护，不是故障

3. **困境分析**（200字）
   - 秦墨寒陷入困境：监控无异常
   - 1秒时间，不可能完成盗窃
   - 常规推理方法无效
   - 自语："这个案子，超出了常规推理。"

4. **继续调查**（100字）
   - 秦墨寒决定深入调查安达科技
   - 查看监控设备维护商信息
   - 准备联系安达科技

#### 对话设计

**秦墨寒自语**：
```
秦墨寒盯着系统日志，眉头紧锁。
"凌晨3点，系统自动维护……"
"维护时长1秒，正常范围……"
"维护期间，监控暂停录制……"

他放下笔记本，靠在沙发上。
"1秒时间，就算打开门，也不可能拿走花瓶再离开。"
"除非……有人提前准备好了。"
```

**秦墨寒向周明远汇报**：
```
秦墨寒站起身，走到周明远身边。
"周所，监控卡顿的原因查清了。"
周明远："什么原因？"
秦墨寒："凌晨3点是系统自动维护时间，监控暂停录制1秒。"
秦墨寒："这是正常维护，不是故障。"
周明远："那1秒能做什么？"
秦墨寒摇头："理论上，1秒不可能完成盗窃。"
周明远皱眉："又是死胡同？"
秦墨寒："这个案子，超出了常规推理。"
```

#### 环境描写

```
客厅里，监控屏幕的光映在秦墨寒脸上，显得专注而冷静。
他蹲在设备前，手指在键盘上飞快敲击，读取系统日志。
屏幕上，一行行代码滚动，凌晨3点的维护记录清晰可见。
```

#### 人物心理

**秦墨寒心理**：
```
凌晨3点卡顿是系统维护，正常现象。
但1秒时间，不可能完成盗窃。
监控没有问题，报警器没有问题，门禁没有问题。
那花瓶怎么消失的？

常规推理方法无效。
这个案子，需要换个角度。
```

### 场景二：陆行舟调查现场细节（1000字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 陆行舟深入调查现场，发现更多细节 |
| **情绪曲线** | 专注→困惑→警觉 |
| **出场人物** | 陆行舟、赵先生、保姆李姨 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

**开头设计**：
```
时间：上午8点
地点：赵先生别墅
氛围：陆行舟在别墅内细致观察
状态：秦墨寒在客厅查监控，陆行舟在调查人员
```

**情节展开**：

1. **深入观察地毯压痕**（200字）
   - 陆行舟再次蹲在地毯前
   - 仔细观察压痕的形状和深度
   - 发现压痕边缘有细微的纤维痕迹
   - 推测：有重物曾短暂放在地毯上
   - 但无法解释：为什么花瓶会在地毯上

2. **检查展示柜**（150字）
   - 陆行舟检查展示柜玻璃
   - 发现玻璃内侧有细微指纹
   - 指纹位置：玻璃门内侧边缘
   - 推测：有人曾打开过展示柜
   - 但指纹不是主人的，需要比对

3. **调查保姆李姨**（250字）
   - 陆行舟找到保姆李姨
   - 李姨：50多岁，工作5年，忠诚可靠
   - 询问昨晚情况：李姨昨晚休息，未听到异常
   - 询问园丁小张：李姨说小张最近行为异常
   - 关键信息：小张最近频繁进客厅，还问过监控设备

4. **调查司机老王**（150字）
   - 陆行舟找到司机老王
   - 老王：45岁，工作3年，老实本分
   - 询问昨晚情况：老王昨晚休息，未听到异常
   - 询问园丁小张：老王说小张最近总往客厅跑

5. **园丁异常汇总**（250字）
   - 陆行舟汇总园丁小张的异常行为
   - 异常1：辞职前频繁进客厅，理由是修剪盆栽（但客厅无盆栽）
   - 异常2：问过监控设备的情况
   - 异常3：最近经常加班，但别墅工作不需要加班
   - 推测：小张在踩点，对监控设备有兴趣

#### 对话设计

**陆行舟观察压痕**：
```
陆行舟蹲在地毯前，仔细观察压痕。
圆形，直径30厘米，边缘有细微的纤维痕迹。
压痕很浅，说明重物停留时间不长。

"花瓶底座和这个压痕差不多大……"
"但花瓶应该在展示柜里，为什么会在地毯上？"
"除非……有人把花瓶拿出来，放在地毯上，然后……消失了？"

陆行舟摇摇头，这个推理说不通。
```

**陆行舟调查李姨**：
```
陆行舟找到保姆李姨，她在厨房准备早餐。
"李姨，我想问您几个问题。"
李姨停下手中的活："您问。"
"昨晚您有没有听到什么异常声音？"
"没有，我昨晚8点就休息了，一觉睡到今早。"
"园丁小张，您了解他吗？"
李姨想了想，脸色微变："小张最近……有点奇怪。"
"怎么奇怪？"
"他最近总往客厅跑，说是修剪盆栽，但我家客厅没有盆栽。"
"还有吗？"
"他还问过我监控设备的事，问什么时候维护，谁负责维护。"
陆行舟眼睛一亮："他问过监控设备？"
"对，我告诉他监控是安达科技负责维护，他就没再问了。"
```

**陆行舟调查老王**：
```
陆行舟找到司机老王，他在车库整理工具。
"老王，我想问您几个问题。"
老王放下工具："您问。"
"昨晚您有没有听到什么异常声音？"
"没有，我昨晚休息了。"
"园丁小张，您了解他吗？"
老王想了想："小张最近总往客厅跑，我问他在干嘛，他说看看环境。"
"看看环境？"
"对，我也没多问。"
```

#### 环境描写

```
别墅内，阳光透过落地窗洒进来，在地板上投下明亮的光斑。
陆行舟蹲在地毯前，仔细观察压痕，眉头紧锁。
厨房里，李姨一边回答问题，一边继续准备早餐。
车库外，老王靠在车门上，回忆着小张的异常行为。
```

#### 人物心理

**陆行舟心理**：
```
地毯压痕，圆形，直径30厘米。
展示柜指纹，不是主人的。
园丁小张，辞职前频繁进客厅，问过监控设备。

这些线索，一定有联系。
但我想不通。

小张为什么要问监控设备？
他在踩点？
但监控显示无人进入……

等等，小张问过监控维护……
如果他能控制监控……
```

### 场景三：人员调查深入（700字）

#### 场景定位
| 项目 | 内容 |
|------|------|

| **出场人物** | 陆行舟、赵先生 |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

**情节展开**：

1. **查询小张信息**（200字）
   - 陆行舟向赵先生询问小张的详细信息
   - 小张真名：张伟，28岁
   - 入职时间：1年前
   - 入职渠道：通过家政公司介绍
   - 辞职时间：昨天下午

2. **查询小张入职资料**（200字）
   - 赵先生找出小张的入职资料
   - 身份证复印件、健康证、推荐信
   - 陆行舟仔细查看，发现异常
   - 推荐信来自"安达家政服务公司"

3. **安达的关联**（200字）
   - 陆行舟注意到"安达"这个名字
   - 监控设备是"安达科技"
   - 小张的推荐信来自"安达家政"
   - 巧合？还是有关联？

4. **联系家政公司**（100字）
   - 陆行舟决定联系安达家政
   - 询问小张的情况
   - 准备进一步调查

#### 对话设计

**陆行舟询问赵先生**：
```
陆行舟找到赵先生："赵先生，小张的入职资料还在吗？"
赵先生："应该在书房，我找找。"
赵先生翻出一叠资料："这是小张入职时提交的。"
陆行舟接过资料，仔细查看。
身份证复印件、健康证、推荐信。
推荐信上写着："兹推荐张伟同志……安达家政服务公司。"

陆行舟眼睛一亮："安达家政？"
赵先生："对，通过家政公司介绍的。"
陆行舟："安达……安达科技……"
赵先生不解："什么？"
陆行舟："监控设备是安达科技的，小张的推荐信来自安达家政。"
陆行舟："这两个安达，有关系吗？"
```

**陆行舟联系家政公司**：
```
陆行舟拿出手机，搜索安达家政的联系方式。
电话接通。
"喂，安达家政吗？我是幸福派出所的陆行舟。"
"我想查询一个员工的信息，张伟，28岁，去年推荐到城北别墅区18号……"
电话那头传来回复："张伟？他不是我们的员工。"
陆行舟愣住："不是你们的员工？"
"对，我们去年确实推荐过员工到18号别墅，但叫李明，不叫张伟。"
陆行舟脸色一变："那张伟是谁？"
"这我们就不清楚了。"
```

#### 环境描写

```
书房里，陆行舟翻看着小张的入职资料，眉头紧锁。
推荐信上的"安达家政"四个字，像是一个线索。
监控设备是安达科技，小张来自安达家政。
这两个安达，真的只是巧合吗？
```

#### 人物心理

**陆行舟心理**：
```

监控设备，园丁小张。

监控是安达科技维护。

这两个安达，一定有关系。
但家政公司说，他们推荐的人叫李明，不叫张伟。
那张伟是谁？
```
