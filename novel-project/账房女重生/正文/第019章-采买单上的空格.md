# 第019章 采买单上的空格

清晨，账房外间。

沈清把所有库房的灯油领单摊开在矮桌上，按库房分堆：内库、西库、旧库房。

内库每月领灯油六斤，西库每月领灯油五斤。两个库房的灯油用量稳定，没有异常。

旧库房每月领灯油九斤。比内库多三斤，比西库多四斤。旧库房只有半间在用，灯油用量却是内库的一倍半。

她把灯油领单和损耗单并排。旧库房领九斤，损耗认三斤烘耗，中间差六斤。六斤灯油，按市价九十文。

她又翻开采买单。

采买单上旧库房的灯油采购价，每月都有空格。空格的位置在"数量"和"单价"之间，填了数量就没填单价，填了单价就没填数量。每月少算的金额，刚好九十文左右。

九十文。

和六斤灯油的市价对上了。

沈清把三张单子排在一起。灯油领单、损耗单、采买单。三张纸，同一笔灯油。

领单上旧库房每月领九斤。损耗单上认了三斤烘耗。采买单上只算了三斤的价钱，空格少算了九十文。

采买单空格少算的九十文，和灯油领单多出的六斤，是同一笔账。灯油领单上旧库房领了九斤，但采买单上只算了三斤的钱。中间六斤灯油的九十文，没有走采买单，也没有走损耗单。

九十文去了哪里？

如果采买单上没有这九十文，那这九十文进了谁的口袋？

空格不是疏忽。是故意留的。留空格的人不想让这九十文出现在采买单上，因为出现了就要入总册，入了总册就要有人负责。

沈清把三张单子收好，站起来。

她拿着灯油领单和采买单走进内间。

"许管事，旧库房的灯油领单和采买单对不上。领单上每月领九斤，但采买单上只算了三斤的钱。中间六斤的差价，要不要补上？"

许管事接过两张单子，翻了翻。他的表情没变，但手指在采买单的空格处停了一下。

"旧库房的账是老规矩，灯油用量大，采买单上不用逐笔算。"许管事把单子放回桌上，"损耗单上不是认了三斤烘耗吗？剩下的就是正常用量。"

"但损耗单上只认了三斤烘耗，没有认剩下的六斤。"沈清低头，"损耗单核销栏是空的，许管事昨天刚盖了章。如果损耗认了三斤，那剩下的六斤应该走采买单。但采买单上没有这六斤的价钱。"

许管事看了她一眼。目光比上次多了几分锐利。

"你倒是算得清楚。"

"理损耗单的时候顺手看的。"沈清低头，"月底对账，领单和采买单对不上，不好看。"

许管事沉默了一会儿。

他在掂量。补上采买单的空格，就要在采买单上填上六斤灯油的价钱。填了价钱，就要有出处。出处只能写旧库房。但旧库房的损耗单已经认了三斤烘耗，如果采买单上又出现六斤灯油的开支，同一笔灯油就出现了两次。

但许管事还是补了。

他从抽屉里拿出笔，在采买单的空格处填上数字：灯油六斤，单价十五文，合计九十文。然后在"经手"栏盖了小印。

红印泥还是湿的。

沈清看着那枚小印落在纸上。

许管事补了假账。他填了六斤灯油九十文，但这九十文和损耗单上认的三斤烘耗是同一笔灯油。同一笔开支，出现在两个地方。采买单上九十文，损耗单上三斤烘耗。两个数字不能同时成立。

沈清没有指出矛盾。她把补好的采买单收起来，低头退出内间。

午后，后院墙根。

小石头跑过来，脸色比昨天更难看。

"沈姐姐，名单后天就定了。"

后天。沈清心里一紧。她只有两天时间。

"几个人？"

"三个。我和另外两个。都是腿脚快的。"小石头蹲在墙根，手指抠着砖缝，"管事说矿山那边催得紧，不能再等了。"

沈清看着他。两天。她需要两天之内找到办法保住小石头。但她现在的筹码只有矛盾账，矛盾账能逼许管事，但能不能逼他放人？

"我还在想办法。"沈清说。

小石头点了点头。他没再说什么，跑走了。

沈清站在墙根，看着他跑远的背影。两天。她必须在这两天之内把矛盾账变成能用的筹码。

入夜，下人房。

别人都睡了。沈清躺在铺上，把今天的收获在心里排了一遍。

采买单：许管事补了六斤灯油九十文，盖了小印。

损耗单：旧库房三斤烘耗，许管事前天盖了核销章。

灯油领单：旧库房每月领九斤。

三张单子，同一笔灯油。领单上九斤，损耗单认三斤，采买单补六斤。三加六等于九，看起来对上了。

但损耗单上的三斤烘耗，是旧库房灯油的一部分。采买单上补的六斤，也是旧库房灯油的一部分。同一笔灯油的开支，走了两条账路。损耗单走的是"烘耗"，采买单走的是"采购"。两条路不能同时走。如果灯油是烘耗掉的，就不应该再出现在采买单上。如果灯油是采购的，就不应该有烘耗。

矛盾账。同一笔开支出现在两个地方，两个数字不能同时成立。

许管事盖了两枚小印。一枚在损耗单上，一枚在采买单上。两枚印，两笔账，一笔灯油。

这是她的弹药。但她还不急着用。她需要一个时机，一个能让矛盾账一击致命的时机。

后天。小石头的名单后天就定了。她必须在后天之前找到这个时机。

她想到了谢氏。

谢氏的"干净账"理念不允许同一笔开支出现在两个地方。如果谢氏看到矛盾账，她会怎么处理？

沈清翻了个身，闭上眼。

后天。两天。
