# 第023章 空账房的灯

夜里的账房，不该有灯。

沈清站在廊柱阴影里，袖中压着那枚秦字旧饭牌。饭牌边缘磨得发亮，像被人捏过许多年，背上的“秦”字却被刮去半边，只剩一点硬骨头似的笔锋。

午后秦妈妈进了主院书房，出来时脸色比灰布袖还淡。两个婆子没有再夹着她，却也没有让她回旧库房，只把她送到西偏廊一间小屋前，说是夫人体恤，让她歇一夜。

歇一夜。

侯府的话，最怕听着像恩典。

沈清没有机会问秦妈妈认了什么。她只得把饭食待核条誊好，夹进主院副册里。春桃缺角饭牌，小石头柴账待核，西膳旧牌待查。

写到最后四字时，谢令仪的朱笔停了一停。

“饭食也要查？”

沈清伏身：“人吃不饱，差事容易出错。差事出错，账也容易乱。”

谢令仪笑了笑：“你倒会替账房省麻烦。”

她没有准，也没有驳，只让沈清晚间去账房外间取灯油例册，说主院要核近日夜灯用度。

灯油例册放在账房外间最东一格。

这是小陈悄悄告诉她的。

可此刻账房门上挂着锁，窗纸里却有光。

那光不亮，像一枚黄豆被油泡着，贴在窗棂后一晃一晃。风从廊下穿过，灯影便斜一下，照出案上空空的笔架。

账房的人早散了。

小陈白日还被许管事叫去核收讫旧页，临走前特意绕到水缸边，同沈清说：“今夜外间不留人。灯油册你若要取，明早再说。”

明早再说的人，今夜不该点灯。

沈清往后退了半步，脚跟抵到廊柱底下的青砖。

门内传来一点轻响。

不是翻册声。

像指甲在木板缝里抠。

她屏住呼吸。

账房外间有三张案。东案放小账，西案放采买副页，中间那张靠墙，底下有一块旧挡板。早先她誊外册，只觉得那挡板比别处新些，木色不齐。那时她还够不到里面。

现在有人在够。

灯影又晃了一下。

门缝下滚出一点黑灰。

沈清蹲下，指尖没有去碰，只借廊下冷光看了一眼。灰里夹着半截细小灯芯，烧得卷曲，末端沾着一丝暗红。

红丝。

她想起西角焦绳头里那一点红，又想起采买单上补入的红丝麻绳。

灯芯可以烧成灰，绳头也可以烧成灰。可两样灰若都落在不该有火的地方，就不是虫蛀，也不是潮损。

门里忽然静了。

沈清立刻起身，侧身隐进廊柱后。

锁头轻轻响了一声。

门没有开。

里面的人似乎也听见了廊下风声，灯光猛地暗下去，只剩一点油烟味从窗缝里钻出来。

这味道比厨房油腥淡，却更呛，像劣油里混了旧蜡。账房白日用的是清灯油，账房外间的人怕熏坏纸，从不许用这种杂油。

有人不敢走正账领油。

沈清没有追。

她现在追上去，只会多一个“夜闯账房”的罪名。她能做的，是让这盏灯自己留下账。

她绕到廊尽头，提起给夜巡预备的空水壶，故意把壶嘴磕在石阶上。

“谁在那里？”廊外传来守夜婆子的声音。

沈清低声道：“奴婢来取主院要的灯油例册，见账房里有灯，怕走了水。”

走了水三个字，比偷账更容易叫人动。

守夜婆子提着灯笼跑来，身后还跟着两个粗使婆子。账房门上的锁还在，窗里却已经黑了。

婆子狐疑地看她：“哪来的灯？”

沈清没有辩，只指门缝下的灰：“许是奴婢看错。可门下有烧落的灯芯，若是白日未扫净，也该记一声。”

守夜婆子最怕担火烛责任，立刻弯腰去看。

“真有灰。”她脸色变了，“钥匙呢？”

账房外间钥匙夜里归许管事房中管。守夜婆子不敢私开，只叫一个粗使去请人。

沈清站在旁边，袖中饭牌压着掌心，一动不动。

没多久，小陈先来了。

他披着外衣，鞋跟都没提好，看见沈清时，眼里先是惊，随即又忍住。

“许管事不在屋里。”粗使婆子喘着气回来，“他房里人说，管事去前院回事了。”

半夜去前院回事。

守夜婆子的脸更白。

小陈低声道：“外间备用钥匙在账房内，不在外头。”

这话说得像废话，却正好把门锁上的责任推回许管事身上。

门锁在外，灯在内。若无钥匙，灯从何来？若有钥匙，钥匙又在谁手里？

规矩有时候不是墙，是绳。谁用它拴人，谁也会被它勒一下。

守夜婆子不敢等许管事，转头去请周嬷嬷。

周嬷嬷来得很快。她身上披着深色外衫，戒尺没有带，脸却比戒尺还硬。

“夜半闹什么？”

沈清垂头，把话说得很短：“夫人命奴婢晚间取灯油例册。奴婢到时，见账房内有灯。守夜妈妈来后，灯灭，门下有烧落灯芯。”

周嬷嬷看向门缝。

小陈也低头去看，忽然道：“这不是账房清灯芯。”

周嬷嬷眼风扫过去。

小陈立刻噤声，却还是把话补完：“清灯芯白，烧后灰细。这个芯里夹红线，像厨房杂油灯用的。”

厨房。

春桃的缺角饭牌，西膳旧牌，小石头藏在馒头里的竹片，都在这一刻轻轻动了一下。

沈清没有看小陈。

她怕自己一看，小陈就被拖进这盏灯里。

周嬷嬷沉默片刻，道：“开门。”

“钥匙不在。”守夜婆子忙道。

周嬷嬷冷笑：“门不开，火烛怎么查？去取铁钩。”

铁钩从窗缝伸进去，勾开内侧木栓时，里面没有人。

账房外间空着。

空得太干净。

东案上的灯油例册摆在最上面，像早有人知道她要取。册面没有灰，边角却有一道新折痕。沈清走近时，先闻到杂油味，再看见中间靠墙那张案底下的挡板松了一线。

周嬷嬷也看见了。

她蹲不下身，只让守夜婆子拿灯照。

挡板缝里夹着一小片碎纸，不是账页，只是一截蓝封皮。纸背有油渍，正面剩下半个字。

耗。

沈清心口一紧。

损耗册的封皮，未必就在这里。

但有人以为在这里。

周嬷嬷伸手要拿。

沈清先一步道：“嬷嬷，纸在夹缝里，若直接扯，字边会断。夫人要核灯油，最好连缝带灰一起封住，明日让账房当众取。”

周嬷嬷的手停在半空。

她看沈清一眼：“你倒会护纸。”

“纸若坏了，谁来过就说不清了。”

这句话落下，小陈的脸色微微变了。

守夜婆子也不敢动了。

不是因为她们信沈清。

是因为谁先碰这张纸，谁就可能变成夜里进账房的人。

周嬷嬷到底没有扯。她让人取封条，把案底挡板、门锁和门下灰都封住，又把灯油例册交给沈清。

“带回主院。”她道，“只抄今夜以前的数。今夜的事，不许添一句。”

沈清接过册子。

册子很轻，压在手里却像压着一盏没有熄干净的灯。

回到偏廊，她翻开灯油例册。

清灯油，账房外间，每夜一钱，近七日皆空。

厨房杂油，西膳旧口，三日前补领半盏。

领油人那一格被墨涂过，涂得很厚。纸背却透出一点旧印，像半枚指腹压下的红痕。

沈清没有去刮。

她只在副册上写下：账房夜灯无领油记录，门下见红芯杂油灰，西膳旧口三日前补领半盏，领油名待复。

最后一笔落下时，窗外风吹动封条，纸声细碎。

空账房里没有人。

可有人比她更急着找那半本册子。
