# 第031章 嫁妆副册

辰正的更鼓刚落，沈清就闻见了红漆匣子的味道。

匣子摆在谢令仪案前，铜扣擦得发亮，封条却是旧的，边角发黄，像一张被人重新贴回去的脸。

西侧窗外传来细细的剪线声。

阿梨在针线房。

窗纸隔着半院，沈清看不见她，只能听见剪刀咔嚓、咔嚓。茶房还有门廊可走，针线房只有高窗，窗下坐满补旧帐幔的丫头，谁多抬一次头，都能被婆子记下。

车马房的人一早送来一页出入小簿，周嬷嬷当着沈清的面压在砚台底下。纸角露着半行字：车马房杂役一名，留用待令。

留用。

侯府最会把关押写得像恩典。

“看够了吗？”谢令仪温声道。

沈清低头：“奴婢不敢。”

周嬷嬷把红漆匣推到她面前：“夫人让你誊嫁妆副册，是抬举你。今日只誊，不核，不问，不添待复。错一个字，拿你十个月银也赔不起。”

沈清应是。

她现在连一个月银也没有，赔不起的不止是字。

谢令仪亲手开匣。红绸封皮压在最上层，四角包金，封面题着端正小楷：陪嫁细目副册。

前世那一角红绸从妆奁底下露出来时，也是这样干净。那时沈清手指断了两根，只看见封皮边有一点绣线毛头。她以为那是富贵线，后来才知道，富贵也会勒人。

“先誊首饰。”谢令仪道。

沈清照着副册落笔。

赤金累丝头面一副，重三十八两六钱，完好。

红宝蝴蝶钗一对，嵌珠十二，完好。

翠玉压鬓簪二支，匣封未动，完好。

字字都是完好。

完好得像侯府从来没有少过一根丝。

誊到第七行，廊外珠帘一响。

“母亲，我今日要那支红宝钗。”

说话的是陆明珠。她刚及笄，腕上红珠串轻轻碰着金镯，两个小丫鬟跟在身后，一个捧妆匣，一个托霞色披帛。

谢令仪笑了：“一早就闹到我这里？”

“寿宴要见外客，姨母说我戴素了压不住。”

周嬷嬷道：“姑娘，那支红宝钗在夫人嫁妆册里，取用要记。”

“记就是了。”陆明珠不以为意，“母亲的东西，将来不也是我的？”

屋里静了一瞬。

谢令仪仍笑着：“小孩子话。”

沈清的笔尖停了半息，又继续往下走。

红宝蝴蝶钗一对，嵌珠十二。

陆明珠腕上却只有九颗红珠。中间三颗色泽最正，孔口有细细金粉痕，不像原本穿在腕串上的珠子。

沈清没有看第二眼。

看一眼，是眼力。看第二眼，就是错处。

谢令仪道：“周嬷嬷，去库里取钗。今日先借戴，晚间卸了送回来。”

周嬷嬷领命出去。陆明珠走到窗边，嫌针线房的剪刀声吵，皱眉道：“那边补的什么旧东西？”

“旧帐幔。”谢令仪道。

“又不是不能买新的。”

“旧物有旧物的用处。”谢令仪看了沈清一眼，“有些破处补得好，旁人便只记得它还能用，不记得它破过。”

窗外剪线声停了一下。

沈清的笔也停了一下。

下一行是铺面。

云记绣坊岁供苏绣屏风四扇，春秋各验，完好。

副册旁夹着一张小签，纸色比册页新，边缘裁得极齐。沈清只扫见半行：云记旧屏，改作帐幔，针线房收。

屏风改帐幔。

嫁妆册里仍写完好，针线房却在补旧帐幔。

窗外那一声声剪线，不是在补侯府旧物。

是在把嫁妆的原样剪碎。

陆明珠忽然凑近案边：“你就是那个会看账的丫头？那你看看，我这串珠子值多少？”

她把腕子伸到沈清面前。

三颗正珠离沈清不过半尺，孔口金粉痕更清楚。谢令仪没有阻止。

这是试探。

看她会不会继续不肯装瞎，也看她会不会当着姑娘的面说出不该说的话。

沈清垂眼：“姑娘的东西，奴婢不敢估。若按账房规矩，奴婢只能记见物，不记价。”

陆明珠问：“那怎么记？”

“腕珠一挂，红珠九颗，新绳，未见旧匣。”

谢令仪眼底笑意淡了淡。

沈清没有说三颗珠从钗上来，也没有说副册写着十二颗。她只把当场能看见的东西说清楚。

见物。

不记价。

不认来处。

这比闭嘴更难罚。

周嬷嬷回来时，手里捧着一只小匣。匣中红宝蝴蝶钗金翅轻薄，钗头空着三处小托位，被金粉细细填过，远看像花纹，近看才知道是缺口。

陆明珠脸色一变：“怎么少了珠？”

周嬷嬷也怔住。

谢令仪没有看钗，只看沈清。

窗外剪刀声又响起来，比先前更急。沈清听见其中有一下剪偏了，像线被扯断，短促地嘶了一声。

阿梨在怕。

沈清也怕。

怕不是不能做事的理由，只是每一笔都要算清本钱。

谢令仪慢慢道：“许是旧匠补过。嫁妆年久，金托松动也有。”

陆明珠摸了摸腕串，忽然不说话了。

她再娇纵，也听懂了一点。腕上那三颗最亮的红珠，正好能填回钗头空位。

“沈清，继续誊。”

沈清坐回案前，写完“云记绣坊岁供苏绣屏风四扇，春秋各验，完好”，又往下誊：红宝蝴蝶钗一对，嵌珠十二，匣封未动，完好。

匣封未动。

可匣子已经开了。

钗头也已经空了。

她笔尖停在“好”字末尾，墨点稍重，像一粒小小的黑珠。

谢令仪道：“手不稳？”

沈清低头：“奴婢昨夜未睡，误重一笔。可换纸重誊。”

“不必。”谢令仪合上红绸封皮，“嫁妆副册不是旧库房待核纸，没那么多讲究。”

没那么多讲究。

沈清垂眼。

扣下人一碗粥时，半勺都要入账；轮到主母嫁妆少三颗珠，便成了没那么多讲究。

傍晚，谢令仪收起副册：“明日誊布匹和绣品。针线房那边手慢，阿梨今晚留灯补帐幔。你若心疼她，就更该把自己的笔管住。”

沈清退到廊下。

针线房高窗透出一点黄光，阿梨的影子伏在窗纸后，一低一抬，像被线牵着。车马房方向传来马嚼草的声音，小陈仍出不来。

沈清回到账房外间，把今日练手废纸压到最底层。

她没有写红宝钗缺珠，也没有写云记屏风改帐幔。

她只在纸角极小处补了两句：

见珠九，册珠十二。

云记屏风，剪声在窗外。

干净账的第一处脏，不在墨里。

在被拆下来的珠子，和被剪碎的屏风里。
