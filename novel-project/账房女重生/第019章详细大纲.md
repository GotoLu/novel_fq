## 🎯 核心目标
1. 采买单空格与灯油领单六斤差额逻辑关联——每月少算的九十文对应六斤灯油
2. 逼许管事补假账——沈清用对账逻辑逼许管事把空格填上
3. 矛盾账出现——同一笔灯油开支同时出现在采买单和损耗单上，数字对不上
4. 小石头矿山风险时间压力——管事们这几天就要定名单
5. 为第020章反杀铺垫——矛盾账是弹药，但沈清还不急着用

## 📝 详细场景设计

### 场景一：对账（700字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清把采买单空格与灯油领单六斤差额对上，发现逻辑关联 |
| **情绪曲线** | 专注→发现→确认 |
| **出场人物** | 沈清 |
| **场景时长** | 约半个时辰 |

#### 详细情节
1. 清晨，账房外间。沈清把所有库房的灯油领单摊开在矮桌上，按库房分堆：内库、西库、旧库房。
2. 内库每月领灯油六斤，西库每月领灯油五斤。两个库房的灯油用量稳定，没有异常。
3. 旧库房每月领灯油九斤。比内库多三斤，比西库多四斤。旧库房只有半间在用，灯油用量却是内库的一倍半。
4. 沈清把灯油领单和损耗单并排。旧库房领九斤，损耗认三斤烘耗，中间差六斤。六斤灯油，按市价九十文。
5. 她又翻开采买单。采买单上旧库房的灯油采购价，每月都有空格。空格的位置在"数量"和"单价"之间，填了数量就没填单价，填了单价就没填数量。每月少算的金额，刚好九十文左右。
6. 九十文。和六斤灯油的市价对上了。
7. 采买单空格少算的九十文，和灯油领单多出的六斤，是同一笔账。灯油领单上旧库房领了九斤，但采买单上只算了三斤的钱。中间六斤灯油的九十文，没有走采买单，也没有走损耗单。
8. 九十文去了哪里？如果采买单上没有这九十文，那这九十文进了谁的口袋？

#### 人物心理
- 沈清：采买单空格和灯油领单差额是同一笔账。空格不是疏忽，是故意留的。留空格的人不想让这九十文出现在采买单上，因为出现了就要入总册，入了总册就要有人负责。

### 场景二：逼账（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清用对账逻辑逼许管事补假账，矛盾账出现 |
| **情绪曲线** | 谨慎→试探→对峙→暗胜 |
| **出场人物** | 沈清、许管事 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 沈清拿着灯油领单和采买单走进内间。
2. "许管事，旧库房的灯油领单和采买单对不上。领单上每月领九斤，但采买单上只算了三斤的钱。中间六斤的差价，要不要补上？"
3. 许管事接过两张单子，翻了翻。他的表情没变，但手指在采买单的空格处停了一下。
4. "旧库房的账是老规矩，灯油用量大，采买单上不用逐笔算。"许管事把单子放回桌上，"损耗单上不是认了三斤烘耗吗？剩下的就是正常用量。"
5. "但损耗单上只认了三斤烘耗，没有认剩下的六斤。"沈清低头，"损耗单核销栏是空的，许管事昨天刚盖了章。如果损耗认了三斤，那剩下的六斤应该走采买单。但采买单上没有这六斤的价钱。"
6. 许管事看了她一眼。目光比上次多了几分锐利。
7. "你倒是算得清楚。"
8. "理损耗单的时候顺手看的。"沈清低头，"月底对账，领单和采买单对不上，不好看。"
9. 许管事沉默了一会儿。他在掂量。补上采买单的空格，就要在采买单上填上六斤灯油的价钱。填了价钱，就要有出处。出处只能写旧库房。但旧库房的损耗单已经认了三斤烘耗，如果采买单上又出现六斤灯油的开支，同一笔灯油就出现了两次。
10. 但许管事还是补了。他从抽屉里拿出笔，在采买单的空格处填上数字：灯油六斤，单价十五文，合计九十文。然后在"经手"栏盖了小印。
11. 沈清看着那枚小印落在纸上。红印泥还是湿的。
12. 许管事补了假账。他填了六斤灯油九十文，但这九十文和损耗单上认的三斤烘耗是同一笔灯油。同一笔开支，出现在两个地方。采买单上九十文，损耗单上三斤烘耗。两个数字不能同时成立。
13. 沈清没有指出矛盾。她把补好的采买单收起来，低头退出内间。

#### 对话设计
- 沈清："旧库房的灯油领单和采买单对不上。领单上每月领九斤，但采买单上只算了三斤的钱。中间六斤的差价，要不要补上？"
- 许管事："旧库房的账是老规矩，灯油用量大，采买单上不用逐笔算。损耗单上不是认了三斤烘耗吗？剩下的就是正常用量。"
- 沈清："但损耗单上只认了三斤烘耗，没有认剩下的六斤。损耗单核销栏是空的，许管事昨天刚盖了章。如果损耗认了三斤，那剩下的六斤应该走采买单。但采买单上没有这六斤的价钱。"
- 许管事："你倒是算得清楚。"
- 沈清："理损耗单的时候顺手看的。月底对账，领单和采买单对不上，不好看。"

#### 人物心理
- 沈清：许管事补了假账。他以为补上空格就能对上账，但他没注意到同一笔灯油已经出现在两个地方了。矛盾账是她的弹药，但她还不急着用。
- 许管事：这丫头算得越来越清楚了。但补上空格就能堵住她的嘴，月底对账也好看。他没多想。

### 场景三：矿山的时间（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 小石头矿山风险时间压力，沈清需要加快节奏 |
| **情绪曲线** | 紧张→紧迫 |
| **出场人物** | 沈清、小石头 |
| **场景时长** | 片刻 |

#### 详细情节
1. 午后，后院墙根。小石头跑过来，脸色比昨天更难看。
2. "沈姐姐，名单后天就定了。"
3. 后天。沈清心里一紧。她只有两天时间。
4. "几个人？"
5. "三个。我和另外两个。都是腿脚快的。"小石头蹲在墙根，手指抠着砖缝，"管事说矿山那边催得紧，不能再等了。"
6. 沈清看着他。两天。她需要两天之内找到办法保住小石头。但她现在的筹码只有矛盾账，矛盾账能逼许管事，但能不能逼他放人？
7. "我还在想办法。"沈清说。
8. 小石头点了点头。他没再说什么，跑走了。
9. 沈清站在墙根，看着他跑远的背影。两天。她必须在这两天之内把矛盾账变成能用的筹码。

#### 对话设计
- 小石头："名单后天就定了。"
- 沈清："几个人？"
- 小石头："三个。我和另外两个。都是腿脚快的。管事说矿山那边催得紧，不能再等了。"
- 沈清："我还在想办法。"

#### 人物心理
- 沈清：两天。矛盾账是弹药，但还需要一个引爆的时机。第020章的反杀必须提前到后天之前。

### 场景四：矛盾账（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清整理矛盾账，确认弹药，准备反杀 |
| **情绪曲线** | 冷静→确认→决心 |
| **出场人物** | 沈清 |
| **场景时长** | 入夜 |

#### 详细情节
1. 入夜，下人房。沈清躺在铺上，把今天的收获在心里排了一遍。
2. 采买单：许管事补了六斤灯油九十文，盖了小印。
3. 损耗单：旧库房三斤烘耗，许管事昨天盖了核销章。
4. 灯油领单：旧库房每月领九斤。
5. 三张单子，同一笔灯油。领单上九斤，损耗单认三斤，采买单补六斤。三加六等于九，看起来对上了。
6. 但损耗单上的三斤烘耗，是旧库房灯油的一部分。采买单上补的六斤，也是旧库房灯油的一部分。同一笔灯油的开支，走了两条账路。损耗单走的是"烘耗"，采买单走的是"采购"。两条路不能同时走。如果灯油是烘耗掉的，就不应该再出现在采买单上。如果灯油是采购的，就不应该有烘耗。
7. 矛盾账。同一笔开支出现在两个地方，两个数字不能同时成立。
8. 许管事盖了两枚小印。一枚在损耗单上，一枚在采买单上。两枚印，两笔账，一笔灯油。
9. 这是她的弹药。但她还不急着用。她需要一个时机，一个能让矛盾账一击致命的时机。
10. 后天。小石头的名单后天就定了。她必须在后天之前找到这个时机。

#### 人物心理
- 沈清：矛盾账是弹药，但弹药需要靶子。许管事是靶子，但打倒许管事不够。她需要让矛盾账打到一个更大的靶子——让谢氏看到。谢氏的"干净账"理念不允许同一笔开支出现在两个地方。如果谢氏看到矛盾账，她会怎么处理？

## 🎭 人物塑造

### 沈清
- **算账能力**：把采买单空格、灯油领单差额、损耗单烘耗三条线拧成一根
- **策略执行**：逼许管事补假账而不是直接揭发，让许管事自己制造矛盾账

- **盲点**：没注意到同一笔灯油已经走了两条账路
- **小印**：两枚印盖在不同单子上，成为铁证

## 📝 写作策略

### 开头策略
承接第018章沈清决定重新查所有库房的灯油领单，直接进入对账场景。

### 中间策略
场景二是核心：沈清用对账逻辑逼许管事补假账。关键是许管事补账的过程——他以为补上空格就能解决问题，但补上之后同一笔灯油就走了两条账路。矛盾账不是沈清制造的，是许管事自己制造的。

### 结尾策略
场景四整理矛盾账，确认弹药。章末用"后天"时间压力和"谢氏看到会怎样"的暗示驱动翻页。
