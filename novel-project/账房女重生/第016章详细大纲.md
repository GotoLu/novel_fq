## 📝 详细场景设计

### 场景一：损耗账里的旧库房（700字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 承接第015章，沈清从灯油领单转向库房损耗账，发现旧库房损耗异常 |
| **情绪曲线** | 日常→发现→警觉 |
| **出场人物** | 沈清、许管事 |
| **场景时长** | 约半个时辰 |

#### 详细情节
1. 沈清继续在账房外间理纸。灯油领单誊完后，许管事让她把库房损耗单也理了。
2. 库房损耗单比灯油领单更复杂：日期、物品、损耗量、损耗原因、库房签收、核销状态。
3. 沈清先按库房分堆。大部分损耗单来自"内库"和"西库"，格式统一，损耗量正常。
4. 她翻到"旧库房"的损耗单。数量很少，只有十几张，但损耗原因栏写的不是常见的"虫蛀""受潮""搬运损耗"，而是统一的"烘耗"。
5. 烘耗。和秦妈妈说的"怕潮，冬天要一直点油灯烘"对上了。但"烘耗"不是侯府损耗单的标准格式。内库和西库的损耗原因都是四字格，"烘耗"只有两个字。
6. 更奇怪的是，这些损耗单的核销状态栏都是空的。没有核销，意味着损耗没有被确认入总册。

#### 对话设计
- 许管事（递纸）："库房损耗单也理了，和灯油领单放一起。"
- 沈清（低头）："是。"

#### 环境描写
- 账房外间午后，日光从窗户斜照进来
- 库房损耗单纸色比灯油领单更白，是近两年的纸
- "旧库房"损耗单夹在一摞纸中间，不翻到底看不到

#### 人物心理
- 沈清：灯油领单是入口，损耗单是出口。入口进来的油，出口出去的损耗，两边对不上——油用了三倍，损耗只写了"烘耗"两个字，没有核销

### 场景二：旧库房的两扇门（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清再次去旧库房，确认钥匙只能开半间门，F-V1-003强化 |
| **情绪曲线** | 紧张→观察→确认→碰壁 |
| **出场人物** | 沈清、秦妈妈 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 沈清借送损耗单核对的名义去旧库房。这次她走正门，不绕小路。
2. 旧库房的门比她上次注意到的更宽。不是一扇门，是两扇并排的木门。左扇门上挂着铁锁，锁擦得干净。右扇门上也有锁，但那把锁是新的，锁环上有锈迹，像是很久没开过。
3. 两扇门。两把锁。秦妈妈只管左边的锁。
4. 沈清走到矮屋门前。这次秦妈妈没有立刻开门，隔了半天才把门推开一条缝。
5. 沈清说损耗单上旧库房的"烘耗"没有核销，想问秦妈妈确认损耗原因。秦妈妈看了她一眼，声音更低："烘耗就是烘耗。不用核销。"
6. 沈清没有追问。她看了一眼秦妈妈腰间——腰带上挂着一串钥匙，其中一把比其他的大，铁质，发黑。那把钥匙的位置最靠外，像是经常用的。
7. 沈清退后一步，目光扫过库房两扇门。左扇门的门框上，那个"半"字刻痕还在。右扇门的门框上没有刻痕，但门板和门框之间有一道细缝，像是被强行关上后没有再打开过。
8. 秦妈妈顺着她的目光看过去，脸色变了一下。然后门关上了，比上次更坚决。

#### 对话设计
- 沈清："损耗单上旧库房的'烘耗'没有核销，想问秦妈妈确认损耗原因。"
- 秦妈妈（更低声）："烘耗就是烘耗。不用核销。"
- [秦妈妈关门，不再说话]

#### 环境描写
- 旧库房正门，两扇并排木门
- 左扇门：铁锁擦得干净，门框有"半"字刻痕
- 右扇门：新锁有锈迹，门板与门框之间有细缝，像很久没开过
- 秦妈妈矮屋门口，门只推开一条缝

#### 人物心理
- 沈清：两扇门、两把锁，秦妈妈只管左边。右边那扇门是谁锁的？为什么很久没开过？钥匙只开半间门，另一半门另有锁——"半"字不是标记，是事实
- 秦妈妈：沈清看两扇门的时候，她脸色变了。她怕的不是沈清问损耗，而是沈清看门

### 场景三：给药钱的方式（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 阿安三天时限推进，沈清找到间接给药钱的方式 |
| **情绪曲线** | 焦虑→决定→行动 |
| **出场人物** | 沈清、阿梨 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 申时，沈清从旧库房回来，在廊下遇到阿梨。阿梨比昨天更瘦了，围裙系带又紧了一圈。
2. 阿梨低声说阿安今天咳出了血，药铺说二十文不够了，要四十文才能给药。阿梨急得眼圈发红，但不敢哭——主院的婆子就在不远处。
3. 沈清不能直接给钱。但她想到了一个办法：待核小账里的三十文。那三十文是"暂缓"的，不是"取消"的。如果她能把待核状态改成"核销退回"，三十文就能退回阿梨的月银。
4. 但改待核状态需要许管事签字。许管事不会无缘无故签字。
5. 沈清对阿梨说："明天会有消息。"她不确定，但她必须说。
6. 阿梨点头，转身走回主院。她的背影比上次更瘦，围裙系带勒进了腰里。

#### 对话设计
- 阿梨（低声）："我弟弟咳出血了，药铺说二十文不够，要四十文。"
- 沈清："明天会有消息。"

#### 环境描写
- 廊下申时，日头偏西
- 阿梨的围裙系带勒进腰里，比上次更紧
- 远处主院婆子在走动

#### 人物心理
- 沈清：不能直接给钱，但可以从账目逻辑里找到退路。待核三十文是钥匙——不是旧库房的钥匙，是阿安药钱的钥匙

### 场景四：从损耗反推（400字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 收束全章，沈清从直接碰壁转向间接反推，为第17章铺垫 |
| **情绪曲线** | 沉思→决心 |
| **出场人物** | 沈清 |
| **场景时长** | 片刻 |

#### 详细情节
1. 入夜，沈清躺在铺上，盯着房梁。她在心里把今天看到的排了一遍。
2. 两扇门。两把锁。秦妈妈只管左边的锁。右边那把锁是新的，很久没开过。
3. 灯油领单三倍用量，损耗单只写"烘耗"两个字，没有核销。油用了，损耗没入总册。中间差了什么？
4. 她想起秦妈妈腰间那把大钥匙。铁质，发黑，位置最靠外。那把钥匙只开左边的门。右边的门，钥匙在谁手里？
5. 直接问秦妈妈，她不会说。直接碰锁，秦妈妈会赶人。但损耗单是账房的东西，许管事让她理的。她可以继续从损耗单里找。
6. 不是从门进去。是从账进去。

#### 人物心理
- 沈清：碰了两次壁，不能再碰第三次。换路——不从门进，从账进。损耗单没有核销，说明旧库房的损耗从未被正式确认。这意味着旧库房在账面上是"不存在"的。但灯油领单证明它在用。一个在用但不存在的库房，里面藏了什么？

## 📝 写作策略

### 开头策略
承接第015章沈清记住三件事，从许管事安排的库房损耗单入手，自然过渡到发现"旧库房"损耗异常。

### 中间策略
场景二是核心：两扇门、两把锁的确认。秦妈妈的反应从"开门见山"变成"推一条缝"，警惕升级。沈清的观察从"看"变成"算"——不是看门，是算门。

### 结尾策略
"不从门进，从账进"是全章转折点。碰壁两次后换路，不是放弃，是更聪明地接近。前世对比不需要——这一世她已经比前世走得更远了。
