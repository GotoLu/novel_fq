## 📝 详细场景设计

### 场景一：账房外间·月银扣项条（900字）

#### 场景定位

| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清在待核小账中发现月银扣项与药钱的精确对应 |
| **情绪曲线** | 专注→发现→心惊 |
| **出场人物** | 沈清、小陈（背景） |
| **场景时长** | 约一个时辰 |

#### 详细情节

1. 沈清继续整理待核小账，今天轮到月银扣项条。这些条子比采买单更碎，每张只有一两行字：姓名、应发、实发、扣项事由。
2. 她按日期排好，开始誊抄。誊到阿梨的名字时，手停了。
3. 阿梨应发月银五百文，实发三百二十文。扣项：汤药预支一百文，饭食补扣三十文，领单印费二十文，待核三十文。
4. 沈清把前后三个月的扣项条排在一起看。每月扣项名目不同，但总数几乎一样：每月扣掉一百八十文左右。
5. 她想起阿梨说过的话：弟弟阿安的药钱，每月一百八十文。差二十文，药铺就不赊了。
6. 月银扣项的数目，和药钱一模一样。不是巧合，是算好的。扣多少，取决于药铺要多少。药铺要多少，取决于阿安还能活多久。
7. 她翻到更早的扣项条。阿梨入府头三个月，扣项只有领单印费和饭食补扣，每月不到五十文。从第四个月开始，突然多了"汤药预支"一项，每月一百文。
8. 第四个月，正是阿安病重的时候。从那以后，阿梨的月银就像一根管子，一头连着侯府账房，另一头连着药铺柜台。管子里的数目，刚好够阿安不死，也刚好够阿梨走不掉。

#### 对话设计

- 小陈随口问："你今天翻得比昨天慢。"
- 沈清："月银条子字小，看得费眼。"

#### 人物心理

- 沈清：前世她知道阿梨月银被扣，但从没算过扣多少、为什么扣。现在她看见了精确的数字，每一个文都对应着阿安的命。不是模糊的"穷"，是"一百八十文，差二十文药铺就不赊"。

### 场景二：廊下·阿梨的消息（600字）⭐核心场景

#### 场景定位

| 项目 | 内容 |
|------|------|
| **场景功能** | 阿梨带来弟弟病情恶化的消息，让数字变成活人 |
| **情绪曲线** | 压抑→震颤 |
| **出场人物** | 沈清、阿梨 |
| **场景时长** | 约一刻钟 |

#### 详细情节

1. 午饭时，阿梨从主院出来。她的脸色比昨天更差，眼底有青黑，像一夜没睡。
2. 阿梨压低声音："我弟弟的药断了。药铺说上月的账还没清，不肯再赊。"
3. 沈清问："差多少？"
4. 阿梨伸出两根手指："二十文。就差二十文。"
5. 二十文。刚好是月银扣项里"待核"的那一笔。第011章沈清用格式漏洞暂缓了阿梨的扣项，但"暂缓"不是"取消"。待核的三十文还挂着，药铺等不了。
6. 阿梨又说："主院的婆子说，我弟弟的事不归侯府管。我求了周嬷嬷，周嬷嬷说我月银还没发，等发了再说。"
7. 沈清看着阿梨的手。那双手端过茶盘、洗过碗碟、拧过抹布，现在攥着二十文的缺口，像攥着弟弟的命。
8. 她没有说"我帮你凑"。她知道二十文不是问题，问题是每个月都会差这二十文，差到阿安的药永远断断续续，差到阿梨永远走不掉。

#### 对话设计

- 阿梨："二十文。就差二十文。我弟弟的命，就值这二十文。"
- 沈清没有接话。她心里有一笔账正在合拢。

#### 人物心理

- 沈清：前世她没有算过这笔账。她只看见阿梨被扣月银，没看见扣的数目刚好卡在"够活但不够走"的线上。这不是许管事贪心，这是有人算好了的。算好了阿梨每个月都会差二十文，算好了她永远不敢离开侯府，因为离开就没人给药钱。

### 场景三：账房外间·合账（600字）

#### 场景定位

| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清把采买单空格和月银扣项合在一起看，发现两条线指向同一个出口 |
| **情绪曲线** | 专注→明悟→决意 |
| **出场人物** | 沈清 |
| **场景时长** | 约半个时辰 |

#### 详细情节

1. 下午，沈清把采买单空格和月银扣项条并排放在矮桌上。
2. 采买单空格：每月九十文（三斤猪肉，三十文一斤，三个月二百七十文）。空格意味着这笔钱没有入总册，去了别的地方。
3. 月银扣项：阿梨每月被扣一百八十文，其中"汤药预支"一百文是虚名，实际药铺只收到八十文。中间差了二十文。
4. 采买单空格少算的钱，和月银扣项多扣的钱，数目对不上。但方向一致：都是从下人身上刮下来的。
5. 沈清没有证据证明这两笔账有关联。但她知道，许管事不会只做一笔。空格是入口，扣项是出口。入口进来的钱，总要从出口流走。流到哪里，才是真正的账。
6. 她把誊清稿写好，照例只写品目、日期和待核状态，没有写自己的判断。
7. 交誊清稿时，许管事没有多问。他翻了两页，说："明日把灯油领单也理了。"
8. 沈清应了。灯油领单——第023章"空账房的灯"的入口。

#### 人物心理

- 沈清：她不能动。她手里只有空格和扣项，没有总册，没有签押，没有证人。动早了，许管事会补账，谢氏会收绳。她只能等。等到空格变成铁证，等到扣项变成人命，等到所有人都能看见那一两银子的分量。

### 场景四：下人房·决意（400字）

#### 场景定位

| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清在心里完成合账，把数字变成决心 |
| **情绪曲线** | 沉→定 |
| **出场人物** | 沈清 |
| **场景时长** | 入夜 |

#### 详细情节

1. 入夜，下人房里别人都睡了。沈清躺在铺上，盯着房梁。
2. 她在心里算了一笔账：阿安的药钱每月一百八十文，一年二两一钱六分。侯府一个二等丫鬟的月银是五百文，一年六两。阿梨一年被扣掉三成多的月银，换来的只是弟弟"够活但不够好"的药。
3. 一两银子。按市价，一两银子值一千文。阿安一年的药钱，刚好二两多一点。一条命，二两银子。侯府一顿席面的零头。
4. 前世她死的时候，连一两银子的丧葬费都没有。
5. 她闭上眼。明天还要理灯油领单。灯油账里也许有空格，也许没有。但她已经知道怎么看账了：不是看数字，是看数字背后的人。

## 🎭 人物塑造

- **沈清**：从"看见数字"到"看见人命"。她不是在算账，是在算命。前世她只看见自己被算计，这一世她看见了每一个被算计的人。
- **阿梨**：二十文的缺口让她从"被牵制的棋子"变成"活生生的人"。她不是在抱怨，她是在用最后的力气撑住弟弟的命。
- **许管事**：只出场一瞬间，"明日把灯油领单也理了"——他不知道自己递给了沈清下一把钥匙。

## 📝 写作策略

### 开头策略
承接第013章沈清在账房外间理纸的日常，自然过渡到今天理月银扣项条。

### 中间策略
场景二是核心，阿梨的"二十文"必须让读者心碎。不煽情，用数字说话。

### 结尾策略
以"一两银子"的重量收束，不是愤怒，是冷静的决意。为后续破局积蓄力量。
