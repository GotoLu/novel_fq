# 《重生账房女，把侯府算到倾家荡产》全书大纲

## 一、全书主线

```text
沈清重生为侯府卖身丫头，主动入账房查前世害死自己的阴账。
她从一笔月银小账入手，撕开侯府内宅嫁妆、赈灾银、军需布料和朝堂贪腐链。
最终，她不只清算仇人，也夺回自由身、父亲清白和自己的人生选择权。
```

## 二、结构决策

| 决策项 | 结论 | 决策依据 |
|---|---|---|
| 全书结构 | 侯府内账逐层升级到朝堂外账的五卷结构 | 账线升级自然，能持续扩展案件、反派和人物代价 |
| 第一卷入口 | 低位入府、主动进账房、许管事小账反杀、损耗册暗记 | 能快速建立女主能力和项目差异化 |
| 长篇核心 | 每卷都有独立谜题、阶段敌人和清算目标 | 避免宅斗日常流水账 |

## 四、第一卷核心设计

第一卷主问题：

```text
沈清一个刚入府的卖身丫头，如何在不暴露重生秘密的情况下进入账房，并拿到第一份能撬动侯府的旧账证据？
```

第一卷阶段目标：

1. 活过入府前三日的下马威。
2. 不逃跑，反而主动争取账房差事。
3. 用小账问题击败许管事。
4. 让谢氏误以为她“聪明但可控”。
5. 找到秦妈妈手里的旧库房钥匙和半本损耗册。

第一卷爽点峰值：

```text
沈清当众揭穿许管事吞月银，却故意不把账算死，而是把更大的窟窿留给谢氏看，让谢氏亲自把她调进账房。
```

第一卷卷末反转：

```text
沈清以为自己拿到的是侯府采买损耗册，翻到最后才发现，册子里夹着一笔前世害死她的赈灾银暗记。
```
