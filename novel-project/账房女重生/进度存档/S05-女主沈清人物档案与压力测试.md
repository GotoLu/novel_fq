## 具体内容存档

### 女主档案

| 项目 | 设定 |
|---|---|
| 姓名 | 沈清 |
| 年龄 | 17 岁重生，前世死时 22 岁 |
| 身份 | 被卖入承恩侯府的低等丫头，后争取进入外账房 |
| 出身 | 寒门破落户之女，父亲曾是乡间账先生，因替人作保欠债，家破人散 |
| 外貌 | 清瘦、寡言、眼神极静，不是明艳型，是越看越冷、越看越锋利 |
| 核心能力 | 算账、记账、识契、辨假账、记忆力极强，能从银钱流向反推人心 |
| 前世死因 | 撞破侯府赈灾银亏空，被主母栽赃偷盗，乱棍打死 |
| 今生起点 | 重生回被牙婆卖入侯府当天 |
| 第一选择 | 不逃，主动进侯府账房 |

### 核心人物公式

```text
她最想要的不是活下去，而是让每一个把人命写成亏空的人，亲眼看见自己的富贵被清算。
```

### 外在目标

1. 活过前世死亡节点。
2. 找出侯府阴账完整链条。
3. 摆脱卖身契，恢复自由身。
4. 让害死她的人按罪付代价。
5. 查清父亲当年欠债破家的真相。

### 内在需求

```text
复仇不是把自己也变成一笔死账。
```

### 核心恐惧

| 恐惧 | 表现 |
|---|---|
| 再次被人栽赃 | 她极度重视证据，不轻易相信口头承诺 |
| 无权者说真话也没人信 | 她不急着告发，而是逼权贵互相作证 |
| 牵连无辜 | 每次设局前都会计算会不会害到底层下人 |
| 信任权贵 | 她对男主最初也只当可利用的“外部账路” |

### 性格特质

| 特质 | 正面表现 | 负面代价 |
|---|---|---|
| 冷静 | 危机中能快速算利害 | 容易显得不近人情 |
| 隐忍 | 能在羞辱中低头换机会 | 容易把痛苦吞成自毁 |
| 记仇 | 不忘每一笔恶债 | 容易被复仇牵着走 |
| 护短 | 对底层弱者有天然共情 | 会为救人打乱原计划 |
| 多疑 | 不轻信、不托底 | 与男主感情推进慢 |

### 错误决策倾向

```text
只要结果值得，她会把自己也算进代价里。
```

### 压力测试

| 压力类型 | 测试问题 | 沈清反应 | 戏剧价值 |
|---|---|---|---|
| 失去 | 若救一个无辜丫鬟会丢掉关键账本，她怎么选？ | 前期选账本，中期开始动摇，后期会设第三条路 | 推动人物成长 |
| 诱惑 | 若男主承诺替她报仇，只要她交出账册？ | 她拒绝，因为她不相信代替审判 | 强化主体性 |
| 误解 | 若她误判某个下人为侯府眼线？ | 会冷处理对方，造成关系裂痕 | 制造代价 |
| 羞辱 | 被主母当众掌嘴、骂贱婢 | 她低头认错，私下记下对方挪用嫁妆的证据 | 爽点蓄压 |
| 两难 | 证据能扳倒侯府，但会牵出父亲旧案污名 | 她先崩溃，再决定连父亲也查到底 | 增加厚度 |

### 人物弧光

```text
起点：把自己当一枚复仇用的铁算盘。
中段：发现账能算清银钱，却算不清人情、亏欠和活人的选择。
终点：她不只清算仇人，也夺回自己的人生账本。
```
