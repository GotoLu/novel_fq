## S13.3 黄金三章详细设计

### 第1章：重回卖身日

| 卡项 | 设计 |
|---|---|
| 开篇前 800 字任务 | 直接呈现异常与危机：沈清听见前世同一句卖身价，意识到自己重生到入侯府当天，卖身契即将按印 |
| 人物目标 | 确认时间点，保住清醒，不让刘牙婆看出异常 |
| 主要阻碍 | 她仍是无权无钱的卖身女，逃跑会立刻被抓回并失去入账房机会 |
| 冲突升级 | 她发现卖身契上有异常副印，说明父亲旧债不是普通欠债 |
| 代价后果 | 她主动放弃逃跑，选择回到前世被打死的侯府 |
| 局面变化 | 从被命运拖走，变成主动入局；卖身契成为第一件核心道具 |
| 章末追读 | 她为什么要把自己送回凶地？ |
| 场景空间 | 牙婆车、侯府偏门、卖身契案桌；空间狭窄，无法逃，只能观察 |
| 镜头顺序 | 先听见卖身价，再看见牙婆袖中契纸，最后看见侯府偏门 |
| 动作节拍 | 捏住袖口稳住颤抖、用余光看契印、故意低头避开牙婆试探 |
| 功能道具 | 卖身契承担身份枷锁、父案伏笔和终局脱籍伏笔 |
| 主导感官 | 听觉：价钱、车轮声、侯府门轴声与前世棍声重叠 |
| 作者情绪投注点 | 写出“她不是想活得轻松，而是宁愿再进死地也要把账算清”的冷痛 |

| 冲突升级 | 沈清若护阿梨会暴露锋芒，不护则会重演前世冷血选择 |
| 代价后果 | 她低头替阿梨认一半错，被周嬷嬷记名，换来阿梨活路 |

| 章末追读 | 她如何在不暴露能力的情况下接近账房？ |
| 场景空间 | 新丫鬟住处、偏院井边、规矩堂；众目睽睽，不能单独行动 |

### 第3章：第一笔脏账

| 卡项 | 设计 |
|---|---|
| 章节接力 | 兑现第2章“接近账房”：厨房采买差事把她送到许管事眼前 |
| 人物目标 | 找到账目异常，同时不让许管事知道她算出了全部 |
| 主要阻碍 | 许管事故意把损耗小账推给新丫鬟，想找替罪人 |
| 冲突升级 | 沈清看见月银和采买账同时缺口，若当场揭穿会被灭口 |
| 代价后果 | 她故意只说半句，暴露“会算账”，换来谢氏注意 |
| 局面变化 | 女主从普通新丫鬟变成账房风险人物；小账主线启动 |
| 章末追读 | 谢氏会赏识她，还是先处理她？ |
| 场景空间 | 厨房后廊、账房外间、采买桌；物件杂乱，方便藏证也方便栽赃 |
| 镜头顺序 | 先看肉案缺斤两，再看采买单空格，最后看许管事递来的笔 |
| 动作节拍 | 称肉、抹掉水渍、停笔、把账推回“主母可看”的范围 |
| 功能道具 | 采买单据、月银账册、账房笔 |
| 主导感官 | 嗅觉：厨房油腥味与账纸霉味，形成侯府体面背后的腐坏感 |
| 爽点链 | 压抑是被推黑锅；读者预判她会当场揭穿；反制是只露半手；回报是获得账房入口；余波是谢氏召见 |

## S13.6 原创性风险审查

检查范围：S13 第一卷 30 章分章大纲、黄金三章设计、章节接力卡、伏笔与资产落点。

对比依据：项目内 S5-S12 既有资产、类型惯例识别、桥段功能、信息顺序和场景调度。

### 风险分型

| 类型 | 等级 | 判断依据 | 处理建议 |
|---|---|---|---|
| 原文重合 | 低 | S13 为新生成大纲，没有沿用旧正文句段或对白 | 正文阶段仍需重写场景表达，避免模板化语言 |
| 近义改写 | 低 | 没有对既有正文做同义替换，主要是拆解项目设定 | 后续写黄金三章时必须重新组织镜头、动作和感官 |
| 桥段相似 | 中 | 卖身入府、嬷嬷立规矩、公开打脸属于古言宅斗常见桥段 | 用账目证据链、代价绑定和女主主动接黑锅来重构桥段骨架 |
| 类型惯例 | 低 | 重生、宅斗、账房查账、男主外线均属类型可用元素 | 保留类型入口，但持续强调“内账不能直接定罪” |

### 保留项

- 低位卖身身份、重生当天入府、主动争取账房。
- 月银账、采买账、旧钥匙、半本损耗册、赈灾银暗记。
- 阿梨、小石头、秦妈妈、许管事、谢氏、裴砚外线的第一卷功能。

### 重构项

- 周嬷嬷立规矩不能只写掌嘴下跪，必须转成卖身契、月银牌和下人互咬的空间压力。
- 许管事小账反杀不能只靠女主报数字，必须通过“主动接黑锅、逼对方补假账、公开见证”完成反制。
- 裴砚外线不能替女主解决问题，只能提供更大谜面和证据规则压力。

### 结论

项目内原创性风险为：中低风险，有条件通过。

是否允许进入下一阶段：允许进入 S14 黄金三章正文起草。

决策依据：S13 保留了类型入口，但核心推进依赖项目独有的账目证据链、女主身份限制、每笔账的人命代价和内外账互证规则，具备继续开发价值。
