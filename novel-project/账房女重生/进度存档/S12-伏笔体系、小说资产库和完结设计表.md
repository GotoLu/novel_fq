## S12.1 伏笔编号与状态规则

| 规则项 | 设定 |
|---|---|
| 编号格式 | `F-卷序-编号`，如 `F-V1-001` 表示第一卷核心伏笔 |
| 状态类型 | 待埋设、已埋设、强化中、误导中、待回收、已回收、留白、废弃 |
| 埋设原则 | 每个伏笔必须在当下场景制造压力、误导、情绪牵挂或资源变化 |
| 回收原则 | 核心伏笔必须有公开见证、人物代价和局面变化，不能只用解释性对白回收 |
| 审计周期 | 分章大纲阶段逐章标注；正文阶段每 10 章检查一次伏笔状态 |
| 废弃规则 | 伏笔若连续两卷无法服务主线，必须标注废弃原因，不能无声消失 |

## S12.4 完结设计表

| 字段 | 设计 |
|---|---|
| 主线偿付 | 沈清从侯府月银小账查到内外账合并，最终让承恩侯府和幕后权贵依法被清算，同时夺回自由身和父亲清白 |
| 人物归宿 | 沈清不再把自己算作复仇代价；裴砚完成从冷面证据执念到守护活人的成长；谢氏贤名破碎；陆怀章权力入口被封；陆承礼承担沉默代价；核心配角各自拿回一部分人生选择 |
| 情绪债清算 | 前世乱棍惨死、卖身契屈辱、阿梨等底层人的被克扣、父亲旧案、裴砚父案、侯府体面假象必须全部有公开回报 |
| 伏笔处理 | F-V1 至 F-V5 的主线伏笔必须回收；人物余味可留白，但证据链、父案、脱籍、侯府倒台不能留白 |
| 主题落点 | 真正的清算不是把仇人算死，而是不再允许任何人把活人写成账上的耗损 |
| 感情线落点 | 沈清与裴砚不是“被拯救”和“拯救者”，而是在内外账都清楚后并肩选择彼此 |
| 续作空间 | 可保留韩照升迁、顾明棠商号扩张、云娘绣坊女工互助、边地余案等外延，但不影响本书主线完整 |
| 烂尾风险 | 若只让皇权一句话定罪、若沈清未脱籍、若父案未翻、若陆怀章没有承担外账责任、若配角代价无回报，都会伤害读者信任 |
