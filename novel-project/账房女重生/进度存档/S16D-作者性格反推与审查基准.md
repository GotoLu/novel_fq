# S16D：作者性格反推与审查基准

日期：2026-06-11

来源：`.codex/skills/skill-chains/phase-3-author-persona.md`

## 一、审查目的

本存档用于从现有正文反推《重生账房女，把侯府算到倾家荡产》的作者性格，并作为后续章节的作者性格一致性审查基准。

本次不是重新设计作者声音，而是从已完成正文中提取已经稳定出现的叙述态度、观察方式、道德站位、幽默边界和句群偏好，避免后续章节出现“像换了作者”“像评估摘要”“只完成章节功能但没有项目气味”的问题。

## 二、取样范围与依据

| 样本 | 取样理由 | 主要证据 |
|---|---|---|
| 第001章《重回卖身日》 | 开篇章，奠定叙述站位和项目气味 | “侯府每一笔损耗，损的从不是银子，是人命”；偏门、卖身契、副印、门槛形成核心意象 |
| 第005章《规矩里的人命》 | 中段样本，集中呈现规矩压迫和底层代价 | “按例”“契后债”“饭食归损耗”把制度压迫落成具体账目 |
| 第008章《大理寺的旧案》 | 外线样本，检验男主线是否共享同一作者气质 | 残页、内耗、私押、内账入口与女主线的空格形成同构 |
| 第011章《假账要有人签》 | 最近章节，检验格式反杀和微爽点 | 领单印、签押、待核栏、月银牌构成公开对抗 |
| 第012章《主母看账》 | 最近章节，检验反派审美和压迫方式 | 谢氏的“干净账”理念把恶意写成体面规则 |
| 第013章《可用的棋子》 | 最近章节，检验边缘上位和道具线索 | 纸角空格规律、旧印木匣、碎瓷片形成后续审查基准 |

取样结论：当前正文的作者声音已经基本成形，核心不是单纯甜宠、单纯宅斗或单纯悬疑，而是“带着一种不肯放过的性格底色，反复追问被账目、格式、印位、纸角和规矩压平的人痛苦”。

## 三、作者性格核心

| 性格词 | 执行含义 | 文本依据 |
|---|---|---|
| 克制而记仇 | 不大喊复仇，不用情绪宣言替代行动；仇恨通过记账、留证、暂缓和反问推进 | 第001章沈清选择入府，不为轻松活命，而为翻旧账 |
| 疼底层人 | 情绪默认站在被扣饭、扣药、扣月银、被契纸勒住的人身边 | 第005章把少饭、泔水、契后债写成“人命代价” |
| 厌恶体面作恶 | 反派越温和、越规整、越讲规矩，越危险 | 第012章谢氏不咆哮，而是要求脏账有来处、有纸能对 |
| 偏执地不肯放过 | 作者性格里有一种持续追索的硬劲：不肯放过小数目、小委屈、小谎话、小空格，也不肯让任何代价被一句“按例”抹平 | 第001章追父债副印，第005章追饭食补扣和契后债，第011-013章追领单印、待核栏、纸角空格和碎瓷片 |
| 冷静中带锋利 | 句子常先冷静陈述，再用末句翻出道德判断或压迫本质 | 第001章“外头一笔光鲜，里头一笔亏空”；第013章“空格一齐，谎话也齐” |

## 四、叙述态度

作者看世界：世界不是天然讲理的，权力会把恶意包装成账面、规矩、体面和流程。真正可怕的不是明面上的打骂，而是让被害者连自己受害都只能被登记成“损耗”“补扣”“待核”的制度。

作者看主角：沈清不是开挂的全知复仇者，而是低位、受限、能忍、会算、知道自己每一步都会牵连旁人的人。她的强不在于立刻赢，而在于能在不能说破的情况下，把破绽留到别人不得不看见。

作者的偏执：这是性格底色，不只是对某类线索的兴趣。作者不相信“差不多”“按例”“小数目无伤大雅”，也不接受“人已经死了、事已经过去、规矩本来如此”。叙述会持续追问：谁被抹掉了，谁被迫认了，谁在装作没看见，谁把责任藏进一套体面说法里。账目、印位、空格和碎瓷只是这种偏执的外化工具；真正的偏执是对代价、责任和被消音者的不肯放过。这种偏执必须表现为证据耐心、道德追问和情绪韧性，不能写成主角无根据地疑神疑鬼。

作者看反派：反派不能写成只会尖叫的恶人。谢氏、许管事、周嬷嬷各有自己的规则和权力边界。作者最鄙视的不是粗暴，而是明知规矩吃人，还把规矩擦得更干净的人。

作者看普通人：普通人不是背景板。阿梨、小石头、春桃、小陈、韩照都要保留各自的怕、急、贫、谨慎和小动作。底层角色可以弱，但不能只是递线索的工具。

## 五、幽默刀口

允许笑：

| 刀口 | 使用方式 | 示例方向 |
|---|---|---|
| 权力话术的荒唐 | 用一句轻巧话拆穿规矩自撞 | “账房最怕的不是有人骂它黑，是有人当众问它有没有按自己的规矩写。” |
| 身份错位的轻微反差 | 让韩照等外线人物承担节奏缓冲 | 第008章韩照用贫嘴缓解旧案沉重感 |
| 程序严肃性的可笑 | 笑格式、名目、流程如何自以为无懈可击 | 领单印、签押、待核栏互相打架 |

禁止笑：

| 禁区 | 原因 |
|---|---|
| 不笑受害者贫穷、恐惧、病痛和无知 | 本书情绪站位保护底层人 |
| 不把阿梨、小石头、春桃等人的困境写成笨拙笑料 | 否则破坏“每笔账对应人命代价”的核心 |
| 不用现代吐槽口吻削弱古代压迫感 | 会破坏沉浸感和时代语境 |

## 六、同情对象、鄙视对象与迷恋对象

| 类型 | 内容 | 后续审查要求 |
|---|---|---|
| 同情对象 | 被契纸、月银牌、饭食补扣、药钱、旧债压住的人 | 每章至少让一个具体人承受账目后果，而不是只写数字游戏 |
| 鄙视对象 | 借规矩做脏事、借体面洗罪、借流程推责的人 | 反派压迫要通过可观察动作和制度话术呈现 |
| 复杂理解对象 | 周嬷嬷、小陈、韩照等处在规则内的人 | 不能把所有非主角角色写成单面恶人或单面好人 |
| 迷恋对象 | 卖身契、红印、月银牌、待核栏、纸角空格、残页、碎瓷片、旧钥匙 | 道具必须推动判断、关系、危险或追读，不能只做装饰 |
| 偏执对象 | 被轻轻带过的人命代价、被规矩抹掉的责任、被迫吞下的委屈、被改过的名目和旧纸流向 | 后续章节要让“看似太小、不值得追”的异常逐步长出大后果 |

## 七、句群偏好

1. 物件先行：常从纸、印、牌、格、碗、钥匙、门槛、木匣等可触摸物件切入。
2. 小额放大：三十文、一两银、半碗粥、一只缺口碗，都要写出背后的人命重量。
3. 偏执追问：对“按例”“待核”“损耗”“补扣”等词不轻易放过，也对沉默、避让、体面话、轻轻揭过的伤口不轻易放过；必须继续追到谁经手、谁签押、谁背锅、谁失去饭药自由。
4. 克制短句收束：关键判断常用短句落下，不用长篇抒情。
5. 对称句和反转句：常用“不是……是……”或“外头……里头……”把表象和本质并置。
6. 对白带试探：人物说话不能只交代信息，要同时测试对方边界。
7. 结尾不预告：章末钩子来自本章新增道具、格式或关系变化，不用“下一章将……”式提示。

## 八、禁用表达

| 禁用类型 | 禁用原因 | 替代方向 |
|---|---|---|
| 作者、读者、本章、后文、剧情、主线、伏笔、爽点、设定等元叙事词 | 破坏沉浸感和视角边界 | 改为人物当下能看见、听见、触碰或推理出的内容 |
| “她终于掌控全局”“真正的关键就在这里”等全知提示 | 提前替读者划重点 | 改为异常物件、未对齐格式、人物反应 |
| 空泛狠话，如“我要让他们付出代价”反复出现 | 会削弱沈清克制、会算、低位受限的特质 | 改成具体动作：留空格、对纸角、暂缓入牌、藏瓷片 |
| 无证据支撑的偏执发作 | 会把性格偏执误写成主角无脑猜忌或作者强行加戏 | 每次不肯放过必须落在可见异常、旧经验、格式矛盾、人物反应或情绪代价上 |
| 纯爽文化打脸口吻 | 本书爽点来自规矩自撞和证据反咬，不来自主角口头压倒 | 让见证者、格式和反派自己的规则完成打脸 |
| 把谢氏、许管事写成失控暴怒 | 破坏反派“体面作恶”的威胁 | 保持温和、压低、规整、可追责 |

## 九、落笔示例

以下样句为后续章节对齐作者气质使用，不直接要求原文复用：

1. 一两银子写在账上，不过三笔墨；落到阿安身上，就是三帖药和一夜退不下去的热。
2. 侯府不怕有人喊冤，怕的是有人把喊冤之前那张纸找出来。
3. 沈清没有拆穿那只碗，她只把碎瓷片放到数目旁边，让二十文自己长出缺口。
4. 谢令仪要的不是没有脏处的账，是脏处足够听话。
5. 空格留得越整齐，越像有人早知道谁该来填。
6. 沈清最怕的不是账少一笔，是所有人都觉得少这一笔不值得问。

## 十、作者性格一致性审查表

后续每章评估必须新增本项。

| 检查项 | 合格标准 | 不合格表现 |
|---|---|---|
| 观察方式 | 至少一个关键判断来自物件、格式、账目、空间压力或人物动作 | 主要靠旁白解释设计意图 |
| 道德站位 | 明确保护底层受害者，不拿受害者困境开玩笑 | 为爽点牺牲阿梨、小石头等人的基本尊严 |
| 反派气质 | 反派通过规矩、流程、体面话术施压 | 反派无脑发怒或直接自爆 |
| 句群气味 | 有克制短句、对称句或物件反转句体现项目声音 | 全章只有通顺叙述，没有辨识度 |
| 性格偏执 | 本章叙述要体现“不肯放过”的人格底色：不放过小数目，也不放过被压住的委屈、责任、沉默和体面谎言 | 只在某个线索上机械追查，缺少持续的人格压力 |
| 偏执落点 | 至少一个看似微小的数目、物件、格式异常、人物沉默或情绪伤口被追问到人命代价、权力责任或后续证据入口 | 偏执只停留在情绪怀疑，没有证据、责任或人物代价推进 |
| 视角边界 | 角色判断只来自当下证据和合理推理 | 用作者语气提前点破真相 |
| 追读钩子 | 章末由本章道具、格式或关系变化推出 | 用预告式、概念式悬念收尾 |

判定规则：

- 全部合格：作者性格一致性通过。
- 1-2 项轻微不足：有条件通过，下一章必须补强物件观察或句群气味。
- 任一项出现元叙事、全知提示、嘲笑受害者、反派脸谱化：最多有条件通过，必须先修正文再更新进度。
- 3 项以上不足：视为风格漂移，回到本存档重校准后再续写。

## 十一、风格漂移风险与修复方向

| 风险 | 触发场景 | 修复方向 |
|---|---|---|
| 过度说明书化 | 账目规则解释太多，人物动作太少 | 把规则压进对账动作、物件细节和见证者反应 |
| 过度压抑无回报 | 连续写底层受苦，但没有小赢或新入口 | 每 2-3 章给出可感知的暂缓、见证、证据或位置收益 |
| 偏执失焦 | 只写主角反复怀疑，缺少可见异常、情绪代价和证据积累 | 每次偏执追问必须落在物件、格式、数目、人物动作、沉默反应或具体代价上，并带来新信息 |
| 爽点口号化 | 主角直接说破、直接宣判、直接胜利 | 让反派自己的格式、签押、总册或朱笔反噬 |
| 男主线脱离本书气味 | 外线只写普通查案，不写账目同构 | 外线必须保留残页、私押、旧纸流向、证据转换限制 |
| 甜宠线冲淡主线 | 感情互动变成单独撒糖 | 情感必须绑定信任、证据保护、身份限制和代价 |

## 十二、质量验收结论

| 项目 | 结论 |
|---|---|
| 作者性格是否来自正文证据 | 通过。核心结论来自第001、005、008、011、012、013章样本，不是凭空重设 |
| 是否贴合题材和目标读者 | 通过。古言宅斗、重生复仇、经商搞钱与账目证据链高度绑定 |
| 是否能指导后续正文落笔 | 通过。已转化为观察方式、性格偏执、幽默刀口、句群偏好、禁用表达和审查表 |
| 是否存在风格漂移风险 | 有条件通过。主要风险是过度说明书化、偏执失焦、压抑过长和男主线普通查案化，已列出修复方向 |
| 是否通过沉浸感与视角边界要求 | 通过。本存档要求后续审查继续禁止元叙事、全知提示和预告式钩子 |

最终结论：作者性格定标通过，作为第014章及后续正文的作者性格一致性审查基准入库。

## 十三、后续执行要求

1. 第014章《一两银子的命》必须使用本基准，重点检查“一两银子”是否写成具体人命代价，而不是抽象账目。
2. 第014章章后质量检查必须新增“作者性格一致性审查”条目。
3. 若后续章节为了节奏临时提高甜宠、查案或爽文密度，必须记录偏离原因和回归方式。
4. 每 5 章小审时复核一次作者性格一致性，优先检查观察方式、性格偏执、道德站位和反派气质。
