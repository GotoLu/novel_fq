#### S11.1 世界观规则

| 规则项 | 设定 |
|---|---|
| 时空背景 | 轻架空王朝“大靖”，京城为主舞台，外部延展到灾区、边军和商路 |
| 权力结构 | 皇权、勋贵、六部、大理寺、地方官、皇商共同构成权力网络 |
| 主场势力 | 承恩侯府、大理寺、户部赈灾线、边军军需线、京城商号 |
| 阶层规则 | 奴籍、良籍、官籍区分严格；沈清入府初期受卖身契控制，证词可信度低 |
| 内宅规则 | 主母掌控人事、月银、库房、嫁妆和下人去留；内宅规矩可被反派包装成“合法压迫” |
| 证据规则 | 内宅账册只能提供线索，不能单独定罪；必须转化为人证、物证、官府案卷和外部账线 |
| 官府规则 | 裴砚不能凭私情立案；大理寺必须有案由、证据链和可追责对象 |
| 复仇规则 | 沈清不能直接揭发，必须让反派为了自保互咬，主动吐出证据 |
| 爽点规则 | 每次反击必须有压抑铺垫、账目证据、公开见证、即时回报和余波升级 |
| 代价规则 | 每一笔关键账都对应人命、名声、自由或关系损失，禁止只写数字游戏 |

#### S11.2 账目体系

| 账目类型 | 首次重点出现 | 功能 | 爽点用途 | 风险与代价 |
|---|---|---|---|---|
| 月银账 | 第一卷 | 揭示底层下人被克扣 | 女主用小账反杀许管事 | 暴露她会算账 |
| 采买账 | 第一卷 | 连接厨房、库房和管事贪墨 | 用斤两、单价和损耗打脸 | 牵连阿梨、小石头 |
| 库房损耗册 | 第一卷卷末 | 打开侯府旧账入口 | 秦妈妈交出旧钥匙和半本册子 | 引起谢氏警觉 |
| 嫁妆册 | 第二卷 | 揭示谢氏侵吞嫁妆和女眷财产 | 在寿宴或公开场合拆穿体面 | 女主被反咬偷盗 |
| 赈灾银账 | 第三卷 | 连接侯府与朝堂贪腐 | 发现前世死因真相 | 牵出陆怀章 |
| 军需布料账 | 第四卷 | 连接顾明棠商线和边军霉布 | 公开验布，击穿侯府外账 | 商线盟友承压 |
| 盐引皇商账 | 第五卷 | 指向幕后权贵和最终清算 | 内外账合并定罪 | 裴砚被朝堂围剿 |
| 债契与卖身契 | 全书贯穿 | 控制身份、父案和自由身 | 沈清夺回自己的人生账本 | 直接击中女主恐惧 |

账目升级路径：

```text
月银账
→ 采买账
→ 库房损耗册
→ 嫁妆册
→ 赈灾银账
→ 军需布料账
→ 盐引皇商账
→ 内外账合并清算
```

证据转化路径：

```text
内宅账目异常
→ 找到对应物件或人证
→ 逼反派为了自保补假账
→ 假账与外部账线冲突
→ 裴砚取得立案口径
→ 公开见证下完成清算
```

#### S11.3 类型引擎

| 类型机制 | 具体规则 | 在本书中的落点 |
|---|---|---|
| 古言宅斗引擎 | 规矩、名声、卖身契、嫁妆、人事调度制造压力 | 谢氏用体面和规矩压迫沈清 |
| 重生复仇引擎 | 前世记忆只提供方向，不提供万能答案 | 沈清知道死亡节点，但仍需重新取得证据 |
| 搞钱经商引擎 | 银钱流向必须改变人物处境 | 顾明棠、云娘推动货物、契书和商线 |
| 查案悬疑引擎 | 线索公平、误导合理、真相有边界 | 裴砚负责外案证据链，沈清负责内宅入口 |
| 爽文回报引擎 | 压抑、反制、公开见证、收益、余波升级缺一不可 | 每次查账反杀都必须带来更大危机 |
| 甜宠护短引擎 | 男主保护证据和退路，不替女主完成核心复仇 | 裴砚守外线，沈清破内局 |
