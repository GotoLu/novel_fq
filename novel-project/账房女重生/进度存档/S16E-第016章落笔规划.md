## 二、最优推进决策

第016章采用“钥匙齿痕 + 双锁登记 + 半门拖痕”的三重异常推进，而不是让沈清直接入库深处或取得损耗册。

决策依据：

1. 可行性：钥匙、锁、登记册和门槛痕都已由第015章自然引出，不需要新增突兀道具。
2. 效果：能明确回答“旧钥匙为何不交”，同时把追读转向“另一半门是谁锁上”。
3. 风险控制：不提前交出半本损耗册，避免透支第017章缺页规律和第026章秦妈妈交册的关键回收。
4. 一致性：符合 S16D 的物件先行、小处追问、克制锋利和不替角色提前点破真相。

## 四、场景调度卡

### 场景一：账房外间，补库房登记

| 字段 | 设计 |
|---|---|
| 场景空间 | 账房外间，许管事在帘内，小陈在案边补旧库房登记 |
| 镜头顺序 | 先看小陈虎口旧痕未消，再看新登记册上“西角旧库半扇启封”，最后看许管事递出补登记的旧铜钥匙拓印 |
| 动作节拍 | 小陈抄错“半扇”二字，许管事温声纠正；沈清借磨墨看见登记册上有旧锁、新锁两栏 |
| 功能道具 | 库房登记册、钥匙拓印、墨迹未干的“半扇启封” |
| 主导感官 | 墨味和铜锈味，形成账房与旧库房的连接 |

执行边界：本场景只给沈清看见登记矛盾，不让她掌握完整库房记录。

### 场景二：旧库房门前，秦妈妈试钥匙

| 字段 | 设计 |
|---|---|
| 场景空间 | 西角旧库房门前，门槛半边有拖痕，另一半干净，门上有旧锁眼和后加锁扣 |
| 镜头顺序 | 先看秦妈妈腰间钥匙磨痕，再看旧锁眼能转、后加锁扣不能开，最后看门只松半寸 |
| 动作节拍 | 秦妈妈不交钥匙，只当着沈清面转一下旧锁；门缝只开到半边拖痕处，随即被后加锁扣卡住 |
| 功能道具 | 旧钥匙、后加锁扣、半扇门槛痕 |
| 主导感官 | 铜钥匙入锁的涩声，强调“能开，但开不尽” |

执行边界：可以打开外半扇的锁声和门缝，但不能写沈清进入旧库深处，不能出现半本损耗册。

### 场景三：主院廊下，余波与新钩子

| 字段 | 设计 |
|---|---|
| 场景空间 | 旧库房回账房的廊下，阿梨端茶经过，小陈抱登记册跟随 |
| 镜头顺序 | 先看阿梨腕上红痕未褪，再看青比甲婆子催“夫人要看库房损耗”，最后看小陈把“新锁经手人”那一栏压住 |
| 动作节拍 | 阿梨借放茶盘提醒沈清别问太快；小陈下意识遮住登记册一角；沈清不追问，只记住栏名 |
| 功能道具 | 茶盘、登记册角、“新锁经手人”栏 |
| 主导感官 | 茶盘轻响与纸页摩擦声，压住人物不敢明说的风险 |

执行边界：阿梨和小陈保留余波压力，但不能变成主动解释真相的工具人。

## 六、正文硬边界

1. 不能直接拿到半本损耗册。
2. 不能让秦妈妈变成万能导师；她只能用动作、短句和拒绝留下可见异常。
3. 不能让沈清全知判断“谢氏锁了另一半门”；她只能判断“后加锁扣不归旧钥匙管，登记上另有经手栏”。
4. 不能让许管事失控暴怒；他继续用登记、补册、规矩压人。
5. 不能让第016章只重复观察小账，必须完成旧库房空间谜面升级。
