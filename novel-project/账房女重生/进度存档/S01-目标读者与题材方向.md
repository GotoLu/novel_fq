## 具体内容存档

### 初始项目定位

| 项目项 | 内容 |
|---|---|
| 目标平台 | 番茄小说 |
| 目标读者 | 女读者，偏好古代言情 |
| 核心题材 | 古代言情 |
| 推荐细分赛道 | 古言穿越/重生 + 宅斗/种田搞钱 + 甜宠/复仇逆袭 |
| 情绪承诺 | 女主受压开局，靠脑子、手段、资源经营翻身，同时获得稳定感情回报 |

### 目标读者画像

| 维度 | 定位 |
|---|---|
| 性别 | 女性 |
| 年龄层 | 18-40 岁为主 |
| 阅读偏好 | 古言、穿越、重生、宅斗、种田、甜宠、逆袭 |
| 情绪需求 | 替女主出气、看女主变强、看坏人付代价、看稳定偏爱 |
| 爽点需求 | 打脸、断亲、退婚、搞钱、护短、身份反转、仇人破防 |
| 雷点 | 女主长期憋屈、男主不坚定、误会拖太久、宅斗无回报、种田无升级 |
