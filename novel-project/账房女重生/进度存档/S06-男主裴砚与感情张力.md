## 具体内容存档

### 男主档案

| 项目 | 设定 |
|---|---|
| 姓名 | 裴砚 |
| 年龄 | 24 岁 |
| 身份 | 大理寺少卿，暗查赈灾银亏空案 |
| 外部形象 | 清贵冷淡、断案严苛、不近女色，京中称“铁面裴少卿” |
| 隐藏处境 | 他父亲曾因查赈灾银案获罪，裴家被贬多年，他回京是为翻案 |
| 核心能力 | 查案、审讯、官场博弈、证据链整合 |
| 核心限制 | 他能查朝堂，却进不了侯府内宅；没有内账，就无法坐实罪名 |
| 与女主绑定 | 沈清掌握内宅阴账，裴砚掌握外部法理和朝堂通道 |

### 核心人物公式

```text
他相信律法能清算罪恶，却发现律法必须先有人把证据从黑暗里活着送出来。
```

### 外在目标

1. 查清赈灾银亏空案。
2. 为父亲当年冤案翻案。
3. 找出承恩侯府与朝堂贪腐链的真实关系。
4. 保住沈清这条关键内线。
5. 在不破坏法理的前提下，让恶人真正伏罪。

### 错误决策倾向

```text
他以为只要证据足够，真相就会赢。
```

### 感情张力设计

| 阶段 | 关系状态 | 关键张力 |
|---|---|---|
| 初见 | 互相试探 | 裴砚怀疑沈清是侯府放出的假线；沈清怀疑裴砚只是想拿她当证人 |
| 前期 | 交易合作 | 她给线索，他给外部保护，但双方都留后手 |
| 中期 | 信任破裂 | 裴砚为保大案延迟救人，沈清认为他把人命排在证据之后 |
| 修复 | 共同付代价 | 裴砚为护沈清违抗上官，沈清为保他的证据链放弃一局私仇 |
| 后期 | 并肩清算 | 她查内账，他查外案；她撕开权贵体面，他让罪名落到实处 |
| 终局 | 情感偿付 | 裴砚不再只是给她庇护，而是承认她本身就是能与他并肩的人 |

### 甜宠方式

- 不说“我信你”，但会把她的证词按最高规格保存。
- 不当众暧昧，但会在她被诬陷时用官印压场。
- 不替她复仇，但会替她守住复仇所需的证据和退路。
- 不要求她放下仇恨，而是问她：“这一局，你想活着赢，还是只想赢？”

### 男主压力测试

| 压力类型 | 测试问题 | 裴砚反应 | 戏剧价值 |
|---|---|---|---|
| 失去 | 若沈清暴露，他必须在保她和保大案之间选择 | 前期犹豫，中期选案，后期找第三条路 | 制造信任裂痕 |
| 诱惑 | 上官承诺替父翻案，但要他放弃侯府线 | 拒绝，但会陷入更孤立处境 | 推动朝堂线 |
| 误解 | 他误以为沈清伪造账册 | 冷处理，险些害她失去关键机会 | 推动感情破冰 |
| 羞辱 | 被权贵讥为“罪臣之后” | 表面无波，私下加快查案 | 暴露旧伤 |
| 两难 | 干净证据不足，但恶人即将灭口 | 他必须突破程序惯性，先救人再补证 | 完成人物成长 |
