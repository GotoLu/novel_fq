| 检查项 | 判断 |

| 主角是否有强欲望 | 通过：复仇、脱籍、查父案、夺回人生 |
| 主角是否有弱点 | 通过：多疑、自毁式计算、复仇执念 |

| 反派是否主动压迫 | 通过：谢氏遮账，陆怀章切割责任，陆承礼制造误判 |

| 是否存在长篇风险 | 有：人物较多，需用资产库和轮转表防止散线 |
