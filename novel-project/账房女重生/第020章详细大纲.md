1. 矛盾账在谢氏面前引爆——沈清不揭发，让谢氏自己发现
2. 击穿许管事月银/采买小账——许管事被剥夺采买权

## 📝 详细场景设计

### 场景一：送账（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清把矛盾账送进谢氏视线，但不揭发 |
| **情绪曲线** | 紧张→冷静 |
| **出场人物** | 沈清、阿梨 |
| **场景时长** | 清晨 |

#### 详细情节
1. 清晨，账房外间。沈清整理月底送审的账册。按规矩，损耗单和采买单要分批送审。但这个月，她把旧库房的损耗单和采买单放在了同一批。
2. 两张单子挨在一起。损耗单上三斤烘耗，许管事核销章。采买单上六斤灯油九十文，许管事经手印。同一笔灯油，两条账路，两枚小印。
3. 阿梨来传话："沈姐姐，主院那边催月底账册，说今天就要。"
4. 沈清把账册封好，递给阿梨。"帮我送到主院。损耗单和采买单放在最上面，主母翻起来方便。"
5. 阿梨接过账册，跑了。
6. 沈清看着她跑远。她没有揭发许管事。她只是把两笔账放在了谢氏面前。谢氏自己会看。

#### 人物心理
- 沈清：退一步。不指控，不揭发，只让账册说话。谢氏的"干净账"理念不允许同一笔开支出现在两个地方。她不需要指控许管事，账册自己会指控。

### 场景二：谢氏看账（900字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 谢氏自己发现矛盾账，击穿许管事小账 |
| **情绪曲线** | 平静→发现→冷怒→决断 |
| **出场人物** | 谢氏、许管事 |
| **场景时长** | 上午 |

#### 详细情节
1. 主院正堂。谢氏翻看月底账册。她翻得很快，月银总册、内库出入、西库盘点，一笔一笔过。
2. 翻到旧库房。损耗单：灯油三斤烘耗，许管事核销章。采买单：灯油六斤，单价十五文，合计九十文，许管事经手印。
3. 谢氏的手指停了。
4. 她把两张单子并排放在桌上。损耗单认了三斤烘耗，采买单补了六斤采购。同一笔灯油，走了两条账路。
5. 谢氏没有发怒。她把两张单子翻过来，看背面的签押。损耗单核销栏：许管事章。采买单经手栏：许管事章。两枚小印，同一笔灯油。
6. "叫许管事来。"
7. 许管事进正堂时还带着笑。他以为月底对账，例行公事。
8. 谢氏把两张单子推到他面前。"许管事，旧库房的灯油，是烘耗了三斤，还是采购了六斤？"
9. 许管事低头看单子。他的笑停了。
10. "这……旧库房灯油用量大，损耗和采购是两笔账……"
11. "同一笔灯油。"谢氏的声音不大，但每个字都清楚，"损耗单上认了三斤烘耗，采买单上又补了六斤采购。三斤加六斤，九斤灯油。但旧库房每月只领九斤。许管事，这九斤灯油，是烘耗了，还是采购了？"
12. 许管事张了张嘴。他看了一眼两枚小印。红印泥已经干了，但印迹清晰。
13. "如果烘耗了三斤，就不应该再在采买单上补六斤。如果采购了六斤，就不应该有烘耗。两条账路不能同时走，许管事。"
14. 许管事的额头冒出细汗。"主母，这是底下人填单子时弄混了……"
15. "弄混了？"谢氏拿起采买单，"这上面的经手印是许管事的。损耗单上的核销章也是许管事的。两笔账都是许管事经手，怎么会弄混？"
16. 许管事说不出话。
17. 谢氏把两张单子收起来。"旧库房的采买账，从今天起不由许管事经手。采买单的审核权交回主院。"
18. 她顿了一下。"月底矿山那边要的人，也先停一停。账目不清，人不能往外送。"

#### 对话设计
- 谢氏："许管事，旧库房的灯油，是烘耗了三斤，还是采购了六斤？"
- 许管事："这……旧库房灯油用量大，损耗和采购是两笔账……"
- 谢氏："同一笔灯油。损耗单上认了三斤烘耗，采买单上又补了六斤采购。三斤加六斤，九斤灯油。但旧库房每月只领九斤。许管事，这九斤灯油，是烘耗了，还是采购了？"
- 谢氏："如果烘耗了三斤，就不应该再在采买单上补六斤。如果采购了六斤，就不应该有烘耗。两条账路不能同时走，许管事。"
- 许管事："主母，这是底下人填单子时弄混了……"
- 谢氏："弄混了？这上面的经手印是许管事的。损耗单上的核销章也是许管事的。两笔账都是许管事经手，怎么会弄混？"

#### 人物心理
- 谢氏：不是愤怒，是冷。她的"干净账"理念不允许同一笔开支出现在两个地方。这不是钱的问题，是规矩的问题。许管事坏了规矩。
- 许管事：被两枚小印钉死了。他以为补上空格就能对上账，没想到同一笔灯油走了两条路。

### 场景三：小石头（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 小石头因账目审查暂缓矿山名单而获救 |
| **情绪曲线** | 紧张→释然→沉重 |
| **出场人物** | 沈清、小石头 |
| **场景时长** | 午后 |

#### 详细情节
1. 午后，后院墙根。小石头跑过来，脸上带着不敢相信的表情。
2. "沈姐姐！名单停了！管事说账目不清，矿山那边的人先不送了！"
3. 沈清松了一口气。但她没有笑。
4. "停了，不是取消了。"沈清说，"账目查清楚之后，名单可能还会再定。"
5. 小石头的笑也收了。他蹲在墙根，想了想。"那……我还有多少时间？"
6. "不知道。"沈清说实话，"但至少不是后天了。"
7. 小石头点了点头。"够了。"他站起来，"沈姐姐，我帮你盯着旧库房。谁进去谁出来，我都记着。"
8. 沈清看着他跑走。小石头获救了，但只是暂时的。账目审查结束之后呢？她需要更永久的办法。
9. 但至少不是后天了。

#### 对话设计
- 小石头："沈姐姐！名单停了！管事说账目不清，矿山那边的人先不送了！"
- 沈清："停了，不是取消了。账目查清楚之后，名单可能还会再定。"
- 小石头："那……我还有多少时间？"
- 沈清："不知道。但至少不是后天了。"
- 小石头："够了。沈姐姐，我帮你盯着旧库房。谁进去谁出来，我都记着。"

#### 人物心理
- 沈清：小石头获救是账目审查的副产品，不是她的直接行动。人被账救了，不是被人救了。这既是胜利，也是残酷。

### 场景四：进账房（600字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 谢氏调沈清进账房，胜利的代价是更深的掌控 |
| **情绪曲线** | 紧张→确认→暗寒 |
| **出场人物** | 谢氏、沈清 |
| **场景时长** | 傍晚 |

#### 详细情节
1. 傍晚，主院偏厅。谢氏叫沈清来。
2. 沈清进门时，谢氏正在翻看旧库房的账册。桌上摊着损耗单和采买单，旁边还有灯油领单。三张单子排在一起。
3. "旧库房的账，是你理的？"
4. "是。"沈清低头。
5. 谢氏看了她一会儿。"损耗单和采买单放在同一批送审，也是你安排的？"
6. 沈清的心跳快了一拍。谢氏看出来了。
7. "是。月底送审，损耗单和采买单按规矩分批。但旧库房的账这个月有变动，我放在一起方便主母核对。"
8. 谢氏没有追问。她把账册合上。
9. "从明天起，你进内间做事。采买单的审核，你先看着。"
10. 沈清抬头。进内间。采买单审核。这是账房的核心位置。
11. "谢主母。"
12. 谢氏站起来，走到沈清面前。她的目光很平静，但沈清觉得那目光比许管事的锐利更冷。
13. "沈清，你算得清楚。但算得清楚的人，要守的规矩也更多。"
14. "是。"
15. "账房的内间，我能让你进去，也能让你出来。记住了？"
16. 沈清低头。"记住了。"
17. 她退出了偏厅。外面天快黑了。
18. 她赢了。许管事的采买权被收回，小石头暂时安全，她进了账房内间。但她也输了。谢氏知道她"算得清楚"，也知道她"故意把两笔账放在一起"。谢氏用她，但也盯她。
19. 进了内间，就进了谢氏的视线。每一步都在谢氏的眼皮底下。

#### 对话设计
- 谢氏："旧库房的账，是你理的？"
- 沈清："是。"
- 谢氏："损耗单和采买单放在同一批送审，也是你安排的？"
- 沈清："是。月底送审，损耗单和采买单按规矩分批。但旧库房的账这个月有变动，我放在一起方便主母核对。"
- 谢氏："从明天起，你进内间做事。采买单的审核，你先看着。"
- 谢氏："沈清，你算得清楚。但算得清楚的人，要守的规矩也更多。"
- 谢氏："账房的内间，我能让你进去，也能让你出来。记住了？"

#### 人物心理
- 谢氏：这个丫头算得清楚，也懂得"退一步"。她没有直接揭发许管事，而是把账册放在我面前让我自己看。聪明，但太聪明了。聪明人要用，但也要盯。
- 沈清：谢氏看出来了。她知道我故意把两笔账放在一起。但她没有追究，反而调我进内间。这是奖赏，也是笼子。

### 场景五：代价（400字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清反思胜利代价，为下一阶段铺垫 |
| **情绪曲线** | 释然→沉重→决心 |
| **出场人物** | 沈清 |
| **场景时长** | 入夜 |

#### 详细情节
1. 入夜，下人房。沈清躺在铺上，把今天的事过了一遍。
2. 许管事的采买权被收回。小石头暂时安全。她进了账房内间。
3. 但许管事没有被赶走。谢氏只收了他的采买权，没有动他的人。许管事还在账房，还在内间，还管着月银和损耗。他只是少了一块地盘。
4. 而她进了内间，就在许管事旁边。一个被收了权的人，和一个被调进来的人，面对面坐在同一张桌子前。
5. 小石头暂时安全，但"停了"不是"取消了"。账目审查结束之后，名单还会再定。她需要更永久的办法。
6. 她赢了这一局。但这一局的代价是：谢氏的眼睛。
7. 从明天起，她每看一笔账，每翻一页纸，都在谢氏的视线里。
8. 沈清闭上眼。没关系。账房内间有她要的东西。旧库房的完整账册，月银总册的底本，采买单的原始存根。这些东西在外间看不到，但在内间，它们就在许管事的抽屉里。
9. 她退了一步，进了内间。

#### 人物心理
- 沈清：退一步不是退缩，是换一个位置。外间看得到采买单的空格，但看不到空格背后的全貌。内间能看到更多。代价是谢氏的视线，但只要她算得够清楚，谢氏的视线也是她的保护。

## 🎭 人物塑造

### 沈清
- **策略执行**："退一步"——不揭发，只让账册说话
- **胜利代价**：进了内间但进了谢氏的视线
- **长远眼光**：退一步不是退缩，是换位置

### 谢氏
- **干净账理念**：不允许同一笔开支出现在两个地方
- **用人手段**：用沈清但盯沈清，"我能让你进去，也能让你出来"
- **权谋水平**：看出沈清"故意把两笔账放在一起"，但不点破

### 许管事
- **被钉死**：两枚小印成铁证，无法辩解
- **未灭**：只被收采买权，人还在账房
- **隐患**：和沈清面对面坐内间，必有反扑

### 小石头
- **暂时获救**：因账目审查暂缓矿山名单
- **主动回报**："我帮你盯着旧库房"
- **危机未解**："停了不是取消了"

## 📝 写作策略

### 开头策略
承接第019章矛盾账和后天期限，直接进入沈清送账场景。时间紧迫，节奏要快。

### 中间策略
场景二是高潮：谢氏看账发现矛盾。关键是谢氏的冷怒——不是暴怒，是冷。她不吼，不摔东西，只是把两张单子并排，一个字一个字地问。这种冷比暴怒更可怕。

场景四是第二高潮：谢氏调沈清进内间。关键是谢氏看穿了沈清的"退一步"——她知道沈清故意把两笔账放在一起，但她不点破，反而用这个来掌控沈清。

### 结尾策略
场景五反思代价。章末"她退了一步，进了内间"——退一步不是退缩，是换位置。这句话既是本章总结，也是下一阶段的起点。
