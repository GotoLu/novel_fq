# 《重生账房女，把侯府算到倾家荡产》世界观与账目规则

## 一、世界观定位

| 项目 | 设定 |
|---|---|
| 时空背景 | 轻架空王朝“大靖”，主舞台为京城 |
| 主场势力 | 承恩侯府、大理寺、户部赈灾线、边军军需线、京城商号 |
| 类型基底 | 古言宅斗、重生复仇、账房查案、经商搞钱、权臣甜宠 |
| 复杂度原则 | 低复杂度世界观，高密度冲突规则 |

决策依据：本书卖点在“账目证据链”和“低位女主反杀”，不是重权谋设定。世界观应服务身份限制、证据限制和账目升级。

## 二、核心规则

| 规则项 | 设定 | 写作作用 |
|---|---|---|
| 阶层规则 | 奴籍、良籍、官籍区分严格；沈清入府初期受卖身契控制 | 限制女主不能直接告官 |
| 内宅规则 | 主母掌控人事、月银、库房、嫁妆和下人去留 | 让谢氏能用“规矩”合法压迫 |
| 证据规则 | 内宅账册只能提供线索，不能单独定罪 | 避免账册一出就解决案件 |
| 官府规则 | 裴砚必须有案由、证据链和可追责对象 | 限制男主开挂 |
| 复仇规则 | 沈清必须逼反派为了自保互咬，主动吐出证据 | 让反击有设计感 |
| 爽点规则 | 压抑、账目证据、公开见证、即时回报、余波升级缺一不可 | 保证爽点不空 |
| 代价规则 | 每一笔关键账都对应人命、名声、自由或关系损失 | 强化项目差异化 |

## 三、账目体系

| 账目类型 | 首次重点出现 | 功能 | 爽点用途 | 风险与代价 |
|---|---|---|---|---|
| 月银账 | 第一卷 | 揭示底层下人被克扣 | 小账反杀许管事 | 暴露沈清会算账 |
| 采买账 | 第一卷 | 连接厨房、库房和管事贪墨 | 用斤两、单价和损耗打脸 | 牵连阿梨、小石头 |
| 库房损耗册 | 第一卷卷末 | 打开侯府旧账入口 | 秦妈妈交出旧钥匙和半本册子 | 引起谢氏警觉 |
| 嫁妆册 | 第二卷 | 揭示谢氏侵吞女眷财产 | 寿宴或公开场合拆穿体面 | 女主被反咬偷盗 |
| 赈灾银账 | 第三卷 | 连接侯府与朝堂贪腐 | 揭开前世死因外层真相 | 牵出陆怀章 |
| 军需布料账 | 第四卷 | 连接顾明棠商线和边军霉布 | 公开验布，击穿侯府外账 | 商线盟友承压 |
| 盐引皇商账 | 第五卷 | 指向幕后权贵和最终清算 | 内外账合并定罪 | 裴砚被朝堂围剿 |
| 债契与卖身契 | 全书贯穿 | 控制身份、父案和自由身 | 沈清夺回自己的人生账本 | 击中女主恐惧 |

## 四、账目升级路径

```text
月银账

→ 嫁妆册
→ 赈灾银账
→ 军需布料账
→ 盐引皇商账
→ 内外账合并清算
```

## 五、证据转化路径

```text
内宅账目异常
→ 找到对应物件或人证
→ 逼反派为了自保补假账
→ 假账与外部账线冲突
→ 裴砚取得立案口径
→ 公开见证下完成清算
```

## 六、账目格式规则

| 格式项 | 规则 | 写作用途 |
|---|---|---|
| 领单印 | 只证明某人经手、领纸或领单，不等同于认账或核账 | 第10章钉住沈清风险，第11章用格式漏洞暂缓扣项 |
| 签押 | 证明有资格的人核准账目，低等丫鬟不能让假账变成真账 | 将责任从沈清推回许管事、谢氏等有权者 |
| 待核栏 | 未核账目不得直接进入月银总册，只能暂挂外册或待核项 | 给女主争取时间，也留下许管事补假账痕迹 |
| 月银总册 | 扣项需有事由、核字、签押或管事认可，周嬷嬷月银牌才可落扣 | 保证月银小账反杀有公开见证和规矩冲突 |
| 主母朱批 | 主母可用朱笔暂缓、改口径或要求复核，但不直接清除账目问题 | 证明谢氏不是不知情，而是把脏账调成可追责、可切割的干净账 |

决策依据：第011章确立“领单不等于签押”的格式边界，既保住沈清不被一枚领单印直接钉死，也让后续第12-20章能把假账责任逐步推回真正有资格签账的人。
第012章进一步确立“干净账”理念：谢氏不否认脏处，而是要求脏处有来处、有人可答、有纸可对。后续写谢氏时，重点不是失控作恶，而是体面地合法化压迫。

## 七、类型引擎

| 类型机制 | 具体规则 | 本书落点 |
|---|---|---|
| 古言宅斗 | 规矩、名声、卖身契、嫁妆、人事调度制造压力 | 谢氏用体面和规矩压沈清 |
| 重生复仇 | 前世记忆只提供方向，不提供万能答案 | 沈清知道死亡节点，但仍要重新取证 |
| 搞钱经商 | 银钱流向必须改变人物处境 | 顾明棠、云娘推动货物、契书和商线 |
| 查案悬疑 | 线索公平、误导合理、真相有边界 | 裴砚管外案，沈清管内宅入口 |
| 爽文回报 | 压抑、反制、见证、收益、余波升级 | 每次查账反杀都带来更大危机 |
| 甜宠护短 | 男主保护证据和退路，不替女主复仇 | 裴砚守外线，沈清破内局 |

## 八、禁止破坏

- 不能让沈清绕过身份限制直接告官成功。
- 不能让裴砚进入内宅替沈清解决核心问题。
- 不能让账目变成大段背景说明。
- 不能让“侯府阴账”只等于几笔银子，必须写出人命代价。
- 不能建立过重权谋，导致女主账房能力被稀释。
