## 📝 详细场景设计

### 场景一：账房外间的门槛（约500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 身份转换的物理呈现，许管事给沈清立规矩 |
| **情绪曲线** | 紧张→压抑 |
| **出场人物** | 沈清、许管事、小陈 |
| **场景时长** | 辰时初 |

#### 详细情节
1. 沈清清晨去账房报到。许管事没有让她进内间，只指了外间角落一张矮桌，上面堆着半人高的旧单据
2. 许管事当面立规矩：只许整理待核小账，不许翻看内间册子，不许问单据来历，每日申时交誊清稿
3. 小陈被安排"照看"沈清，实为监视
4. 许管事临走前留下一句话："谢夫人赏你差事，不是赏你脑袋。"

#### 对话设计
- 许管事："外间这些纸，你按日期理出来，能看清的誊一遍，看不清的搁一边。只许看，不许问。"
- 沈清低头应"是"
- 许管事对小陈："她翻内间的纸，你告诉我。"

#### 环境描写
- 账房外间比内间矮半截，窗户小，光从门帘缝里漏进来
- 矮桌是旧门板搭的，桌腿下垫着碎砖
- 旧单据有霉味，边角发黄卷曲

#### 人物心理
- 沈清：知道这是许管事给她的下马威，但也是她等了十二天的入口
- 许管事：不信任但暂时无法拒绝谢氏的安排，用规矩困住沈清

### 场景二：旧纸里的空格（约900字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 核心发现——采买单空格规律，边缘位置转化为明确收益 |
| **情绪曲线** | 专注→发现→克制兴奋 |
| **出场人物** | 沈清、小陈 |
| **场景时长** | 辰时至午时 |

#### 详细情节
1. 沈清开始整理待核小账。旧单据杂乱，有厨房采买单、月银扣项条、灯油领单、杂耗记录
2. 她先按日期分，再按类目分。过程中发现：厨房采买单每月都有一笔"猪肉三斤"的空格——品名写了，数量写了，单价写了，但总价那栏是空的
3. 不是一笔。是连续三个月，每月同一笔"猪肉三斤"，总价栏都空着
4. 沈清心算：三斤猪肉，按市价约九十文。三个月就是二百七十文。空格不是遗漏，是故意留的——总价不填，入总册时就能填别的数
5. 她不敢当场记下来。把那三张采买单按日期夹回原处，只在心里默记了月份和品目
6. 小陈偶尔抬头看她，她始终低头理纸，手指平稳，像真的只是在做杂活

#### 对话设计
- 小陈（试探）："你从前真在牙行待过？这纸理得倒快。"
- 沈清（低头）："牙行也理契纸，都是按日子排。"
- 小陈不再说话，但目光比早上松了一点

#### 环境描写
- 日头升高，光从窗户移到矮桌一角，照见旧纸上的虫蛀小洞
- 沈清把纸翻过来时，背面有前人写的墨痕，像被刮过又重写

#### 人物心理
- 沈清：发现空格规律时心跳加快，但立刻压住。前世她在账房待了三年才注意到这个规律，这一世只用了一个上午。不是她更聪明，是她知道该看哪里
- 小陈：对沈清的警惕从"监视"慢慢变成"观察"

#### 伏笔处理
| 伏笔ID | 类型 | 内容 | 说明 |
|--------|------|------|------|
| F-V1-002 | 延续强化 | 采买单空格规律（三斤猪肉总价空格连续三月） | 与第006章"厨房少了三斤肉"呼应，从"厨房视角"转到"账面视角" |
| 采买单空格 | 埋设 | 总价栏空格是许管事补假账的入口 | 为第019章"采买单上的空格"铺垫 |

### 场景三：阿梨传茶（约500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 阿梨暗线推进，展现谢氏牵制的压力 |
| **情绪曲线** | 担忧→无力→坚定 |
| **出场人物** | 沈清、阿梨 |
| **场景时长** | 午时 |

#### 详细情节
1. 午饭时沈清在廊下碰到阿梨。阿梨穿着主院丫鬟的围裙，比平时干净，但脸色不好
2. 阿梨低声说：主院规矩更严，传茶时不能抬头看人，走路的步数都有人教。谢氏身边的婆子问她认不认识沈清，她说"同日进府的"
3. 阿梨没有抱怨，只说："沈姐姐，你好好理账。我弟弟的药钱……"
4. 沈清说："三日之内会有结果。"她不确定，但她必须说
5. 阿梨点头走了。她的背影比进主院前更瘦了一点

#### 对话设计
- 阿梨："主院的婆子问我，你平时都做什么。我说你帮我记过汤钱。"
- 沈清心里一紧，面上不动："你怎么说的？"
- 阿梨："我说你只帮我问过一句，别的不知道。"
- 沈清："好。以后谁问，都这么说。"

#### 人物心理
- 沈清：阿梨在主院每待一天，谢氏对她的牵制就紧一分。阿梨不是人质，但比人质更管用——因为沈清在乎
- 阿梨：害怕但信任沈清，把弟弟的药钱寄托在沈清身上

### 场景四：第一份誊清稿（约600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清展示能力但不越界，许管事重新评估她 |
| **情绪曲线** | 谨慎→微松→暗涌 |
| **出场人物** | 沈清、许管事 |
| **场景时长** | 申时 |

#### 详细情节
1. 申时，沈清把整理好的待核小账誊清稿交给许管事。她只誊了日期、品目和待核状态，没有写自己的判断
2. 许管事翻看，发现她把杂乱的单据按日期和类目理得清清楚楚，连破损的旧单都标了"残"字
3. 许管事沉默片刻，问："你理纸的时候，有没有看见什么不该看的？"
4. 沈清："奴婢只认得日期和品目。有些字不认识，没敢多看。"
5. 许管事盯着她看了几息，最终说："明日继续。"
6. 沈清退出账房时，在廊下站了一息。她知道许管事在身后看着她。她没有回头，脚步平稳地走回下人房

#### 对话设计
- 许管事（翻看誊清稿）："字倒写得齐整。"
- 沈清："牙行先生教的，只求清楚。"
- 许管事："看见什么了？"
- 沈清（低头）："纸旧，有些字看不清。奴婢只按日子排了。"
- 许管事（停顿）："……明日继续。"

#### 环境描写
- 申时的光已经偏黄，账房内间点了一盏油灯
- 许管事的影子投在墙上，比白天长了一倍

#### 人物心理
- 沈清：她必须让许管事觉得她"有用但无害"。太聪明会被灭口，太蠢会被赶走
- 许管事：开始重新评估沈清——她可能比预想的更危险，但谢氏的人不能随便动

## 📝 写作策略
### 开头策略
从沈清踏入账房外间的物理动作开始，用空间描写呈现身份转换。承接第012章谢氏的安排，但不重复第012章内容。

### 中间策略
场景二是核心，重点写沈清发现空格规律的过程。不要直接写"她发现了规律"，而是通过她整理纸时的细节——翻纸、停顿、心算、克制——让读者跟着她一起发现。

### 结尾策略
以许管事的试探和沈清的伪装收尾，留下"她能撑多久"的悬念。同时用阿梨的处境作为情感暗线，让读者既关心账目真相也关心人物命运。
