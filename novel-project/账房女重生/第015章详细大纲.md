## 📝 详细场景设计

### 场景一：灯油领单里的库房名（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 承接第014章许管事安排的灯油领单差事，发现库房损耗异常，建立找秦妈妈的动机 |
| **情绪曲线** | 日常→发现异常→警觉 |
| **出场人物** | 沈清、小陈 |
| **场景时长** | 约半个时辰 |

#### 详细情节
1. 沈清在账房外间理灯油领单。灯油领单比采买单和月银条都简单：日期、领油量、领用人、库房签收。但有一栏她没见过——"损耗归处"。
2. 大部分领单的"损耗归处"写的是"内院各房"，少数写"账房自用"。但有三张连着写的是"旧库房"。
3. 旧库房。不是"内库"或"西库"，是"旧库房"。沈清翻遍所有领单，只有这三张出现这个名字，而且日期集中在去年冬天。
4. 她注意到这三张领单的领油量异常大——是普通领单的三倍，但签收栏只有一个模糊的"秦"字。
5. 小陈路过看了一眼："秦妈妈签的。她管旧库房，不常出来。"

#### 对话设计
- 小陈（随口）："秦妈妈签的。她管旧库房，不常出来。"
- 沈清（克制）："旧库房在哪儿？"
- 小陈："后院西北角，挨着柴房。你别去，她脾气不好，见人就赶。"

#### 环境描写
- 账房外间清晨，日光刚过窗沿
- 灯油领单纸色发黄，比采买单更薄，油渍渗透纸背
- 三张"旧库房"领单的墨色比其他深，像是同一天写的

#### 人物心理
- 沈清：灯油领单是新入口，"旧库房"三个字让她警觉——许管事的小账在采买单和月银条里，旧库房是另一条线
- 小陈：随口提秦妈妈，没有警觉，只是怕她脾气

### 场景二：小石头引路（600字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清不能直接找到秦妈妈，通过小石头引路，同时推进阿安药断后续 |
| **情绪曲线** | 焦虑→决定→行动 |
| **出场人物** | 沈清、小石头 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 午时廊下吃饭，沈清看见小石头蹲在墙角啃冷馒头。她走过去，小石头立刻站起来。
2. 沈清先问阿安的情况——小石头和安济坊的人有来往，比阿梨消息更快。小石头说阿安昨天咳了一夜，今天没吃药，但还没死。
3. 沈清问旧库房怎么走。小石头脸色变了，压低声音说："你找秦妈妈？她不见人。上次周嬷嬷派人去盘点，被她拿扫帚赶出来了。"
4. 沈清不问为什么，只问路。小石头犹豫了一下，说后院西北角有条小路，从柴房后面绕过去，比走正门近。
5. 小石头临走时说了一句："秦妈妈不是坏人，但她怕。怕什么我不知道。"

#### 对话设计
- 小石头："你找秦妈妈？她不见人。上次周嬷嬷派人去盘点，被她拿扫帚赶出来了。"
- 沈清："我只问路。"
- 小石头（犹豫后）："后院西北角，从柴房后面绕。比走正门近。"
- 小石头（临走）："秦妈妈不是坏人，但她怕。怕什么我不知道。"

#### 环境描写
- 廊下午时，日头正烈，墙角有阴凉
- 小石头的冷馒头掰了一半藏在袖子里，另一半还没啃完
- 远处厨房传来洗碗声

#### 人物心理
- 沈清：阿安药断让她焦虑，但她不能直接给药钱——给了就是暴露。必须先找到旧账入口，从根上解决问题
- 小石头：怕秦妈妈，但更怕沈清出事。他说"她怕"时，自己也怕

### 场景三：旧库房门前（900字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 秦妈妈首次出场，沈清试探旧库房线，碰壁但留下伏笔 |
| **情绪曲线** | 紧张→试探→碰壁→隐约触动 |
| **出场人物** | 沈清、秦妈妈 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 沈清按小石头说的路绕到旧库房后面。旧库房比她想象的大，青砖墙，木门半旧，门上挂着一把铁锁。锁不是新的，但擦得很干净——有人天天摸这把锁。
2. 门旁有一间矮屋，烟囱冒着细烟。沈清走过去，门开了。
3. 秦妈妈站在门口。五十多岁，头发花白但梳得整齐，腰板直，眼睛不大但看人很准。她手里拿着一把扫帚，像随时准备赶人。
4. 秦妈妈先开口："账房的人？"
5. 沈清没有否认："我理灯油领单，有几张写的是旧库房。领油量比别处多三倍，我想问问是不是记错了。"
6. 秦妈妈看了她一眼，目光从她的手看到她的鞋，再回到脸上。然后说："记没错。冬天冷，油灯点得久。"
7. 沈清说："三倍？"
8. 秦妈妈沉默了一会儿，声音更低："旧库房存的东西怕潮，冬天要一直点油灯烘。这是老规矩。"
9. 沈清想追问"存什么"，秦妈妈已经把门带上了。门缝里露出半截扫帚，像一道无声的界线。
10. 沈清站在门外。她没有再敲门。但她看见门框上有一道刻痕，很浅，像是用钥匙尖划的。刻痕旁边有一个小小的"半"字。
11. 她转身走的时候，听见门里传来一声极轻的咳嗽。不是秦妈妈的声音。是男人的咳嗽。

#### 对话设计
- 秦妈妈（开门见山）："账房的人？"
- 沈清（直入正题）："我理灯油领单，有几张写的是旧库房。领油量比别处多三倍，我想问问是不是记错了。"
- 秦妈妈（简短）："记没错。冬天冷，油灯点得久。"
- 沈清（追问）："三倍？"
- 秦妈妈（更低声）："旧库房存的东西怕潮，冬天要一直点油灯烘。这是老规矩。"
- [秦妈妈关门，不再说话]

#### 环境描写
- 旧库房在后院西北角，远离主院和账房
- 青砖墙，木门半旧，铁锁擦得干净
- 矮屋烟囱冒细烟，门口扫得干净
- 门框上有浅刻痕，旁边一个"半"字
- 旧库房周围安静，只有远处传来的扫地声

#### 人物心理
- 沈清：秦妈妈的回答太简短，"老规矩"三个字像一堵墙。但她注意到铁锁擦得干净（有人天天摸）、门框上的"半"字（F-V1-003埋设）、门里的男人咳嗽（秦妈妈藏着人）
- 秦妈妈：看见沈清的第一眼就知道她是账房的人，警觉但没赶她走。"老规矩"是挡箭牌，也是暗示——旧库房的规矩比许管事的账更老

### 场景四：回廊上的决定（200字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 收束全章，沈清碰壁后不放弃，为下一章铺垫 |
| **情绪曲线** | 沉思→决心 |
| **出场人物** | 沈清 |
| **场景时长** | 片刻 |

#### 详细情节
1. 沈清走回廊下，日头已经偏西。她没有回账房，而是站在廊角，看着后院西北方向。
2. 旧库房。秦妈妈。铁锁。门框上的"半"字。门里的咳嗽。
3. 她想起前世。前世她从来没有走到过旧库房。那时候她只盯着许管事的小账，从没想过账的根不在账房里。
4. 这一次，她知道了。账房的账是枝叶，旧库房的账才是根。
5. 但根不是一天能挖出来的。秦妈妈不是许管事，不能用格式漏洞逼她开口。

#### 人物心理
- 沈清：碰壁不是失败。秦妈妈关门，但没赶她走。"老规矩"三个字本身就是信息——旧库房有比许管事更老的规矩，有比小账更深的账

## 🎭 人物塑造

### 秦妈妈（首次出场）
- **外在**：五十多岁，花白头发梳得整齐，腰板直，眼睛不大但看人准
- **行为**：手里拿扫帚，像随时准备赶人，但对沈清没赶
- **语言**：极简，每句话都是挡箭牌，但"老规矩"三个字暗示旧库房有更深层的规矩
- **禁忌**：不提亡夫，不提旧账，不让人进库房
- **核心**：她怕——怕的不是沈清，而是沈清问的问题会牵出她守了多年的东西

### 沈清
- **策略**：用灯油领单做敲门砖，不暴露自己知道多少
- **观察**：铁锁擦得干净、门框"半"字、男人咳嗽——三个细节都记住了
- **克制**：碰壁后没有追问，转身就走，但心里已经开始算下一步

### 小石头
- **功能**：引路+传递阿安消息+给出"秦妈妈怕"的判断
- **性格**：机灵但谨慎，对沈清有信任，对秦妈妈有畏惧

## 📝 写作策略

### 开头策略
承接第014章许管事安排的灯油领单差事，沈清在账房外间理灯油领单，自然过渡到发现"旧库房"异常。

### 中间策略
小石头引路是过渡，重点在场景三：旧库房门前。秦妈妈的出场要"冷"——不是冷脸，是冷墙。她不赶人，但也不让人进来。沈清的试探要"轻"——用领单做敲门砖，不暴露自己知道多少。

### 结尾策略
碰壁不是失败。三个细节（铁锁、半字、咳嗽）留给沈清和读者，驱动下一章。前世对比一笔带过，不展开。
