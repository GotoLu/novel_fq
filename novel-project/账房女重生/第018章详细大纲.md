## 🎯 核心目标
1. 小石头提供烧账线索——亲眼看见有人烧带格子的账册纸，地点在旧库房后面
2. 烧账线索与第017章缺页规律逻辑关联——烧掉的就是缺页那些月份的灯油/炭火记录
3. 小石头被卖矿山风险浮出——他偷剩饭时听到管事们说"矿山缺人"，下人房几个男丁要被卖出去
4. 沈清用救人承诺换线索——承诺帮小石头不被卖走，但这个承诺超出她目前的能力
5. 阿安药钱线推进——三十文退回后阿梨拿到药，但阿安病情仍在加重

## 📝 详细场景设计

### 场景一：阿梨的药（400字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 交代待核三十文退回后的结果，阿安药钱仍不够 |
| **情绪曲线** | 小松→再紧 |
| **出场人物** | 沈清、阿梨 |
| **场景时长** | 片刻 |

#### 详细情节
1. 清晨，廊下。阿梨等在那里，脸色比昨天好了一点，但眼底还是青黑。
2. 沈清把待核小账递给她："核销退回了，三十文，今天能领。"
3. 阿梨接过小账，手指攥紧了纸角。她没有说谢，只是点了点头。
4. "药铺要四十文。"沈清说。
5. "我知道。"阿梨低头，"我自己想办法凑剩下的。"
6. 她转身走了。围裙系带还是勒得很紧，但步子比昨天快了一点。三十文不够，但至少有三十文了。

#### 对话设计
- 沈清："核销退回了，三十文，今天能领。"
- 阿梨："我知道。我自己想办法凑剩下的。"

#### 人物心理
- 沈清：三十文只是药钱的一半。阿安的病在加重，药钱也在涨。她能做的有限，但至少做了。
- 阿梨：没有说谢，因为她知道沈清帮她的代价。但三十文是实实在在的，够买一半的药。

### 场景二：小石头看见火（1000字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 小石头提供烧账线索，与缺页规律逻辑关联 |
| **情绪曲线** | 警觉→紧张→发现→沉重 |
| **出场人物** | 沈清、小石头 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 午后，后院墙根。沈清在廊下整理损耗单，小石头从墙根跑过来，蹲在她旁边，像是在躲人。
2. 小石头压低声音："沈姐姐，你昨天去旧库房了？"
3. 沈清没有否认。她知道小石头消息灵通，后院的事他都知道。
4. 小石头往四周看了看，确认没人，才说："我看见过火。"
5. 沈清停下手里的笔。
6. "旧库房后面，有一小片空地，堆着碎砖头。"小石头用手比划，"那天晚上，我偷剩饭经过那里，看见有人在烧东西。火不大，蹲在碎砖头后面烧，像是怕人看见。"
7. "烧的什么？"
8. "纸。带格子的纸。"小石头的声音更低了，"我离得远，看不太清，但那纸上有格子，一格一格的，和账房的纸一样。"
9. 沈清的手指微微收紧。带格子的纸。账册纸。损耗册缺的那几页，灯油和炭火的记录——不是丢了，是烧了。
10. "什么时候的事？"
11. "入冬那会儿。冬月前后。"小石头想了想，"对，冬月。那几天特别冷，我偷剩饭都偷不到热的。"
12. 冬月。和损耗册缺页的时间对上了。冬月到腊月的灯油和炭火记录被裁掉，裁掉之后烧了。烧账灭证。
13. "谁烧的？"
14. 小石头摇头："太远了，看不清脸。但那个人穿着管事的衣裳，袖口有白边。"
15. 袖口白边。许管事的衣裳袖口就是白边。但小石头说"看不清脸"，不能确定。
16. 沈清没有追问。她把小石头说的每一句话在心里排了一遍：旧库房后面、碎砖头空地、冬月、带格子的纸、袖口白边。
17. 和她已知的拼在一起：损耗册缺页、灯油和炭火、烘耗未核销、两扇门两把锁、封门痕迹。
18. 缺页不是丢了，是烧了。烧账的人不想让灯油和炭火的数目被人查到。灯油用了三倍，损耗只认三斤，中间差了六斤。六斤灯油去了哪里？如果灯油不是用在旧库房，那用在了哪里？

#### 对话设计
- 小石头："我看见过火。"
- 沈清："烧的什么？"
- 小石头："纸。带格子的纸。和账房的纸一样。"
- 沈清："什么时候的事？"
- 小石头："入冬那会儿。冬月前后。"
- 沈清："谁烧的？"
- 小石头："看不清脸。但那个人穿着管事的衣裳，袖口有白边。"

#### 环境描写
- 后院墙根：偏僻，沈清整理损耗单的地方
- 旧库房后面碎砖头空地：小石头描述的烧账地点

#### 人物心理
- 沈清：缺页不是丢了，是烧了。烧账灭证。冬月的灯油和炭火记录被烧掉，和"烘耗"指向同一个方向。六斤灯油去了哪里？如果灯油不是用在旧库房，那用在了哪里？
- 小石头：他说这些话的时候，眼睛一直在往四周看，像是在确认有没有人盯着他。他知道看见不该看的东西是什么后果。

### 场景三：矿山（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 小石头被卖矿山风险浮出，沈清承诺保护但超出能力 |
| **情绪曲线** | 紧张→沉重→无奈 |
| **出场人物** | 沈清、小石头 |
| **场景时长** | 约半刻钟 |

#### 详细情节
1. 小石头说完烧账的事，没有走。他蹲在墙根，用手指抠砖缝里的泥。
2. "沈姐姐。"他的声音变了，不再是刚才偷偷摸摸的语气，而是带着一种沈清没听过的东西——像是求人，又像是认命。
3. "下人房在说，矿山缺人。管事们要挑几个男丁卖出去。"
4. 沈清心里一沉。矿山。卖人。和阿安的药钱一样，下人的命在侯府也是一笔账。用得着就留着，用不着就卖掉。
5. "你也在名单上？"
6. 小石头点头。"我偷剩饭的时候听到的。管事说，小石头腿脚快，矿山正缺跑腿的。"
7. 他抬起头看着沈清。那双眼睛和沈清第一次见到他时一样，机灵、警觉，但多了一层东西——怕。不是怕被打，是怕被卖。被打还能跑，被卖就跑不了了。
8. "沈姐姐，你能帮我吗？"
9. 沈清看着他的眼睛。她想说能，但她不确定。她现在连阿安的药钱都只凑了一半，她拿什么保小石头不被卖走？
10. 但她不能不说。小石头给了她烧账的线索，这条线索比什么都重要。如果她不帮小石头，小石头不会再说第二句话。不只是小石头，后院所有下人都会知道：沈清用完人就不管了。
11. "我试试。"沈清说，"但我不确定能不能成。"
12. 小石头盯着她看了一会儿，然后点了点头。他没说谢，也没说别的。他站起来，拍了拍膝盖上的灰，往墙根另一头跑走了。
13. 沈清看着他跑远的背影，心里又多了一笔账。阿安的药钱差十文。小石头要被卖去矿山。她承诺了"试试"，但"试试"不是"一定能"。
14. 她的保护范围在扩大，但她的能力没有跟上。

#### 对话设计
- 小石头："下人房在说，矿山缺人。管事们要挑几个男丁卖出去。"
- 沈清："你也在名单上？"
- 小石头："我偷剩饭的时候听到的。管事说，小石头腿脚快，矿山正缺跑腿的。"
- 小石头："沈姐姐，你能帮我吗？"
- 沈清："我试试。但我不确定能不能成。"

#### 人物心理
- 沈清：她承诺了"试试"，但"试试"不是"一定能"。她的保护范围在扩大——阿梨、阿安、小石头——但她的能力没有跟上。她需要更快地找到证据，更快地拿到筹码。
- 小石头：他不是在求沈清，是在赌。赌沈清和别的大人不一样，赌她会管。但他也知道，赌输了就是矿山。

### 场景四：账册纸（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清把烧账线索与已有证据整合，推进判断 |
| **情绪曲线** | 沉思→推进→警觉 |
| **出场人物** | 沈清 |
| **场景时长** | 入夜 |

#### 详细情节
1. 入夜，下人房。别人都睡了，沈清躺在铺上，盯着房梁。
2. 她在心里把所有线索排了一遍。
3. 损耗册缺页：冬月到腊月，灯油和炭火记录被裁掉。
4. 小石头看见的火：冬月，旧库房后面，烧的是带格子的账册纸。
5. 缺页和烧账是同一件事。裁掉记录，烧掉纸，不留痕迹。
6. 烘耗未核销：旧库房灯油用了九斤，损耗只认三斤，中间差六斤。
7. 封门痕迹：左右半间曾相通，后来被封死。
8. 六斤灯油去了哪里？如果灯油不是用在旧库房，那用在了哪里？旧库房右半间——那扇铜锁锁着的门——里面是不是藏着什么东西？需要灯油和炭火来维持？
9. 烧账的人不想让人知道灯油和炭火的真实用量。因为真实用量会暴露右半间库房里有什么。
10. 但她现在还不能进右半间。秦妈妈守着左半间，右半间的铜锁在别人手里。
11. 她能做的是从账上继续追。损耗册缺页，但灯油领单还在。灯油领单上旧库房每月领九斤油，这个数字是入总册的。如果她能把灯油领单和损耗册对上，就能算出六斤灯油的去向。
12. 还有采买单。许管事的采买单有空格，每月少算九十文。九十文和六斤灯油之间，也许真的隔着一条路——或者一堵墙。
13. 她翻了个身。明天她要重新看灯油领单。不只是旧库房的，要看所有库房的灯油领单。如果旧库房的灯油用量和别的库房对不上，那六斤灯油的去向就更清楚了。

#### 人物心理
- 沈清：缺页+烧账=灭证。灯油和炭火的真实用量被销毁，因为真实用量会暴露右半间库房里有什么。她需要从灯油领单入手，把用量和损耗对上。这是她能做的——从账上追，不从门上进。

## 📝 写作策略

### 开头策略
承接第017章待核三十文核销退回，先交代阿梨拿到药的结果，再引入小石头的线索。

### 中间策略
场景二是核心：小石头的烧账证词必须具体、可信、与缺页规律对得上。关键信息：旧库房后面、碎砖头空地、冬月、带格子的纸、袖口白边。场景三把情感加重——小石头不只是证人，也是需要被保护的人。

### 结尾策略
场景四是沈清的思考整合，把缺页+烧账+烘耗+封门四条线索拧成一根线：灭证。灯油和炭火的真实用量被销毁，因为真实用量会暴露右半间库房里有什么。章末钩子：她要重新查所有库房的灯油领单。
