## 📝 详细场景设计

### 场景一：盘点的由头（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 许管事安排沈清去旧库房盘点，合理触发进入 |
| **情绪曲线** | 日常→机会 |
| **出场人物** | 沈清、许管事 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 沈清在账房外间理损耗单，把旧库房的损耗单单独挑出来，核销栏空白的摞成一摞。
2. 她拿着这摞损耗单去问许管事："旧库房的损耗单核销栏都是空的，要不要先核一批？年底堆多了怕对不上。"
3. 许管事翻了翻，皱眉。他不想核销旧库房的损耗单——核了就要入总册，入了总册就要有人负责。但沈清说得有道理，年底堆多了确实不好看。
4. 许管事想了想："你去旧库房盘点一下，看看实物和损耗单对不对得上。对上了再核。"
5. 沈清应了。她等的就是这句话。

#### 对话设计
- 沈清："旧库房的损耗单核销栏都是空的，要不要先核一批？年底堆多了怕对不上。"
- 许管事（皱眉）："你去旧库房盘点一下，看看实物和损耗单对不对得上。对上了再核。"

#### 人物心理
- 沈清：不是她要去的，是许管事让她去的。名正言顺。
- 许管事：让一个小丫头去盘点，省得自己跑腿。旧库房反正有秦妈妈守着，出不了事。

### 场景二：半间库房（900字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清进入旧库房左半间，发现损耗册缺页规律 |
| **情绪曲线** | 紧张→观察→发现→警觉 |
| **出场人物** | 沈清、秦妈妈 |
| **场景时长** | 约半个时辰 |

#### 详细情节
1. 沈清拿着损耗单和笔，走到旧库房。秦妈妈已经在门口等着了，像是有人提前通知了她。
2. 秦妈妈没有拦她。许管事安排的盘点，她拦不了。但她开了左扇门的铁锁，只开了左扇。
3. 左半间库房比沈清想象的小。靠墙一排木架，架子上放着油灯、灯芯、炭盆、火折子。都是防潮烘干用的东西，和"烘耗"对得上。
4. 木架旁边有一张矮桌，桌上放着一本册子。册子封面写着"旧库房损耗册"，纸色发黄，比损耗单旧得多。
5. 沈清翻开册子。册子按月份记录损耗，格式和损耗单一样：日期、物品、损耗量、损耗原因、签收。但记到去年冬天那几个月，中间突然缺了几页。
6. 缺页不是随机的。沈清翻前翻后对比，发现缺的几页都集中在灯油和炭火类物品上。其他物品——虫蛀的布匹、受潮的纸张——记录完整，一页不缺。
7. 灯油和炭火，正是"烘耗"涉及的两类物品。缺页和"烘耗"指向同一个方向：有人不想让这些月份的灯油和炭火损耗被查到。
8. 沈清没有把缺页的事说出来。她继续盘点，把实物和损耗单逐项核对，一项一项报给秦妈妈听。秦妈妈站在门口，目光一直盯着她，但没靠近。
9. 盘点到一半，沈清的目光扫向右半间。右扇门关着，铜锁挂着，门缝里的灰线还在。她看不见里面，但她注意到左半间的墙上有痕迹——曾经有过一道门，后来被封死了。左半间和右半间之间，本来是通的。
10. 秦妈妈顺着她的目光看过去，脸色又变了。和上次一样，嘴角一紧，手握扫帚柄。

#### 对话设计
- 秦妈妈（开门时）："许管事让你来的？"
- 沈清："是，盘点旧库房实物，核对损耗单。"
- 秦妈妈（只开左扇门）："这边。那边不用看。"
- 沈清（盘点时逐项报）："灯油，三斤。灯芯，一束。炭盆，两只……"

#### 环境描写
- 左半间库房：小，靠墙一排木架，油灯灯芯炭盆火折子
- 矮桌上的损耗册：纸色发黄，封面手写"旧库房损耗册"
- 右扇门：铜锁，门缝灰线
- 左半间墙上：曾经有过一道门的痕迹，后来被封死

#### 人物心理
- 沈清：缺页不是随机的。灯油和炭火的记录被撕掉了，和"烘耗"指向同一个方向。左半间和右半间本来是通的，后来被封死。封死的那道门，和右扇门的铜锁，是同一时间做的事。
- 秦妈妈：让沈清进左半间是不得已，但她绝不让沈清碰右半间。沈清看墙上封门痕迹时，她的反应和上次看两扇门时一样——怕的不是问话，是看门。

### 场景三：眼线（500字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清从旧库房出来时被主院婆子看到，眼线注意成立 |
| **情绪曲线** | 松→紧 |
| **出场人物** | 沈清、主院婆子 |
| **场景时长** | 片刻 |

#### 详细情节
1. 沈清从旧库房出来，秦妈妈在身后锁门。她沿着窄路往回走，走到柴房后面，转角处差点撞上一个人。
2. 是主院的一个婆子，四十多岁，手里端着个食盒，像是给哪房送点心。但食盒很轻，不像装了东西。
3. 婆子看了沈清一眼，目光从她的脸扫到她手里的损耗单，再扫到旧库房方向。
4. "账房的丫头？"
5. 沈清低头："是，许管事让我来盘点。"
6. 婆子"嗯"了一声，端着食盒走了。但她走的方向不是主院，是后院更深处。
7. 沈清站在原地，看着婆子的背影。食盒是空的，她不是来送点心的。

#### 对话设计
- 婆子："账房的丫头？"
- 沈清："是，许管事让我来盘点。"

#### 人物心理
- 沈清：被看到了。旧库房不是随便能来的地方，一个账房丫头出现在这里，会有人问为什么。许管事的安排是挡箭牌，但挡不了多久。

### 场景四：核销与待核（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 沈清借核销损耗单的机会递上待核小账，推进阿安药钱 |
| **情绪曲线** | 紧张→试探→等待 |
| **出场人物** | 沈清、许管事 |
| **场景时长** | 约一刻钟 |

#### 详细情节
1. 申时，沈清回到账房，把盘点结果报给许管事。实物和损耗单基本对得上，灯油三斤、炭盆两只、灯芯一束，数目无误。
2. 许管事点头："对得上就核了吧。"他拿出小印，在旧库房损耗单的核销栏盖章。一张一张盖，红印落下去，像钉子钉进纸里。
3. 沈清等他盖到最后一张，从袖子里抽出待核小账："许管事，这几笔待核的也一起核了吧？挂着不好看。"
4. 许管事接过待核小账，翻了翻。三十文，阿梨的扣项。他看了沈清一眼。
5. "你倒记得清楚。"
6. "理损耗单的时候顺手看的。"沈清低头，"这几笔挂了快一个月了，再不核，月底对账不好看。"
7. 许管事想了想，在待核小账上盖了章。核销退回。三十文可以退回阿梨的月银了。
8. 沈清把盖章的待核小账收好，退出内间。她没有笑。三十文只是药钱的一半，阿安还需要更多。但至少，明天阿梨能拿到三十文。

#### 对话设计
- 许管事："对得上就核了吧。"
- 沈清（递待核小账）："许管事，这几笔待核的也一起核了吧？挂着不好看。"
- 许管事（看了一眼）："你倒记得清楚。"
- 沈清："理损耗单的时候顺手看的。这几笔挂了快一个月了，再不核，月底对账不好看。"

#### 人物心理
- 沈清：一笔换一笔，成了。三十文不够四十文，但至少阿安能先拿一部分药。剩下的十文，阿梨自己想办法。
- 许管事：这丫头心细，但不算坏事。能帮着理账，省他不少事。他没多想。

## 📝 写作策略

### 开头策略
承接第016章"从账进"策略，沈清主动制造进入旧库房的机会——不是硬闯，是用账目逻辑逼许管事安排盘点。

### 中间策略
场景二是核心：旧库房内部的空间感、损耗册缺页规律、封门痕迹。三个发现层层递进：缺页→与烘耗关联→封门暗示人为分割。秦妈妈的监视贯穿始终，增加紧张感。

### 结尾策略
待核退回是小赢，但不是全赢——三十文只够一部分药钱。眼线注意是暗雷，为后续风险铺垫。缺页规律是章末钩子，驱动读者追问"谁撕的"。
