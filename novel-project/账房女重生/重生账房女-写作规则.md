# 《重生账房女，把侯府算到倾家荡产》写作规则

## 一、章节字数标准

| 类型 | 标准 |
|---|---|
| 常规章节 | 约 2500 字 |
| 合格区间 | 2200-2800 字 |
| 高潮章、卷末章 | 可放宽至 2800-3200 字 |
| 低于 2200 字 | 必须在正文进度表记录原因，优先补足场景压力、人物选择或章末钩子 |
| 高于 3000 字 | 优先拆章；若不拆，必须说明该章为何需要更长篇幅 |

决策依据：本书属于古言重生宅斗、查账复仇和爽点连载结合体。2500 字左右能保证单章有完整冲突闭环，又不会让账目说明拖慢节奏。

## 二、单章闭环

每章必须具备五项：

| 项目 | 要求 |
|---|---|
| 目标 | 本章沈清或关键人物想要什么 |
| 阻碍 | 谁或什么阻止目标达成 |
| 代价 | 推进后失去什么、暴露什么或承担什么风险 |
| 变化 | 关系、线索、资源、压力或认知至少一项改变 |
| 钩子 | 章末留下具体追读问题，不用空泛悬念 |

不合格表现：

- 只写侯府日常，没有账线推进。
- 只让女主报数字，没有压迫、见证和代价。
- 章末只用“她愣住了”制造停顿，没有具体问题。

## 三、场景调度

| 模块 | 要求 |
|---|---|
| 空间压力 | 场景必须限制人物行动，如偏门、井边、厨房后廊、账房门外 |
| 动作节拍 | 用称肉、递契、藏铜钱、翻账册等动作推进冲突 |
| 功能道具 | 每个关键道具必须承担线索、误导、威胁、反转或情绪触发 |
| 主导感官 | 每章至少有一个明确记忆点，如霉味、油腥味、戒尺声 |
| 账目落点 | 账不是数字游戏，必须对应人命、饭钱、药钱、自由或名声 |

## 四、账目爽点规则

每次反击必须包含：

| 环节 | 标准 |
|---|---|
| 压抑铺垫 | 女主或底层人物先承受羞辱、栽赃、克扣或误判 |
| 证据动作 | 账册、契纸、斤两、木牌、损耗单必须进入动作链 |
| 公开见证 | 至少有一个能改变局面的旁观者或权力角色看到结果 |
| 即时回报 | 女主获得位置、线索、资源或关系变化 |
| 余波升级 | 胜利后必须带来更大风险，不能轻松收场 |

## 五、角色保护线

| 角色 | 写作底线 |
|---|---|
| 沈清 | 不能全知全能，不能跳过身份限制直接告官成功 |
| 裴砚 | 不能替沈清破内宅局，只能保护证据、退路和外案口径 |
| 谢令仪 | 不能写成只会尖叫的恶人，必须保持体面、规矩和反咬能力 |
| 陆怀章 | 不能过早暴露终极主谋，必须先通过外账影子出现 |
| 配角 | 不能只递线索，每个配角都要有个人目标和代价 |

## 六、每章收尾检查

正文完成后检查：

1. 是否在 2200-2800 字区间内。
2. 是否完成目标、阻碍、代价、变化、钩子。
3. 是否更新正文进度表。
4. 是否把新增人物、道具、伏笔、关系变化写入小说资产库。
5. 是否保留账目证据链和人命代价，而不是普通宅斗吵架。
6. 是否存在作者视角语境；若有，必须先改回人物认知、场景动作或时代语境后再通过。
7. 是否完成编辑审稿：从连载编辑视角检查开头抓力、信息密度、场景可读性、对白自然度、章末追读、重复表达和发布端可读性；若发现影响追读的硬伤，必须先修正文再入库。

## 七、后续章节默认执行模式

第025章起，后续章节默认采用“平衡模式”。

| 环节 | 平衡模式要求 |
|---|---|
| 上下文读取 | 只读取上一章尾部、当前阶段硬要求、资产库关键词命中和必要大纲行，避免全量读取长文档 |
| 正文写作 | 目标 2500 字左右，保持 2200-2800 字合格区间，三稿流程压缩为“闭环设计、一次成稿、硬检查修订” |
| 文档同步 | 默认只更新正文文件、正文进度表、阶段存档、第一卷分章大纲、小说资产库、项目进度追踪和工作台索引 |
| 全文预览 | 不逐章更新，默认每 5 章或用户明确要求时批量同步 |
| 资产入库 | 只记录新增核心人物、核心道具、关键伏笔和关系变化，避免流水账式膨胀 |
| 检查输出 | 保留硬闸门结论，避免输出大段 diff 和重复长评 |

决策依据：平衡模式能保留章节质量硬闸门和长篇资产连续性，同时降低上下文读取、全文预览同步和大段差异输出造成的 token 消耗。

作者视角语境判定：

- 正文中直接出现“作者、读者、本章、后文、剧情、主线、伏笔、爽点、设定、人物弧光”等元叙事提示。
- 叙述脱离当前人物可知信息，提前替读者解释后续功能、创作意图或章节作用。
- 用作者总结替代人物动作，例如直接说明“这就是本章爽点”“这是后续伏笔”“读者会知道”等。
- 可保留人物内心判断、时代化叙述和叙事者的古言语气，但判断必须落在当下处境、人物认知或可见证据上。

## 八、周期质量审计

| 周期 | 审计类型 | 必查项目 | 处理动作 |
|---|---|---|---|
| 每章 | 基础检查 | 字数区间、目标/阻碍/代价/变化/钩子、资产入库、无作者视角语境、编辑审稿 | 不合格则先修本章，不进入下一章 |
| 每5章 | 小审 | 追读钩子、爽点密度、压抑是否过长、人物轮转、伏笔状态 | 记录问题；若同类问题连续出现，下一组章节必须调整 |
| 每10章 | 大审 | 群像轮转、长篇资源账本、账目重复风险、阶段目标、爽点兑现 | 更新资产库和项目进度；必要时调整后10章写法 |
| 每20-30章 | 卷级防塌审计 | 阶段敌人、阶段谜题、爽点峰值、卷末反转、类型机制 | 若阶段目标失效，必须调整大纲并记录依据 |
| 每卷结束 | 类型机制复盘 | 悬疑公平性、喜剧回收、爽点收益层级、伏笔回收 | 形成卷末复盘，作为下一卷写作依据 |

爆款质量硬线：

1. 前30章执行“每5章小审 + 每10章大审”，不能只做10章审计。
2. 连续5章只有压抑没有回报，必须在下一组章节安排阶段性反制或明确补偿。
3. 连续5章同一配角没有私线推进，需标记工具化风险。
4. 连续10章只靠新账册推进，需补人物选择、公开见证或反派自保动作。
5. 审计结论必须写入进度存档或正文进度表，不能只口头判断。
6. 每章若检出作者视角语境，必须先改正文再更新为“已完成”，不得把元叙事留到后续统一处理。
