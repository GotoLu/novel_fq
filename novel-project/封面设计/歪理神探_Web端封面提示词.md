# 《歪理神探》Web 端封面生成提示词

日期：2026-06-04

用途：用于豆包、即梦、可灵、Midjourney、Stable Diffusion、通义万相等 Web 端图片生成工具。

## 一、封面固定文案

书名：

《歪理神探》

笔名：

一直在匿名

第一卷卷名：

证据不会笑

宣传语：

全警局都笑我，直到真相站在我这边

底部卖点：

歪理只能指路，证据才能判人

## 二、推荐生成方式

最优方式：先生成“无文字封面底图”，再在 Web 端编辑器、Canva、醒图、PS 或平台后台封面工具中手动加字。

核心理由：多数图片生成模型对中文标题、笔名和标点不稳定，容易出现错字、乱码、漏字。书名和笔名是发布硬字段，必须准确。

如果 Web 工具支持“AI 生成后编辑文字层”，请采用：

- AI 只负责画面。
- 标题、卷名、笔名、宣传语全部手动排版。

## 四、带文字封面提示词（仅在工具中文稳定时使用）

```text
生成一张竖版网络小说封面，比例 3:4，都市轻喜悬疑探案风格，适合番茄小说。

封面必须包含准确中文文字：
主标题：歪理神探
笔名：一直在匿名
卷名：证据不会笑
宣传语：全警局都笑我，直到真相站在我这边

文字排版要求：
主标题“歪理神探”放在画面中上部或中央偏上，最大、最醒目，白色或金白色粗体，带深色描边，移动端缩略图也能看清。
笔名“一直在匿名”放在标题下方或底部，字号小于标题，但必须清晰准确。
卷名“证据不会笑”作为金色横条或徽章，放在标题下方。
宣传语放在上方或底部，不能遮挡标题。

画面主体：夜色楼梯间与警局证据板融合，一个黑色便携音响放在楼梯平台，后盖微开，里面露出金色珠宝微光，音响挂红色绸带。年轻中国男性协查员站在中下部，深色风衣或略皱西装，手持记录本，聪明、镇定、带一点反套路笑意。背景有模糊证据白板、线索线、便签和暖光。

风格：商业小说封面，精致数字插画，悬疑但不恐怖，轻喜但不幼稚，都市探案，反套路，证据翻盘，强点击感。

色彩：深蓝黑、炭灰、暖金、少量红色绸带。高对比，移动端清晰。

禁止：错别字、乱码、英文假字、水印、平台 logo、血腥、尸体、恐怖鬼怪、玄学法阵、枪械特写、低清晰度、标题被遮挡。
```

## 五、后期排版建议

### 5.1 推荐文字层级

| 层级 | 文案 | 位置 | 字号关系 |
|------|------|------|----------|
| 主标题 | 歪理神探 | 中上部或中央偏上 | 最大 |
| 卷名 | 证据不会笑 | 主标题下方金色横条 | 主标题的 35%-45% |
| 笔名 | 一直在匿名 | 底部或标题下方小字 | 主标题的 18%-25% |
| 宣传语 | 全警局都笑我，直到真相站在我这边 | 顶部或底部 | 主标题的 20%-28% |
| 底部卖点 | 歪理只能指路，证据才能判人 | 底部细条 | 可选 |

### 5.2 推荐字体风格

- 主标题：粗黑体、宋黑结合、标题黑体，必须厚重醒目。
- 卷名：金色或黑底金字，像“证据标签”或“案件卷宗贴纸”。
- 笔名：白色小字即可，不要抢标题。
- 宣传语：白字黑底或浅金字，保证可读。

### 5.3 推荐色值

| 用途 | 色值 |
|------|------|
| 背景深色 | `#111820` |
| 主标题白金 | `#FFF4D6` |
| 标题描边 | `#05070A` |
| 证据金 | `#F6B13F` |
| 绸带红 | `#C0362B` |
| 冷光蓝 | `#73C4DC` |

## 六、封面审核自检

上传前检查：

- 缩略图里能一眼读出“歪理神探”。
- “一直在匿名”没有错字、漏字、乱码。
- 画面能看出“探案/证据/音响藏赃”，不是玄幻、恐怖或硬核刑侦。
- 标题没有被人物、证据板或高光遮挡。
- 宣传语没有夸大成“神级破案”“无敌侦探”“全新原创奇案”。
- 封面与简介一致：歪理是入口，证据才是定案。
