## 📝 详细场景设计

### 场景一：秦墨寒的困境（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 展示数据分析的局限性 |
| **情绪曲线** | 专注→困惑→焦虑 |
| **出场人物** | 秦墨寒 |
| **场景时长** | 约2小时（故事时间） |

#### 详细情节

**开头设计（承接第25章）**：
```
时间：竞争第五天上午
地点：幸福派出所，秦墨寒工位
氛围：专注紧张，但越来越焦虑
```

**情节展开**：

1. **数据分析完全失效**（400字）
   - 秦墨寒继续分析11起案件的数据
   - 作案时间分散在全天各时段：中午12点到晚上10点
   - 作案地点分散在整个辖区
   - 受害者职业、年龄、收入都无规律
   - 所有维度都显示：分散，无规律

2. **陷入困境**（400字）
   - 秦墨寒盯着屏幕，越来越焦虑
   - 他尝试了所有可能的分析维度，但都找不到规律
   - "数据不会说谎，但数据也可能沉默。"
   - 他第一次意识到：有些规律，数据分析找不到

#### 对话设计

**秦墨寒自言自语**：
```
"作案时间：中午12点到晚上10点，分散在全天各时段。"
"作案地点：分布在整个辖区，无聚集特征。"
"受害者职业、年龄、收入：都无规律。"
"所有维度都显示：分散，无规律。"
"难道...这个案子真的没有规律？"
```

#### 环境描写

```
秦墨寒的电脑屏幕上，数据表格密密麻麻。
他用不同颜色标注不同维度，试图找出关联。
但所有图表都显示同一个结论：分散，无规律。
窗外的阳光照在屏幕上，形成一道反光，像一道墙。
```

### 场景二：嫌疑人排查（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 排查有前科的人，但都无作案时间证据 |
| **情绪曲线** | 期待→失望 |
| **出场人物** | 秦墨寒、派出所民警 |
| **场景时长** | 约2小时（故事时间） |

#### 详细情节

1. **查询前科犯**（400字）
   - 秦墨寒联系分局，查询辖区内有过技术开锁前科的人员
   - 一共查到5人，都有技术开锁前科
   - 秦墨寒逐一排查他们的近期活动

2. **排除嫌疑**（400字）
   - 第1人：正在服刑，排除
   - 第2人：案发时间在外地工作，有不在场证明，排除
   - 第3人：案发时间在医院住院，有不在场证明，排除
   - 第4人：案发时间在家照顾老人，有不在场证明，排除
   - 第5人：周强，6月16日释放，近期活动不明，需进一步调查
   - 秦墨寒发现：周强就是陆行舟排查到的可疑人员

#### 对话设计

**排查对话**：
```
秦墨寒："辖区内有过技术开锁前科的人员，一共5人。"
"第1人正在服刑，排除。"
"第2人案发时间在外地工作，排除。"
"第3人案发时间在医院住院，排除。"
"第4人案发时间在家照顾老人，排除。"
"第5人周强，6月16日释放，近期活动不明。"
```

**秦墨寒内心**：
```
"周强...就是陆行舟排查到的可疑人员。"
"技术开锁前科，6月16日释放，近期活动不明。"
"需要进一步调查。"
```

#### 环境描写

```
派出所里，秦墨寒拿着电话，逐一核实前科犯的不在场证明。
大部分都有明确的不在场证明，可以排除。
只有周强，近期活动不明，无法排除。
```

### 场景三：陆行舟的整理（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 整理受害者作息表，发现饭点作案规律 |
| **情绪曲线** | 专注→发现 |
| **出场人物** | 陆行舟 |
| **场景时长** | 约1小时（故事时间） |

#### 详细情节

1. **整理受害者作息表**（400字）
   - 陆行舟拿出笔记本，整理11起案件受害者的作息时间
   - 他列出每个受害者的外出时间和外出原因
   - 发现：所有受害者都在饭点外出

2. **发现饭点规律**（400字）
   - 11起案件中：
     - 6起发生在午饭时间（11:30-13:00）
     - 5起发生在晚饭时间（17:30-19:00）
   - 所有案件都发生在饭点！
   - 陆行舟在笔记本上写下：**嫌疑人选择饭点作案，因为受害者外出，家中无人**

#### 对话设计

**陆行舟整理**：
```
陆行舟："第1起：中午12:00，午饭时间。"
"第2起：晚上7:00，晚饭时间。"
"第3起：中午12:30，午饭时间。"
"第4起：下午3:00，接近午饭时间。"
"第5起：晚上8:00，晚饭时间。"
"..."
"所有案件都发生在饭点！"
```

**陆行舟内心**：
```
"11起案件，6起午饭时间，5起晚饭时间。"
"嫌疑人选择饭点作案，因为受害者外出，家中无人。"
"这个规律，数据分析找不到。"
```

#### 环境描写

```
陆行舟坐在工位上，笔记本摊开。
歪歪扭扭的字迹记录着每个受害者的外出时间。
他发现一个惊人的规律：所有时间都指向饭点。
午饭、晚饭，每天固定，从不改变。
```

### 场景四：关键发现（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 发现周强释放时间与首次作案时间吻合 |
| **情绪曲线** | 发现→兴奋 |
| **出场人物** | 陆行舟、秦墨寒、周明远、苏晚 |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

1. **查询释放记录**（300字）
   - 陆行舟查询周强的释放记录
   - 发现：周强6月16日释放，因技术开锁入狱，服刑3年
   - 首次作案时间：7月1日
   - 释放到首次作案：15天

2. **关键发现**（300字）
   - 陆行舟计算：15天，正好是踩点周期
   - 周强释放后，用15天时间踩点，观察受害者的饭点外出习惯
   - 然后开始作案
   - 陆行舟兴奋地想：这就是关键证据！

#### 对话设计

**陆行舟发现**：
```
陆行舟："周强6月16日释放，首次作案7月1日。"
"释放到首次作案：15天。"
"这15天，正好是他踩点的时间！"
```

**周明远反应**：
```
周明远："15天踩点，然后开始作案？"
陆行舟："对，他用15天时间观察受害者的饭点外出习惯。"
周明远："这个时间吻合，是关键证据！"
```

#### 环境描写

```
派出所里，陆行舟兴奋地找到周明远。
他拿着笔记本，上面记录着周强的释放时间。
15天，从释放到首次作案，正好是踩点周期。
这个发现，让周强成为最大嫌疑人。
```
