# 《歪理侦探正着破案》全流程重构计划

本文档使用 `.codex/skills/` 的全技能链，对现有低质量未完成稿进行系统重构。重构从 `01-创意方案.md` 开始，不直接进入正文润色；先重建创意、人物、情节、资产和质量闸门，再批量改写正文。

## 一、重构总目标

把现有作品从“有梗但松散的幽默推理稿”重构为：

- 第一章能抓人。
- 每章有追读。
- 每案有公平线索、误导和反转。
- 人物会在压力下犯错、付代价、成长。
- 爽点有压抑、反制、见证、回报和余波。
- 长篇资源不重复、不塌卷、不漂移。
- 发布材料能准确打中平台读者。

## 二、当前项目诊断

| 模块 | 现状 | 核心问题 | 重构方向 |
|------|------|----------|----------|
| 创意 | “错误逻辑却总能破案”的反向侦探 | 概念有爆点，但与人物代价、案件机制绑定不够 | 强化“直觉不是运气，而是另一种看见真相的方式” |
| 人物 | 陆行舟、苏晚、秦墨寒有基本功能 | 人物像设定卡，压力测试不足，秦墨寒偏工具人 | 重做人设压力、错误决策倾向、关系交易 |
| 情节 | 100 章五卷结构已存在 | 大纲偏事件列表，缺少资源账本和章节接力 | 重建案件引擎、卷级防塌、章节卡 |
| 正文 | 第 1-31 章已有多版稿 | 开篇慢、场景功能弱、章末追读不稳定 | 先改黄金三章，再按案件批量重写 |
| 质量评估 | 旧报告自评 85.5 | 评分过宽，缺少硬性淘汰项 | 重新按 P0-P19 验收 |
| 原创性风险 | 未形成稳定闭环 | 创意、案件桥段、场景表达缺少人工风险分型 | 每阶段加入原创性风险审查 |
| 进度管理 | 文档多但资产分散 | 伏笔、案件、人物关系、版本变化散落 | 建立小说资产库和进度审计表 |

## 三、全技能调用总链路

`skill-chains` 总控 → `market-analyzer` → `idea-generator` → 原创性风险审查 → `quality-evaluator` → `problem-solver` → `character-designer` → `plot-architect` → `content-writer` → `progress-tracker`

实际执行时按阶段回路运行：

1. 创意重构：市场定位 → 高概念升级 → 原创性风险审查 → 创意验收。
2. 人物重构：人物压力测试 → 群像轮转 → 人物验收。
3. 情节重构：案件引擎 → 卷级结构 → 长篇资产 → 情节验收。
4. 正文重构：章节卡 → 正文改写 → 质量评估 → 原创性风险审查 → 记录。
5. 连载重构：周期审计 → 反馈闭环 → 发布适配 → 完结设计。

## 四、阶段一：创意方案重构

主技能：`idea-generator`

协同技能：`market-analyzer`、原创性风险审查、`quality-evaluator`、`progress-tracker`

### 4.1 保留项

- “歪理推理”核心记忆点。
- 陆行舟一本正经胡说八道的喜剧风格。
- 陆行舟 vs 秦墨寒的“直觉 vs 证据”竞技关系。
- 单元案件加长篇主线模式。

### 4.2 必改项

| 旧设定 | 问题 | 新设定方向 |
|--------|------|------------|
| 错误逻辑却总能破案 | 太靠运气，容易廉价 | 错误逻辑是表层，底层是对“异常细节”和“人性漏洞”的超常捕捉 |
| 歪打正着体质 | 金手指过轻浮 | 反向直觉有代价：误判会伤人，过度依赖会失灵 |
| 轻松幽默推理 | 压力不足 | 喜剧外壳下必须有误判代价和受害者情绪 |
| 成为传奇神探 | 目标泛 | 目标改为：证明自己不是骗子，并建立一套能被证据验证的歪理方法 |

### 4.3 新高概念

一个被全警局当笑话的编外协查员，靠荒唐歪理一次次撞中真相；但当他的误判差点毁掉无辜者人生，他必须学会把直觉变成证据，在证据至上的精英侦探面前证明：真相有时藏在所有人都觉得“不合逻辑”的地方。

### 4.4 验收闸门

- P3：换掉陆行舟后，故事是否仍成立？如果成立，创意绑定失败。
- P11：悬疑、喜剧、爽文三套类型机制是否分别成立？
- P17：一句话卖点是否能变成书名、简介、标签和前三章钩子？
- 原创性风险审查：高概念、反向侦探设定和核心案件模式必须有明确保留依据与重构项。

## 五、阶段二：人物体系重构

主技能：`character-designer`

协同技能：`idea-generator`、`plot-architect`、`quality-evaluator`、`progress-tracker`

### 5.1 陆行舟重构

| 维度 | 重构要求 |
|------|----------|
| 外在目标 | 从编外协查员成为被正式认可的案件顾问 |
| 内在需求 | 证明自己不是靠运气蒙对，不是伤害无辜者的骗子 |
| 核心恐惧 | 下一次歪理误判会害死真正需要帮助的人 |
| 错误倾向 | 被质疑时急于证明自己，先下结论后补证据 |
| 成长代价 | 每次错误推理都必须造成真实损失或关系裂痕 |
| 终点 | 能把“荒唐直觉”转化为“可验证线索链” |

### 5.2 秦墨寒重构

| 维度 | 重构要求 |
|------|----------|
| 表层功能 | 精英侦探，对照组和竞争者 |
| 深层恐惧 | 害怕无法解释的直觉摧毁自己信奉的证据体系 |
| 错误倾向 | 过度相信可量化证据，忽略人性异常和低概率细节 |
| 成长线 | 从鄙视陆行舟，到利用陆行舟的异常视角补足证据链 |
| 爽点功能 | 质疑、压迫、见证、被打脸、再成长 |

### 5.3 苏晚重构

| 维度 | 重构要求 |
|------|----------|
| 表层功能 | 警方搭档、吐槽担当 |
| 深层功能 | 程序正义守门人，防止陆行舟歪理伤人 |
| 私线 | 在“保护程序”和“相信异常直觉”之间摇摆 |
| 高光 | 关键时刻不是附和主角，而是用程序和证据救主角 |

### 5.4 群像轮转

必须建立 `人物轮转表`：

| 人物 | 每卷目标 | 私线 | 阶段高光 | 与主线交易 |
|------|----------|------|----------|------------|
| 陆行舟 | 证明自己 | 自我怀疑 | 歪理转证据 | 主线发动机 |
| 秦墨寒 | 证明证据至上 | 傲慢崩塌 | 承认歪理价值 | 竞技和互补 |
| 苏晚 | 守住程序 | 信任选择 | 用规则保护主角 | 现实约束 |
| 周明远 | 保护异类 | 旧案隐情 | 揭示陆行舟过去 | 主线伏笔 |

### 5.5 验收闸门

- P2：每个主要人物必须通过失去、羞辱、误解、利益冲突和道德两难测试。
- P13：每 5-10 章检查配角是否有变化。
- `quality-evaluator`：人物不能只服务剧情，必须有自己想要的东西。

## 六、阶段三：情节与长篇资产重构

主技能：`plot-architect`

协同技能：`character-designer`、原创性风险审查、`quality-evaluator`、`progress-tracker`

### 6.1 案件引擎

每个案件必须建立五张表：

1. 线索公平表：读者能看到哪些线索。
2. 误导层级表：谁误导、怎么误导、何时反转。
3. 嫌疑人动机矩阵：每个嫌疑人的欲望、谎言、压力。
4. 歪理命中表：陆行舟的荒唐判断对应哪个真实异常。
5. 证据闭环表：最后如何从直觉落到可定案证据。

### 6.2 第一案重构方向

旧结构：找音响 → 发现珠宝 → 误判小王 → 发现红泥 → 抓老张。

新结构：

| 章节 | 重构目标 | 核心变化 |
|------|----------|----------|
| 第1章 | 强钩子 | 第一屏出现“音响里藏赃物”，压缩派出所日常 |
| 第2章 | 强对抗 | 秦墨寒公开否定陆行舟，赌约形成 |
| 第3章 | 强代价 | 陆行舟误判小王，导致小王母亲治疗款危机 |
| 第4章 | 强低谷 | 陆行舟公开道歉，发现秦墨寒红泥矛盾 |
| 第5章 | 强爽点 | 证据链翻盘，公开打脸，但保留秦墨寒反击余波 |

### 6.3 长篇资源账本

必须新增 `小说资产库.md`，至少包含：

- 案件资产：案件类型、谜题、真相、误导、歪理命中点。
- 人物资产：人物状态、关系变化、口癖、伤口。
- 伏笔资产：埋设章节、回收章节、状态。
- 爽点资产：压抑、反制、见证、回报、余波。
- 情绪债资产：误伤、亏欠、承诺、偿还。
- 设定资产：反向直觉规则、限制、代价。

### 6.4 验收闸门

- P1：每章必须写清目标、阻碍、代价、变化。
- P5：每个关键场景必须有空间压力、动作节拍和功能道具。
- P6：每章开头必须处理上一章钩子。
- P8：爽点必须有压抑、公开见证、额外收益和余波。
- P10、P14、P16、P19：建立资源账本、卷级防塌、资产库和完结设计。

## 七、阶段四：正文重构

主技能：`content-writer`

协同技能：`plot-architect`、`character-designer`、`quality-evaluator`、`problem-solver`、原创性风险审查、`progress-tracker`

### 7.1 改写顺序

1. 先重写第 1 章。
2. 再重写第 2-5 章，完成第一案闭环。
3. 复评黄金五章。
4. 重写第 6-20 章，完成第一卷。
5. 根据新资产库调整第 21-31 章旧稿。
6. 再规划第 32-100 章。

### 7.2 单章改写模板

每章重写前先生成章节卡：

```markdown
## 章节卡

- 章节：
- 上章钩子：
- 本章开头兑现方式：
- 本章目标：
- 阻碍：
- 代价：
- 局面变化：
- 场景调度：
- 情绪投注点：
- 爽点链：
- 歪理命中点：
- 章末钩子：
- 入库资产：
```

### 7.3 第 1 章改写要求

旧版第 1 章从派出所日常写起，钩子偏慢。新版必须：

- 第一屏出现异常事件。
- 500 字内出现音响藏赃。
- 1000 字内确认这是刑事案件。
- 保留陆行舟荒唐推理的喜剧感。
- 章末抛出秦墨寒或更大案件压力。

### 7.4 验收闸门

- P0：第一页钩子、单章闭环、章末追读。
- P7：每章必须有具体情绪投注。
- P9：必须建立作者风格声明并检查每章独特句群。
- 原创性风险审查：正文、对话、场景表达需检查旧稿继承、桥段撞车和表达复用。
- `problem-solver`：未通过章节按结构、人物、追读、场景、语言顺序修。

## 八、阶段五：质量评估、原创性审查与进度闭环

### 8.1 新质量评估权重

| 维度 | 权重 |
|------|------|
| 追读动力 | 20% |
| 案件引擎 | 15% |
| 人物压力 | 15% |
| 爽点链 | 15% |
| 情绪投注 | 10% |
| 语言风格 | 10% |
| 长篇资产 | 10% |

出现以下任一项，本章不能评为优秀：

- 开篇无钩子。
- 单章无变化。
- 人物无欲望或无代价。
- 案件无公平线索。
- 爽点无见证。
- 章末无追读。
- 原创性风险高且未完成重构。
