## 📝 详细场景设计

### 场景一：秦墨寒的困境（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 展示数据分析的局限性 |
| **情绪曲线** | 专注→困惑→焦虑 |
| **出场人物** | 秦墨寒 |
| **场景时长** | 约2小时（故事时间） |

#### 详细情节

**开头设计（承接第22章）**：
```
时间：竞争第二天上午
地点：幸福派出所，秦墨寒工位
氛围：专注紧张，数据表格铺满屏幕
```

**情节展开**：

1. **继续数据分析**（300字）
   - 秦墨寒继续分析10起案件的数据
   - 尝试不同维度：作案时间分布、地点热力图、被盗物品关联
   - 每个维度都显示：分散、无规律

2. **陷入困境**（300字）
   - 作案时间：分散在中午到晚上，无聚集特征
   - 作案地点：分布在整个辖区，无热点区域
   - 被盗物品：现金、首饰、电子产品，无偏好
   - 秦墨寒皱眉：数据量已经足够，但找不到规律

3. **自我质疑**（200字）
   - "数据不会说谎，但数据也可能沉默。"
   - 秦墨寒第一次怀疑自己的方法
   - 他决定继续收集数据，但心里有了不安

#### 对话设计

**秦墨寒自言自语**：
```
"作案时间：中午12:45、下午2:30、3:20、4:45、5:10...分散。"
"作案地点：幸福小区、幸福花园、阳光公寓、康乐小区...分散。"
"被盗物品：现金、首饰、电子产品...无规律。"
"数据量已经足够了，为什么找不到规律？"
"难道...数据本身就没有规律？"
```

#### 环境描写

```
秦墨寒的电脑屏幕上，数据表格密密麻麻。
他用不同颜色标注不同维度，试图找出关联。
但所有图表都显示同一个结论：分散，无规律。
窗外的阳光照在屏幕上，形成一道反光，像一道墙。
```

### 场景二：陆行舟的发现（1000字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 陆行舟找到关键线索 |
| **情绪曲线** | 专注→疑惑→兴奋 |
| **出场人物** | 陆行舟、受害者 |
| **场景时长** | 约3小时（故事时间） |

#### 详细情节

1. **走访第10起案件受害者**（400字）
   - 陆行舟来到康乐小区9栋，走访第10起案件的受害者
   - 一对年轻夫妻，昨晚8点外出就餐，回来发现被盗
   - "你们每晚8点都外出就餐吗？"
   - "差不多，每天晚饭后都出去吃，孩子喜欢外面的口味。"
   - 陆行舟记下："第10起，晚上8:00外出就餐（固定习惯）"

2. **发现规律**（400字）
   - 陆行舟突然想到什么，翻开笔记本
   - 第1起：下午2:30买菜（午饭时间）
   - 第2起：晚上7:00散步（晚饭时间）
   - 第3起：中午12:00吃饭（午饭时间）
   - 第10起：晚上8:00就餐（晚饭时间）
   - 他发现：所有受害者都在饭点外出，而且是固定习惯

3. **验证规律**（200字）
   - 陆行舟继续走访，询问每个受害者："你们外出是固定习惯吗？"
   - 大部分回答："差不多每天都是那个时间。"
   - 陆行舟在笔记本上写下：**所有受害者都有固定的饭点外出习惯**

#### 对话设计

**走访对话**：
```
陆行舟："你们每晚8点都外出就餐吗？"
受害者："差不多，每天晚饭后都出去吃。"
陆行舟："是固定习惯吗？"
受害者："对，差不多每天都是那个时间。"
```

**陆行舟思考**：
```
"第1起：下午2:30买菜——午饭时间。"
"第2起：晚上7:00散步——晚饭时间。"
"第3起：中午12:00吃饭——午饭时间。"
"第10起：晚上8:00就餐——晚饭时间。"
"所有受害者都在饭点外出，而且是固定习惯！"
```

#### 环境描写

```
康乐小区的楼道里，陆行舟一家家敲门。
笔记本上，歪歪扭扭的字迹记录着每个受害者的外出时间。
他发现一个惊人的规律：所有时间都指向饭点。
午饭、晚饭，每天固定，从不改变。
```

### 场景三：歪理推理萌芽（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 陆行舟形成推理方向 |
| **情绪曲线** | 兴奋→思考→坚定 |
| **出场人物** | 陆行舟 |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

1. **歪理推理启动**（400字）
   - 陆行舟回到派出所，坐在工位上思考
   - 他想起第21章苏晚的提醒："你需要找方向。"
   - 现在，他找到了方向：饭点
   - 他开始歪理推理：
     - 作案时间无规律 → 但人一定有规律
     - 人最大的规律是什么 → 吃饭
     - 饭点 → 受害者饭点外出 → 家中无人 → 作案时机

2. **形成假设**（400字）
   - 陆行舟在笔记本上写下推理：
     - **假设**：嫌疑人踩点，发现受害者有固定的饭点外出习惯，选择饭点作案
     - **验证方法**：调查所有受害者，确认是否都有固定饭点外出习惯
     - **推论**：如果假设成立，嫌疑人应该是在饭点前后踩点，观察受害者外出规律
   - 陆行舟兴奋地想：这就是方向！

#### 对话设计

**陆行舟歪理推理**：
```
"作案时间无规律...但人一定有规律。"
"人最大的规律是什么？吃饭。"
"饭点...受害者饭点外出...家中无人...作案时机。"
"嫌疑人踩点，发现受害者有固定的饭点外出习惯！"
```

**陆行舟假设**：
```
"假设：嫌疑人踩点，发现受害者有固定的饭点外出习惯，选择饭点作案。"
"验证：调查所有受害者，确认是否都有固定饭点外出习惯。"
"推论：嫌疑人应该是在饭点前后踩点，观察受害者外出规律。"
```

#### 环境描写

```
派出所里，陆行舟坐在工位上，笔记本摊开。
歪歪扭扭的字迹记录着他的推理过程。
旁边是秦墨寒的电脑屏幕，密密麻麻的数据表格。
两种方法，一个陷入困境，一个找到方向。
```
