## 五、核心决策

最优决策：第 27 章只把“证据真实”写到足够硬，不提前进入“展出物是假”的答案。

核心依据：

- C006 的设计目标是让秦墨寒凭验证体系赢一局，因此第 27 章必须把胜利给到他，而不是让陆行舟抢先破题。
- “证据越真实，案件越不可能”是本章追读发动机。若提前解释赝品，压迫感会坍塌。
- 第 28 章标题《消失的不是它》需要一个自然入口，本章章末把问题改成“消失的到底是什么”最稳。
- 第 25 章起执行汉字约 3000、最多不超过 4000 的短章约束，本章只坐实证据地基，不展开材料验证和主犯链。

执行边界：

- 不出现“赝品”“水溶”作为明确结论。
- 不锁定布展负责人梁启。
- 底座水渍只写成“轻微湿痕/冷凝/清洁残留争议”，不得写成定案证据。
- 证书真实只作为 F050 提示，不能让角色直接推出对象造假。

## 七、关键场景设计

### 场景一：监控室原始文件复核

| 项目 | 内容 |
|------|------|
| 场景空间 | 展馆监控室，主机柜、校时记录、六路画面、备份硬盘 |
| 镜头顺序 | 白板三行字 -> 原始文件校验码 -> 六路画面同步 -> 空柜定格 |
| 动作节拍 | 秦墨寒要求断网封存，苏晚双人签封，技术员报校时，陆行舟沉默看时间轴 |
| 功能道具 | 原始监控文件承担“证据没撒谎”的第一根柱子 |
| 主导感官 | 风扇声、鼠标点击声、硬盘轻响 |

推进卡：

- 人物目标：秦墨寒要证明监控是否真实。
- 主要阻碍：馆方和保险代表都急着听解释，而不是听复核过程。
- 冲突升级：监控不但没有被改，多机位还互相印证。
- 代价后果：秦墨寒把自己逼进更难的位置，无法再用“监控造假”卸压。
- 局面变化：监控真实性成立。
- 章末追读：如果监控没撒谎，谁在撒谎。

### 场景二：证人路线表

| 项目 | 内容 |
|------|------|
| 场景空间 | 展馆教育活动室，临时询问桌、贴在墙上的展厅平面图 |
| 镜头顺序 | 证人号码贴 -> 讲解员激光笔路线 -> 学生作业纸 -> 保安交接本 |
| 动作节拍 | 秦墨寒让每个人只说亲眼所见，苏晚标注视线范围，陆行舟把“以为”圈掉 |
| 功能道具 | 展厅平面图承担证词交叉验证 |
| 主导感官 | 纸张摩擦、激光笔轻点墙面的声音 |

推进卡：

- 人物目标：团队要确认证人是否串供或记错。
- 主要阻碍：证人都带着自保情绪，表述里夹杂“我以为”。
- 冲突升级：去掉推测后，证词反而更稳定。
- 代价后果：不可能感加重，陆行舟不能从证人谎言里找入口。
- 局面变化：证人初步真实升级为证词链条基本可靠。
- 章末追读：没有人撒谎时，空柜从哪里来。

### 场景三：展柜锁与底座湿痕

| 项目 | 内容 |
|------|------|
| 场景空间 | 展厅主柜旁，封锁线内只能两人进入，玻璃反光影响观察 |
| 镜头顺序 | 锁芯编号 -> 报警线 -> 底座绒布边缘 -> 极浅湿痕 |
| 动作节拍 | 秦墨寒戴手套查锁，苏晚拍照编号，馆长解释清洁流程，沈岚追问是否有人碰柜 |
| 功能道具 | 展柜底座承担公平线索和后续材料方向入口 |
| 主导感官 | 玻璃冷气、消毒水味、绒布潮痕 |

推进卡：

- 人物目标：确认展柜有没有被打开。
- 主要阻碍：柜锁、报警、重量感应都没有给出正常盗窃入口。
- 冲突升级：唯一新痕迹只是轻微湿痕，表面解释过于平常。
- 代价后果：秦墨寒不能把湿痕当结论，只能记录，承受“线索不足”的压力。
- 局面变化：底座水渍入库，证据地基更牢但答案更远。
- 章末追读：证据指向的对象是否本身有问题。

### 场景四：外界施压与章末复盘

| 项目 | 内容 |
|------|------|
| 场景空间 | 展馆临时复盘桌，外侧是媒体和保险代表，内侧是证据袋、证书复印件和监控定格画面 |
| 镜头顺序 | 保险代表催促 -> 馆长递证书 -> 秦墨寒划掉“证据造假” -> 陆行舟盯住“展品”两个字 |
| 动作节拍 | 沈岚试图推内部盗窃，郝馆长用证书和专家背书保声誉，秦墨寒只承认证据真实，陆行舟把问题改成“消失的到底是什么” |
| 功能道具 | 证书复印件承担 F050 提示，监控定格承担章末反问 |
| 主导感官 | 纸张翻动声、封锁线外的快门声 |

推进卡：

- 人物目标：团队要给出阶段判断，但不能被外界压力逼成错误定性。
- 主要阻碍：馆方、保险方和媒体都需要一个可传播的答案。
- 冲突升级：秦墨寒证明证据没有撒谎，却无法直接推出“谁偷了展品”。
- 代价后果：警方暂时拿不出公众想要的解释，秦墨寒的胜利反而把谜题推得更硬。
- 局面变化：普通盗窃解释被压掉，问题从“谁拿走”转向“消失的到底是什么”。
- 章末追读：消失的是古董，还是大家以为在展柜里的那个东西。
