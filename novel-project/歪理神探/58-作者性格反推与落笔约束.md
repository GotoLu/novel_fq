# 《歪理神探》作者性格反推与落笔约束

生成日期：2026-06-11

调用阶段：`skill-chains` 阶段三点五“作者性格定标”。

调用技能：`progress-tracker` 定位已有正文样本，`quality-evaluator` 反推文本气质，`content-writer` 固化作者性格声明，`problem-solver` 标记风格漂移风险。

## 一、结论

《歪理神探》的作者性格应定为：

**清醒克制、护短普通人、爱用生活物件拆复杂真相、对漂亮话天然不信、用冷幽默逼证据说话。**

这不是“幽默”“犀利”“温暖”的泛标签，而是已有正文反复表现出的落笔人格：作者允许陆行舟说荒唐话，但不允许荒唐话替代证据；作者喜欢笑方法、笑话术、笑过度合理的解释，但不笑受害者和普通人的窘迫；作者的爽点不在“主角封神”，而在“一个被欺负的人终于拿到可复核的事实”。

最优决策：后续正文以“克制型轻喜证据派作者”为统一性格基准。

核心依据：

- 题材是都市悬疑轻喜，不适合纯硬核冷峻，也不能滑向段子刑侦。
- 已有章节的高分句群都来自“生活物件比喻 + 证据边界校正”，不是来自夸张嘴炮。
- 全书主题是“歪理只能指路，证据才能判人”，作者性格必须天然反感无证据定论。
- 受害者多为普通人、消费者、学生、工人、基层住户，作者同情点必须稳定落在他们身上。

## 三、作者性格声明

| 字段 | 定标 |
|------|------|
| 作者性格核心 | 清醒、克制、护短普通人、反话术、证据洁癖式冷幽默 |
| 叙述态度 | 世界很吵，真相很小；作者不急着替任何人定罪，只盯住被忽略的异常、被压住的普通人和必须补齐的证据 |
| 看主角 | 陆行舟可爱在荒唐和敏锐，不可被神化；他每一次漂亮判断都必须被苏晚、秦墨寒和证据校正 |
| 看反派 | 不写天生坏人式扁平恶；更关注他们如何利用话术、流程、亲情、专业身份或公开见证转移责任 |
| 看普通人 | 普通人的钱、药费、工资、名誉、安全感都是真代价；作者默认保护他们的具体损失，不把他们当工具人 |
| 幽默刀口 | 笑荒唐逻辑、官样话、甩锅话术、过度合理的解释、主角自我克制失败；不笑受害者、穷困者、无知者和真实创伤 |
| 同情对象 | 被话术压住的人、被流程绕晕的人、被亲情或权威借名的人、被群体声音淹没的人 |
| 鄙视对象 | 用漂亮流程遮事实的人、用“都是为你好”转嫁责任的人、用群体见证制造压力的人、拿证据外壳偷换证明对象的人 |
| 迷恋对象 | 白板、便签、签收表、流水、压痕、封条、时间戳、道具边角、普通场景里的异常秩序 |
| 句群偏好 | 短句判断 + 生活物件比喻 + 证据边界回收；先给一句歪理，再立刻压回事实、推断、待证 |
| 禁用表达 | 作者式剧透、生产语汇、宏大煽情、硬喊爽点、角色越权定论、拿受害者痛苦抖包袱、把复杂责任写成单一善恶审判 |

## 四、落笔样句

以下不是必须复用的原句，而是后续章节对齐气味的样句：

1. 直播间说退款在路上，银行流水却像一扇没开过的门。
2. 线索太懂陆行舟时，陆行舟反而应该先怀疑自己。
3. 一张表不会撒谎，但它可以被人放在最会撒谎的位置。
4. 秦墨寒不负责相信怪话，他负责让怪话死在证据里，或者活成证据。
5. 苏晚不怕麻烦，她怕的是麻烦被人包装成流程。

## 五、正文落笔约束

后续正文必须遵守：

- 每个歪理句后面必须有证据接口，不能让歪理直接定罪。
- 每个幽默点必须避开受害者痛点，优先笑逻辑错位、话术遮羞和主角自嘲。
- 每个爽点必须有人为判断负责，不允许“群众倒戈 + 对手震惊 + 主角赢麻了”的廉价胜利。
- 复杂案情必须被生活物件、现场动作或具体文书承载，不能连续堆术语。
- 情绪落点必须具体到一笔钱、一张表、一次误判、一个名字、一段被压住的真相。
- 秦墨寒和苏晚不能变成主角捧哏；他们要持续承担证据和程序的校正功能。
- 章末钩子必须来自新证据、新误判、新压力或责任边界变化，不用作者式预告。

## 六、章节审查新增模板

后续章节评估必须加入“作者性格一致性审查”：

| 检查项 | 合格标准 | 风险信号 |
|--------|----------|----------|
| 叙述态度 | 克制、清醒，不替角色提前审判 | 旁白急着告诉读者谁对谁错 |
| 幽默刀口 | 笑话术、逻辑和方法，不笑受害者 | 用受害者痛苦换轻松感 |
| 证据洁癖 | 歪理只做入口，结论靠证据闭环 | 陆行舟一句话压过秦墨寒和苏晚 |
| 普通人同情 | 具体损失被看见，情绪债不被爽点抹平 | 破案后自动原谅、自动和解 |
| 句群气味 | 有生活比喻、功能道具和证据边界 | 通顺但像通用刑侦说明 |
| 责任分层 | 罪责、过失、隐瞒、程序问题分开写 | 所有压力都推给一个坏人解决 |

结论规则：

- 全部通过：可进入常规质量评分。
- 轻微偏离：最多“有条件通过”，需列出偏离句和修正方向。
- 严重偏离：先回本文件校准作者性格，再重写相关段落。

## 七、风格漂移风险

| 风险 | 等级 | 处理方式 |
|------|------|----------|
| 技术案变成说明书 | 中 | 每段技术信息必须绑定人物动作、证据道具或受害者现实损失 |
| 轻喜过界稀释受害者痛感 | 中 | 幽默只给主角自嘲、话术荒唐和逻辑错位，不落到受害者身上 |
| 主角被写成无证据神探 | 高 | 每次异常判断必须被秦墨寒/苏晚压回待证栏 |
| 过度冷峻失去网文可读性 | 中 | 保留陆行舟生活比喻和轻微自嘲，但不破坏案件重量 |
| 章节卡功能压过正文沉浸 | 中 | 正文中禁止出现生产语汇，所有功能目标必须转为场景冲突 |

## 八、适用范围

本作者性格声明适用于：

- 第 34 章及后续正文写作。
- 第 33 章及后续章节评估。
- 后续五章段整体复评、终稿审美统一和问题修复。
- 发布文案的语气校准：可以强调反套路、歪理、证据翻盘，但不能把作品包装成主角开挂秒破一切。
