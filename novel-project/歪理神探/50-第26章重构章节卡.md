## 五、核心决策

最优决策：第 26 章不破案，只启动“真不可能”谜题，并让秦墨寒主导证据地基。

核心依据：

- 第 25 章信息密度较高，第 26 章必须换气，先靠场景和冲突抓读者。
- C006 的单元爽点规划为“秦墨寒胜一局”，因此开篇不能让陆行舟立刻抢走主导权。
- “监控真实、证人真实、展柜空了”是本案不可能感的根，必须让读者先相信证据没撒谎。
- 第 25 章起执行汉字约 3000、最多不超过 4000 的短章约束，本章只承担开案、换气和证据地基，不承担破案解释。

执行边界：

- 不揭示可溶赝品。
- 不揭示布展负责人梁启主犯身份。
- 不回收证书真实但展出物可假。
- 不让陆行舟强行命中“消失的不是古董”。

## 七、关键场景设计

### 场景一：旧符号暂压

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所证物柜旁，旧账本复印件、收款截图和匿名指令截图并列 |
| 镜头顺序 | 边角符号 -> 陆行舟停笔 -> 周明远来电 -> 展馆失窃 |
| 动作节拍 | 陆行舟想追符号，秦墨寒整理截图，周明远要求先去展馆 |
| 功能道具 | 证物袋承担主线压力 |
| 主导感官 | 证物袋封口声 |

推进卡：

- 人物目标：陆行舟想追旧账本符号。
- 主要阻碍：现实案件突发，不能让主线吞掉单元案。
- 冲突升级：新案公开失窃，舆论压力比 C005 更高。
- 代价后果：陆行舟必须暂时放下“被编号”的不安。
- 局面变化：C006 启动。
- 章末追读：展馆公开失窃为何压过旧账本。

### 场景二：展馆主厅

| 项目 | 内容 |
|------|------|
| 场景空间 | 市文博展馆主厅，玻璃展柜、红色封锁线、媒体镜头和观众人群 |
| 镜头顺序 | 闪光灯 -> 空展柜 -> 馆长苍白的脸 -> 保险代表低声催促 |
| 动作节拍 | 苏晚拉封锁，秦墨寒确认展柜状态，陆行舟观察人群却无入口 |
| 功能道具 | 空展柜承担视觉谜题 |
| 主导感官 | 展馆冷气、玻璃反光、快门声 |

推进卡：

- 人物目标：团队要先确认是否真失窃。
- 主要阻碍：现场太公开，所有人都在看警方如何解释。
- 冲突升级：展品在众目睽睽下消失，比普通盗窃更像不可能犯罪。
- 代价后果：处理不当会毁掉馆方声誉，也会让警方被舆论围攻。
- 局面变化：C006 从视觉冲击启动。
- 章末追读：空展柜里原本放的到底是什么。

### 场景三：秦墨寒接管流程

| 项目 | 内容 |
|------|------|
| 场景空间 | 展柜边缘、报警按钮、保安交接记录台和封锁线外的媒体人群 |
| 镜头顺序 | 秦墨寒戴手套 -> 锁具编号 -> 报警时间 -> 证人站位 -> 保险代表催促 |
| 动作节拍 | 秦墨寒分组复核，苏晚保护现场，陆行舟主动退后，媒体催问被苏晚挡回 |
| 功能道具 | 证据流程单承担秦墨寒主场 |
| 主导感官 | 笔尖划纸声和展厅广播残音 |

推进卡：

- 人物目标：秦墨寒要先证明证据地基是否可靠。
- 主要阻碍：所有人都催着解释“怎么消失”，但他必须先确认“什么是真的”。
- 冲突升级：陆行舟短暂无入口，团队主导权切换。
- 代价后果：如果流程没守住，不可能案会变成舆论案。
- 局面变化：秦墨寒取得阶段主导权。
- 章末追读：证据真的可靠吗。

### 场景四：监控室慢放

| 项目 | 内容 |
|------|------|
| 场景空间 | 展馆监控室，六块屏幕、时间轴、保安和值班记录 |
| 镜头顺序 | 展品在柜中 -> 人群经过 -> 灯光闪动 -> 柜中变空 -> 秦墨寒要求重放原始文件 |
| 动作节拍 | 秦墨寒要求原始文件，苏晚核拷贝程序，陆行舟盯画面沉默，章末落到“证据真实但结果不可能” |
| 功能道具 | 原始监控文件承担不可能感 |
| 主导感官 | 监控风扇声和鼠标点击声 |

推进卡：

- 人物目标：团队要确认监控是否被改。
- 主要阻碍：初看画面没有剪辑、遮挡或替换痕迹。
- 冲突升级：证据越真，案件越不可能。
- 代价后果：陆行舟不能靠异常感插嘴，秦墨寒必须顶住压力。
- 局面变化：监控真实性初步成立。
- 章末追读：如果监控没撒谎，展品怎么没了。
