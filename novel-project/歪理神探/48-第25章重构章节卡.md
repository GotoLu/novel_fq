## 四、核心决策

最优决策：第 25 章必须用“主动否定饭点”完成 C005，而不是用饭点规律抓人。

核心依据：

- C005 的成长爽点是“陆行舟不再迷恋漂亮歪理”，必须让他亲手否定自己最顺手的判断。
- 周强诱饵只有在真犯路径闭合后才有价值，不能只靠一句“不是他”洗掉。
- 真规律必须由苏晚和秦墨寒共同固定，体现团队互补：陆行舟翻面，秦墨寒建模，苏晚保程序。
- 本章是五章案收束章，需要同时完成证据闭环、抓捕、周强责任边界和主线钩子，但正文仍遵守单章汉字约 3000、最多不超过 4000 的连载节奏约束。

执行边界：

- 卢俊必须通过快递代收、取件时间、门禁/电梯空档和现场物证闭合，不能靠口供定案。
- 周强必须有可疑行为和收款记录，但缺乏入室收益链。
- 本章结案 C005 表层案，但只推进幕后投喂，不摊牌顾闻策/样本库主线。

## 六、详细场景设计

### 场景一：不吃饭的房间

| 项目 | 内容 |
|------|------|
| 场景空间 | 六号楼 303 独居者房间，餐桌、灶台、冰箱、快递短信同场 |
| 镜头顺序 | 冷茶 -> 空灶台 -> 外卖券 -> 手机取件短信 -> 陆行舟擦掉“饭点” |
| 动作节拍 | 苏晚复核现场，秦墨寒核时间，陆行舟要求把 303 单独列出 |
| 功能道具 | 半杯冷茶和取件短信承担“非饭点”反转 |
| 主导感官 | 冷茶味、空厨房和外卖塑料袋声 |

推进卡：

- 人物目标：陆行舟要找出六号楼 303 为什么被盗。
- 主要阻碍：案发仍在饭点窗口，旧解释很顺手。
- 冲突升级：主动否定饭点等于承认前一晚设伏方向错。
- 代价后果：陆行舟放弃一次“我早说饭点有问题”的公开打脸。
- 局面变化：六号楼 303 从例外变成新中心。
- 章末追读：如果不是饭点，犯人靠什么知道房间空了。

### 场景二：三条线重合

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所复盘室，饭点时间轴、取件记录、电梯维保表和周强工具包同场 |
| 镜头顺序 | 原饭点表 -> 取件短信 -> 电梯维保表 -> 周强收款截图 -> 三条线重合 |
| 动作节拍 | 秦墨寒重算样本，苏晚调取合法来源，陆行舟要求删掉“吃饭”标签并重新问周强 |
| 功能道具 | 三色白板线和工具包承担模型翻面与诱饵落地 |
| 主导感官 | 白板擦声和打印机吐纸声 |

推进卡：

- 人物目标：团队要找到比饭点更窄的作案窗口，并确定周强在链条中的真实位置。
- 主要阻碍：饭点规律太漂亮，周强又因前科隐瞒收钱送包。
- 冲突升级：秦墨寒必须承认模型输入被污染，周强也必须承认自己不是无辜旁观者。
- 代价后果：团队前一晚设伏被进一步否定，周强的旧前科再次伤害他的可信度。
- 局面变化：真正空档指向快递代收和电梯维保，周强从主嫌降为被利用的诱饵。
- 章末追读：谁同时知道快递取件和电梯维保。

### 场景三：快递站反查

| 项目 | 内容 |
|------|------|
| 场景空间 | 快递站后台、货架、监控死角、卢俊工作台 |
| 镜头顺序 | 取件码墙 -> 后台代收记录 -> 卢俊手上胶带痕 -> 货架底部空位 |
| 动作节拍 | 苏晚调后台，秦墨寒核时间，陆行舟看卢俊处理包裹顺序 |
| 功能道具 | 取件码后台承担真规律；胶带和货架底部承担现场物证 |
| 主导感官 | 胶带撕扯声、纸箱灰尘味 |

推进卡：

- 人物目标：团队要证明卢俊能知道住户离家空档。
- 主要阻碍：快递站每天几百件，数据噪音大。
- 冲突升级：卢俊说自己只代收快递，行为看似合理。
- 代价后果：若证据不闭合，卢俊会把所有异常解释成工作流程。
- 局面变化：卢俊进入直接执行链。
- 章末追读：卢俊何时入室，赃物在哪里。

### 场景四：电梯空档抓捕

| 项目 | 内容 |
|------|------|
| 场景空间 | 电梯机房、楼道、快递站后门、临时暂存柜和派出所证物柜快速切换 |
| 镜头顺序 | 电梯维保停靠 -> 卢俊离岗 -> 暂存柜开门 -> 赃物入袋 -> 旧账本边角符号 |
| 动作节拍 | 苏晚布控取证，秦墨寒核时间，陆行舟守错位动线，卢俊取赃被截，归档时发现符号 |
| 功能道具 | 电梯维保表、暂存柜钥匙和旧账本边角符号承担闭环与主线尾钩 |
| 主导感官 | 电梯机房低频震动、暂存柜金属声和证物袋封口声 |

推进卡：

- 人物目标：团队要拿到卢俊转移赃物的行为链，并归档 C005 表层证据。
- 主要阻碍：卢俊知道快递站和楼栋监控死角。
- 冲突升级：抓捕必须合法且不能污染赃物链。
- 代价后果：陆行舟不能靠歪理喊人，只能等证据落地；表层案结了，却确认自己仍被观察。
- 局面变化：C005 阶段结案，第二卷主线压力升级。
- 章末追读：边角符号代表什么，幕后者如何记录他的判断。
