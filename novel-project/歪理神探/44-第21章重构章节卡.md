## 四、核心决策

最优决策：第 21 章不写旧版“竞争正式开始”，而写成“旧账本复印件与饭点入室案同时出现”。

核心依据：

- 42 已确定第二卷卷级问题是“当异常被人为制造，陆行舟还能不能相信自己”。
- 43 已将 C005 定为“被投喂异常”的入口，必须从第一章就让饭点规律带有被摆出来的嫌疑。
- 旧版“握手言战/计分竞争”会削弱第 20 章尾钩的寒意，也会让第二卷重复第一卷的对手压制爽点。

执行边界：

- 竞争关系只能作为人物压力低频存在，不做本章主轴。
- 旧账本只露一页复印件、观察编号和标题格式，不解释顾闻策。
- 饭点规律必须先作为“看似好用的方向”出现，不能在第 21 章就定性为幕后投喂。

## 六、详细场景设计

### 场景一：附件不是账本

| 项目 | 内容 |
|------|------|
| 场景空间 | 夜晚派出所办公室，屏幕光、值班灯和未收拾的 C004 白板并存 |
| 镜头顺序 | 邮件文件名 -> 秦墨寒手停在鼠标上 -> 苏晚要求固定证据 -> 陆行舟看见“旧账本”三个字 |
| 动作节拍 | 秦墨寒截屏，苏晚封存邮件，周明远从办公室出来，陆行舟没有碰鼠标 |
| 功能道具 | 未打开的附件承担威胁；C004 白板承担第一卷余温 |
| 主导感官 | 冷光和夜风，突出“刚结案就被盯上”的寒意 |

推进卡：

- 人物目标：陆行舟想立刻知道对方寄来的是什么。
- 主要阻碍：苏晚坚持先固定邮件来源，不能破坏证据。
- 冲突升级：附件标题直接使用“样本观察补记”，说明对方不是偶然围观。
- 代价后果：陆行舟必须压住好奇，承认自己也是证据对象。
- 局面变化：第 20 章尾钩从神秘邮件变成程序化证物。
- 章末追读：附件里到底记录了谁的判断。

### 场景二：复印件的第一行

| 项目 | 内容 |
|------|------|
| 场景空间 | 小会议室，打印机、证物袋、旧白板和周明远的沉默形成压迫 |
| 镜头顺序 | 打印件吐出 -> 标题第一行 -> 观察编号 -> 周明远脸色变化 |
| 动作节拍 | 苏晚装袋，秦墨寒念标题，陆行舟抄下编号，周明远把手从纸边移开 |
| 功能道具 | 复印件边角符号承担长线伏笔，打印纸的热度承担“刚被送来”的临场感 |
| 主导感官 | 纸张热气和打印机噪音，形成冷案被重新打印出来的感觉 |

推进卡：

- 人物目标：秦墨寒想把复印件纳入证据流程，陆行舟想知道旧账本和自己有什么关系。
- 主要阻碍：周明远下意识想把旧账本压住，只说“先不要扩散”。
- 冲突升级：复印件不是泛泛威胁，而是模仿第一案记录格式。
- 代价后果：周明远的遮掩第一次让团队感觉到旧案不是普通历史包袱。
- 局面变化：旧账本成为第二卷主线入口。
- 章末追读：谁知道第一案记录格式。

### 场景三：连环入室案打断

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所接警大厅，夜班电话、群众焦急和会议室冷静形成对撞 |
| 镜头顺序 | 电话铃响 -> 钱凤英带人进门 -> 财物清单 -> 三个案发时间被贴上白板 |
| 动作节拍 | 苏晚接警，秦墨寒分派固定现场，陆行舟把旧账本纸袋推到一边 |
| 功能道具 | 辖区地图承担案件入口；饭盒、外卖小票、厨房灯承担饭点生活痕迹 |
| 主导感官 | 食物余味和夜班电话声，形成“饭点”记忆点 |

推进卡：

- 人物目标：团队必须处理现实报案，不能沉在旧账本里。
- 主要阻碍：三起入室案损失不算惊天，但节奏密集、群众恐慌上升。
- 冲突升级：旧账本制造心理压力，新案制造现实压力，双线并行。
- 代价后果：陆行舟没时间消化被观察感，就要重新判断案件。
- 局面变化：C005 启动。
- 章末追读：三起入室案是否真的有关联。

### 场景四：地图上的红圈

| 项目 | 内容 |
|------|------|
| 场景空间 | 会议室白板前，辖区地图、案发时间轴、受害者作息表同桌并列 |
| 镜头顺序 | 三个红圈 -> 三个饭点时间 -> 受害者作息 -> 陆行舟停在“太顺”两个字 |
| 动作节拍 | 秦墨寒拉时间轴，苏晚核报案笔录，陆行舟在地图上画红圈后又擦掉半个 |
| 功能道具 | 红色白板笔承担误导与自我克制；地图红圈承担“被画好”的视觉意象 |
| 主导感官 | 白板笔摩擦声，突出规律被人为画出来的感觉 |

推进卡：

- 人物目标：陆行舟想找到入室案的第一规律，证明自己没有被旧账本影响。
- 主要阻碍：秦墨寒指出饭点规律过宽，不能成为指认依据。
- 冲突升级：饭点规律越顺，越像旧账本寄件人希望他看见的东西。
- 代价后果：陆行舟不能立刻说出漂亮结论，必须把爽点往后压。
- 局面变化：饭点从直觉结论降级为待证方向。
- 章末追读：饭点规律是自然形成，还是被人摆出来。

### 场景五：不是结论

| 项目 | 内容 |
|------|------|
| 场景空间 | 深夜会议室收尾，白板上同时留着旧账本编号和饭点时间轴 |
| 镜头顺序 | 陆行舟三栏笔记 -> “饭点”写入待证 -> 复印件边角符号 -> 第四起报案提示 |
| 动作节拍 | 陆行舟写下“推断，不是事实”，苏晚补程序清单，秦墨寒把复印件和时间轴分开放 |
| 功能道具 | 三栏笔记承担成长回扣；边角符号承担幕后投喂伏笔 |
| 主导感官 | 深夜纸张翻动声，收束为压低但不断的追读感 |

推进卡：

- 人物目标：陆行舟想稳住方法边界，不让旧账本和新案把他拖回旧模式。
- 主要阻碍：饭点规律确实太诱人，且第四起报案预警让时间压力增加。
- 冲突升级：新案像是专门把“红圈”摆到他面前。
- 代价后果：他放弃本章立刻打脸，只换来一个不完整方向。
- 局面变化：第二卷主问题确立：有人可能正在用案件测试他的判断。
- 章末追读：连环入室为何专挑饭点。

| 环节 | 设计 |

| 压抑铺垫 | 刚结案就收到旧账本附件，陆行舟发现自己可能被长期观察 |

## 九、正文写作策略

| 模块 | 要求 |
