## 四、核心决策

最优决策：第 24 章必须让设伏失败，并让新案发生在“他们没有守的另一栋”。

核心依据：

- C005 的主题不是“主角按饭点抓贼”，而是“饭点规律被摆出来测试主角”。
- 第 25 章需要主角主动否定饭点歪理，因此第 24 章必须让旧方法付出代价。
- 失败不能归咎于某人蠢，而要归咎于“显眼规律过于顺手，连证据体系也被带着走”。

执行边界：

- 周强不能被抓现行，也不能出现明确逃跑行为。
- 新案必须发生在同一饭点大窗口，但不符合团队设伏点。
- 本章结尾只提出“谁知道他们会设伏”，不揭示真犯和幕后。

## 六、详细场景设计

### 场景一：设伏方案

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所会议室，周强路线图、饭点时间轴、两户住户保护方案同桌并列 |
| 镜头顺序 | 周强路线 -> 两户固定饭点 -> 苏晚报备单 -> 陆行舟在“诱饵？”旁加问号 |
| 动作节拍 | 秦墨寒定点，苏晚审程序，陆行舟提出风险但同意验证 |
| 功能道具 | 报备单承担合法边界；路线图承担误导 |
| 主导感官 | 白板笔和打印纸声，形成行动前的紧绷 |

推进卡：

- 人物目标：团队要通过设伏抓现行或排除周强。
- 主要阻碍：周强证据不足，只能用验证方式推进。
- 冲突升级：陆行舟怀疑诱饵，但没有足够证据否决设伏。
- 代价后果：一旦设伏失败，团队和饭点判断都会被质疑。
- 局面变化：调查从排查进入行动。
- 章末追读：周强会不会按饭点出现。

### 场景二：楼道埋伏

| 项目 | 内容 |
|------|------|
| 场景空间 | 老小区楼道、监控室、电梯间三点交叉，空间狭窄且居民来往频繁 |
| 镜头顺序 | 住户出门 -> 楼道灯闪 -> 监控画面 -> 陆行舟听见电梯停靠 |
| 动作节拍 | 苏晚安抚住户，秦墨寒盯监控，陆行舟守楼道拐角 |
| 功能道具 | 对讲机承担紧张节奏；楼道灯承担误导 |
| 主导感官 | 楼道回声和电梯提示音 |

推进卡：

- 人物目标：按饭点规律等待入室者出现。
- 主要阻碍：居民日常流动干扰判断，设伏点空间不可控。
- 冲突升级：每个灰夹克、工具包、脚步声都像周强。
- 代价后果：设伏让住户把安全期待押在团队身上。
- 局面变化：读者期待抓现行。
- 章末追读：楼道里出现的人是不是目标。

### 场景三：周强没有出现

| 项目 | 内容 |
|------|------|
| 场景空间 | 监控室和维修店电话连线 |
| 镜头顺序 | 时间过饭点 -> 周强未出现 -> 维修店回传工作照片 -> 秦墨寒沉默 |
| 动作节拍 | 秦墨寒核时间，苏晚核照片来源，陆行舟看路线图 |
| 功能道具 | 工作照片承担排除；路线图承担错误期待 |
| 主导感官 | 对讲机静默和钟表声 |

推进卡：

- 人物目标：确认周强是否按预判进入楼栋。
- 主要阻碍：周强没有出现，且有另一处工作记录。
- 冲突升级：饭点规律没有兑现抓捕预期。
- 代价后果：团队公开行动开始显得尴尬。
- 局面变化：周强嫌疑被动摇，但还未排除。
- 章末追读：如果不是周强，真正入室者在哪。

### 场景四：另一栋新案

| 项目 | 内容 |
|------|------|
| 场景空间 | 另一栋案发现场、设伏楼道、监控室交叉剪切 |
| 镜头顺序 | 对讲机报新案 -> 团队冲到另一栋 -> 受害者打开空抽屉 -> 陆行舟看见饭点仍成立 |
| 动作节拍 | 苏晚保护现场，秦墨寒核案发窗口，陆行舟发现他们守错方向 |
| 功能道具 | 空抽屉承担失败落点；新案门锁记录承担连续性 |
| 主导感官 | 急促脚步声和受害者质问声 |

推进卡：

- 人物目标：确认新案是否与饭点入室案同源。
- 主要阻碍：新案发生在设伏外的另一栋，时间仍在饭点窗口。
- 冲突升级：不是犯人没出现，而是犯人绕过了他们的预判。
- 代价后果：受害者因警方守错点产生不信任。
- 局面变化：团队意识到有人可能知道他们的判断路径。
- 章末追读：谁知道他们守在哪里。

### 场景五：预测了预测

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所复盘室，设伏点、新案点、周强照片和旧账本证物柜形成隐性同框 |
| 镜头顺序 | 两个红圈 -> 周强照片 -> 新案时间 -> 陆行舟写“预测了预测” |
| 动作节拍 | 秦墨寒承认数据路径被带偏，苏晚追知情范围，陆行舟压住自责 |
| 功能道具 | 知情名单承担第 25 章入口；旧账本柜子承担长线阴影 |
| 主导感官 | 白板擦过红圈后的刺耳声 |

推进卡：

- 人物目标：团队要复盘失败原因。
- 主要阻碍：失败可能来自泄密，也可能来自对方预测了他们的判断。
- 冲突升级：饭点规律不只是线索，可能是对方投喂出来的测试题。
- 代价后果：陆行舟和秦墨寒都要承认自己被显眼规律牵走。
- 局面变化：C005 进入反转前夜。
- 章末追读：谁知道他们会设伏。
