## 五、主场景设计

### 场景一：当事人身份确认

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，秦墨寒给出搜索结果 |
| 空间压力 | 视频中女子的身份信息有了——但信息很少，没有前科，没有报案记录 |
| 镜头顺序 | 秦墨寒调出户籍信息 -> "林小满，二十二岁，本地户籍，无前科" -> 职业不详 -> 住址是老地址 |
| 动作节拍 | 秦墨寒确认：这个人不在警方的关注名单上，就是一个普通市民 |
| 功能道具 | 户籍信息、身份证照片 |
| 主导感官 | 键盘敲击声 |
| 推进作用 | 从"视频中的施暴者"还原为"一个有名字的人"——林小满 |

### 场景二：接触林小满

| 项目 | 内容 |
|------|------|
| 场景空间 | 林小满租住的出租屋——老小区的单间 |
| 空间压力 | 门只开了一条缝，链子还挂着。女孩的眼睛是肿的——不是哭的，是很多天没睡的肿 |
| 镜头顺序 | 苏晚敲门 -> 门缝开了 -> "我叫苏晚，是派出所的" -> 女孩沉默 -> 门关上了 -> 过了三十秒，门锁响了一声，门开了 |
| 动作节拍 | 苏晚和陆行舟进门。房间里很乱——外卖盒、泡面、揉成团的草稿纸。女孩坐在床边，不说话。电视上放着新闻，没声音 |
| 功能道具 | 出租屋环境、外卖盒、草稿纸、电视静音画面 |
| 主导感官 | 房间里的沉默、电视的无声画面 |
| 推进作用 | 当事人出现——但她的状态和视频里的"打人者"完全不同 |

### 场景三：沉默的当事人

| 项目 | 内容 |
|------|------|
| 场景空间 | 林小满的出租屋，三人坐下 |
| 空间压力 | 苏晚告诉林小满她有沉默的权利，但需要她配合还原事实；林小满不说话 |
| 镜头顺序 | 苏晚:"我可以告诉你一句话——你有权不开口。但如果你开口了，我保证记录你说的一切。" -> 女孩抬头看了一眼苏晚 -> 然后摇头 -> "我没打人" -> 又沉默了 |
| 动作节拍 | 苏晚让林小满看那段视频。女孩看到一半就转过头去了。她说"不是我打的"——几乎是低吼——然后不再开口 |
| 功能道具 | 手机上的视频画面 |
| 主导感官 | 女孩的声音、房间里的安静 |
| 推进作用 | 当事人拒绝配合，但给出了最关键的信息——"不是我打的" |

### 场景四：苏晚vs平台

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所，苏晚接到平台客服电话 |
| 空间压力 | 平台接到投诉要求删除原始视频，苏晚需要决定是否配合 |
| 镜头顺序 | 平台客服:"有人投诉侵犯肖像权，要求删除原始上传文件" -> 苏晚:"视频是证据，不能删" -> 客服:"可是投诉方提供了身份证明" -> 苏晚:"视频涉及刑事调查，根据《网络安全法》，平台不得主动删除涉案内容" |
| 动作节拍 | 苏晚用法律规定顶住了平台压力，但平台的上一级服务器日志已经自动清理了部分数据 |
| 功能道具 | 电话、法律条文 |
| 主导感官 | 电话里的客服声音、苏晚的冷静应答 |
| 推进作用 | 追查遇阻——原始素材被删了 |

### 场景五：周明远的补入

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所茶水间，周明远倒茶，陆行舟在旁边 |
| 空间压力 | 周明远刚从C012余波中走出来，听到陆行舟说起林小满的事 |
| 镜头顺序 | 周明远:"那女孩不说话？" -> 陆行舟:"不说。就说了一句'不是我打的'，然后闭嘴了。" -> 周明远沉默了很久 -> "我懂。我当年也说了'不是我签的'，然后就闭嘴了。" |
| 动作节拍 | 周明远用自己的经历理解林小满——"不是所有人都有能力在被审判的时候为自己辩护。" |
| 功能道具 | 茶杯、热水壶 |
| 主导感官 | 倒茶声、周明远的低沉声音 |
| 推进作用 | C012→C013情绪接力——周明远从"太合理"的经验中提供同理心视角 |

## 八、歪理命中点

| 歪理 | 表层荒唐 | 命中异常 | 证据转化 | 代价 |
|------|----------|----------|----------|------|
| "热搜不会道歉，但人可以。" | 把道歉的主体从"舆论"换成了"人" | 舆论永远不会承认自己错了，但当事人是人——她需要一个说话的机会 | 苏晚保护林小满的沉默权 | 林小满的沉默不是认罪，是恐惧 |

候选歪理句：

1. "热搜不会道歉，但人可以。"
2. "一百万人说她有罪，但她只有一个人——这不公平。"
3. "沉默不是默认，沉默也可能是被压住了。"
