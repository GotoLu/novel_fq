全警局都知道，陆行舟破案不靠逻辑。

他说音响不是丢了，是被人塞回家里等它自己唱出来。结果音响后盖一开，滚出一盒被盗珠宝。

所有人都以为他又要歪打正着，直到他把一个无辜店员当成嫌疑人，差点耽误对方母亲的治疗款。

从那天起，陆行舟必须学会一件事：歪理只能指路，不能判人。

证据至上的精英侦探秦墨寒看不起他，程序严谨的苏晚时时拦住他，真正的凶手却一次次输在他那些荒唐到可笑的判断里。

## 五、正文复制规则

| 场景 | 处理 |
|------|------|
| 平台自动生成章节标题 | 删除正文首行 H1，只保留正文内容 |
| 平台不自动生成章节标题 | 可保留正文首行 H1 |
| 平台提示重复标题 | 优先确认是否正文 H1 与后台标题重复显示，不先改章名 |
| 平台提示字数异常 | 第 20 章约 3045 字，偏短但不属空章；不建议为凑字数加戏 |
| 平台提示敏感词 | 按 `38-第一卷平台格式与敏感表达预检.md` 第六节局部替换 |

最优执行方式：后台标题字段录入“第N章 标题”，正文框内删除 Markdown 标题行。

核心依据：这能避免前台重复显示“第N章 标题”，同时保留本地文件的三位编号排序优势。

## 六、首发节奏

推荐首日发布：第 1-10 章。

最低首日发布：第 1-5 章。

不建议首日只发 1-3 章。

决策依据：

- 第 1 章提供强异常和珠宝开箱。
- 第 3 章提供误判代价，但尚未兑现翻盘爽点。
- 第 5 章完成第一案闭环，是最低可接受发布单元。
- 第 10 章完成第二案阶段闭环，更能展示连续单元案能力。
