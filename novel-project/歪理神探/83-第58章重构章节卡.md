| 上章欠债 | 本章兑现 |

## 三、目标闭环

| 字段 | 内容 |
|------|------|
| 本章目标 | 追查七天时间线内的异常，确认取样钢管的来源 |
| 主要阻碍 | 七天内的现场已经被清理；鉴定机构的记录不完整；当事人态度不一 |
| 冲突升级 | 从"证据组合可疑"推进到"证据本身可能被替换"——如果取样的钢管不是事故现场的，那么鉴定意见书的基础就不成立 |
| 代价后果 | 如果鉴定意见书基础不成立，整个2019年工伤赔偿案的责任认定就需要重新评估 |
| 局面变化 | 从"太合理"推进到"证据可能被替换"——这是质的飞跃 |
| 章末钩子 | 第七天取样的钢管不是事故现场的，是城东仓库里一批从未出租过的钢管 |

## 五、主场景设计

### 场景一：苏晚的当事人联系进展——有人配合，有人拒绝

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，苏晚打电话，其他人听 |
| 空间压力 | 七年过去了，当事人态度各异 |
| 镜头顺序 | 第一个电话（保安）-> 第二个电话（单位联系人）-> 第三个电话（鉴定机构对接人） |
| 动作节拍 | 保安愿意配合但记不清了；单位联系人说"都七年了找不到了"；鉴定机构对接人说"记录不全，得去查档案" |
| 功能道具 | 电话、当事人名单、笔记 |
| 主导感官 | 电话铃声、沉默、对方的语气 |
| 推进作用 | 建立当事人联系网络，同时确认追查难度 |

### 场景二：秦墨寒核实鉴定机构记录

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所档案室/鉴定机构电话 |
| 空间压力 | 鉴定意见书的取样记录不完整——缺少取样过程的详细记录 |
| 镜头顺序 | 秦墨寒翻鉴定意见书 -> 发现取样记录缺失 -> 打电话给鉴定机构 -> 对方回复 |
| 动作节拍 | 秦墨寒发现鉴定意见书只有结论，没有取样过程的详细记录。他打电话给鉴定机构，对方说"七年前的档案需要调取"。 |
| 功能道具 | 鉴定意见书、电话 |
| 主导感官 | 翻纸声、电话电流声 |
| 推进作用 | 确认鉴定意见书的技术缺陷——没有取样过程记录 |

### 场景三：陆行舟的七天追查——谁动了脚手架？

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，陆行舟在白板上画七天时间线 |
| 空间压力 | 七天内的现场已经被清理，但时间线可以重建 |
| 镜头顺序 | 第一天事故 -> 第二天到第六天 -> 第七天取样 |
| 动作节拍 | 陆行舟画时间线：第1天赵某坠落，第2-6天现场被清理/脚手架被拆走，第7天城东仓库取样。"中间这五天——脚手架去哪了？" |
| 功能道具 | 白板、笔、七天时间线 |
| 主导感官 | 白板笔写字声 |
| 推进作用 | 将抽象的"七天"具象化为可追查的时间线 |

### 场景四：周明远的回忆——七天内的具体经历

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，周明远听着陆行舟的时间线，开始回忆 |
| 空间压力 | 周明远记得第七天去过城东仓库——但他当时以为那是正常的 |
| 镜头顺序 | 陆行舟画时间线 -> 周明远回忆 -> "第七天我去城东仓库取了钢管样本" -> 解释 |
| 动作节拍 | 周明远说第七天他跟着鉴定机构的人去了城东仓库。他记得仓库很大，钢管很多。他指了一根说"就是这根"。但他没问这根钢管从哪来的。 |
| 功能道具 | 白板上的时间线 |
| 主导感官 | 沉默、周明远的低语 |

## 十、原创性风险边界

| 风险点 | 处理 |
|--------|------|
| "七天时间线"可能太抽象 | 用白板可视化，具体到每一天发生了什么 |
| 当事人联系可能太顺利 | 有人配合，有人拒绝，有人记不清 |
| 鉴定机构记录缺失是常见桥段 | 重点不在"记录缺失"，在"第七天周明远去了仓库但没问来源" |

风险结论：低风险，可继续。
