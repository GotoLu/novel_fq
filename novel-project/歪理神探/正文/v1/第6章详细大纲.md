## 📝 详细情节设计

### 场景一：庆功宴（600字）

**时间**：破案后第二天晚上
**地点**：幸福派出所会议室
**人物**：陆行舟、苏晚、周明远、钱凤英、其他同事

**场景功能**：延续爽感，展示陆行舟的变化

**具体情节**：

1. **庆功宴开场**（150字）：
   - 周明远为陆行舟举办小型庆功宴
   - 桌上摆着简单的菜和饮料
   - 同事们的态度明显转变，从质疑到佩服

2. **钱凤英的激动**（150字）：
   - 钱凤英激动地说："小陆，我就知道你能行！"
   - 钱凤英："之前是我动摇了，对不起啊！"
   - 陆行舟："没关系，钱阿姨，我理解。"

3. **苏晚的认可与质疑**（150字）：
   - 苏晚："这次你确实做得不错。"
   - 苏晚："但我还是觉得你的推理方法有问题。"
   - 陆行舟："我知道，我会改进的。"
   - 苏晚："你能这么想，说明你真的在成长。"

4. **陆行舟的思考**（150字）：
   - 陆行舟内心独白：为什么这次能成功？
   - "因为我用了证据，不是只靠直觉。"
   - "但我的推理方向一开始还是错了..."
   - "如果一开始就找对方向，就不会浪费那么多时间。"

**幽默点**：
- 钱凤英的激动（前后态度反差）
- 苏晚的"认可但质疑"（傲娇式认可）

**钩子设计**：
- 情绪钩子：爽感延续
- 成长钩子：陆行舟开始反思

---

### 场景二：秦墨寒的反击（800字）⭐核心场景

**时间**：庆功宴中途
**地点**：幸福派出所会议室
**人物**：陆行舟、秦墨寒、周明远、苏晚

**场景功能**：确立竞争关系，制造冲突

**具体情节**：

1. **秦墨寒的到来**（200字）：
   - 门被推开，秦墨寒走进来
   - 表情平静，看不出情绪
   - 陆行舟有些紧张：他来干什么？
   - 周明远："秦侦探，你也来了。"

2. **秦墨寒的祝贺**（150字）：
   - 秦墨寒走到陆行舟面前
   - "恭喜你破案。"
   - 语气平静，没有嘲讽
   - 陆行舟："谢谢。"

3. **秦墨寒的反击**（250字）：
   - 秦墨寒："但我不会认输的。"
   - 秦墨寒："我提议，我们来一场正式的竞争。"
   - 周明远："什么竞争？"
   - 秦墨寒："下一个案件，看谁先破案。"
   - 秦墨寒："输的人，要公开承认对方的方法更有效。"
   - 苏晚："这..."
   - 周明远看向陆行舟："陆行舟，你怎么看？"

4. **陆行舟的回应**（200字）：
   - 陆行舟犹豫：这风险太大了
   - 如果输了，就要公开承认歪理不如精密推理
   - 但苏晚低声说："你不是说你会改进吗？这是检验的机会。"
   - 陆行舟深吸一口气，点头："好，我接受挑战。"
   - 秦墨寒嘴角微扬："那就这么说定了。"

**幽默点**：
- 秦墨寒的平静（和之前的震惊形成对比）
- 陆行舟的犹豫（想接受又怕输）
- 苏晚的激将法（低声说话）

**钩子设计**：
- 冲突钩子：竞争确立
- 悬念钩子：谁能赢？

### 场景三：新案件引入（800字）

**时间**：第三天上午
**地点**：幸福派出所前台
**人物**：陆行舟、苏晚、周明远、报案人林太太

**场景功能**：引入新案件，设置悬念

**具体情节**：

1. **报案人到来**（200字）：
   - 一个穿着讲究的中年妇女冲进派出所
   - 眼眶红肿，显然刚哭过
   - "警察同志，我的传家宝不见了！"
   - 周明远："别急，慢慢说。"

2. **案件详情**（300字）：
   - 林太太："那是我们林家传了三代的玉佩，价值连城！"
   - 林太太："我把它放在卧室的保险柜里，昨晚还在，今早就不见了！"
   - 周明远："卧室门窗呢？"
   - 林太太："门被撬开了，保险柜也被打开了..."
   - 林太太："但奇怪的是，我有三个嫌疑人，他们都有完美的不在场证明！"
   - 陆行舟眼睛一亮："不在场证明？"
   - 秦墨寒也来了："完美的不在场证明？有意思。"

3. **三个嫌疑人**（200字）：
   - 林太太："我侄子林小伟，昨天下午来过，但晚上在朋友家聚会，有监控证明。"
   - 林太太："邻居老王，昨天在家看电视，有小区监控证明。"
   - 林太太："还有古董商赵老板，昨天在店里，有店员证明。"
   - 林太太："他们三个，都有不在场证明，怎么可能是凶手？"

4. **竞争气氛**（100字）：
   - 陆行舟："不在场证明？有意思！"
   - 秦墨寒："不在场证明，考验的是精密的时间线分析。"
   - 两人对视，竞争气氛浓厚
   - 苏晚叹气："又来了..."

**幽默点**：
- 林太太的激动（富太太的夸张表现）
- 陆行舟和秦墨寒的对视（竞争火花）
- 苏晚的叹气（无奈）

**钩子设计**：
- 悬念钩子：不在场证明如何破解？
- 竞争钩子：谁能先破案？

### 场景四：现场调查（800字）

**时间**：第三天下午
**地点**：林太太家（别墅）
**人物**：陆行舟、苏晚、秦墨寒、林太太

**场景功能**：展示两人不同的调查方式

**具体情节**：

1. **现场勘查**（200字）：
   - 林太太家是栋二层别墅
   - 卧室在二楼，门锁被撬开
   - 保险柜在衣柜里，被打开
   - 玉佩不见了
   - 陆行舟观察现场整体布局

2. **秦墨寒的调查**（200字）：
   - 秦墨寒拿出工具箱
   - 仔细检查门锁的撬痕
   - 测量撬痕的深度、角度
   - 拍照记录每一个细节
   - 秦墨寒："这是专业的撬锁手法，撬痕很干净。"

3. **陆行舟的调查**（250字）：
   - 陆行舟没有检查门锁
   - 而是观察卧室的整体布局
   - 他走到窗前，拉开窗帘
   - 注意到窗外有一棵大树
   - 树的位置正对卧室窗户
   - 树枝延伸到窗边，距离很近
   - 陆行舟："这棵树..."
   - 林太太："这棵树？这棵树有什么问题？"
   - 陆行舟："树干很粗，可以承重。"

4. **两人的分歧**（150字）：
   - 秦墨寒："这是典型的入室盗窃，需要精密的时间线分析。"
   - 秦墨寒："当务之急是验证三个嫌疑人的不在场证明。"
   - 陆行舟："我觉得，问题可能不在时间线..."
   - 秦墨寒冷笑："又是你的歪理？"
   - 陆行舟："不是歪理，是直觉。"
   - 秦墨寒："直觉？那不是证据。"

**幽默点**：
- 秦墨寒的精密检查（工具箱、测量）
- 陆行舟的奇怪观察（盯着树看）
- 两人的分歧（逻辑vs直觉）

**钩子设计**：
- 悬念钩子：大树有什么问题？
- 冲突钩子：推理方式冲突
