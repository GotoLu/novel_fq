## 📝 详细场景设计

### 场景一：接案（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 竞争正式开始，两人同时接案 |
| **情绪曲线** | 严肃→紧张 |
| **出场人物** | 陆行舟、秦墨寒、周明远、苏晚 |
| **场景时长** | 约15分钟（故事时间） |

#### 详细情节

**开头设计（承接第21章）**：
```
时间：第二天上午
地点：幸福派出所，周明远办公室
氛围：严肃紧张，分局施压
```

**情节展开**：

1. **周明远分配案件**（200字）
   - 周明远召集陆行舟和秦墨寒到办公室
   - 桌上摊开9起连环入室盗窃案的卷宗
   - "分局要求一周内破案，压力很大。"周明远说
   - "你们两个，从今天开始，各用各的方法调查这9起案件"

2. **竞争规则重申**（200字）
   - 秦墨寒："独立调查，互不干扰，发现关键线索必须共享。"
   - 陆行舟点头："明白。"
   - 周明远："每天下午5点，你们到我这里汇报进展。"
   - 苏晚在旁边记录，心里想：竞争正式开始了

3. **接案确认**（200字）
   - 两人分别在案件分配表上签字
   - 秦墨寒拿走数据分析需要的卷宗复印件
   - 陆行舟拿走现场走访需要的资料
   - 两人对视一眼，没有说话，但眼神里都有战意

#### 对话设计

**核心对话**：
```
周明远："分局要求一周内破案，压力很大。你们两个，从今天开始，各用各的方法调查这9起案件。"
秦墨寒："独立调查，互不干扰，发现关键线索必须共享。"
陆行舟："明白。"
周明远："每天下午5点，你们到我这里汇报进展。"
```

**苏晚内心**：
```
竞争正式开始了。
两种方法，谁能先找到突破口？
我期待着，也担忧着。
```

#### 环境描写

```
周明远的办公室里，卷宗摊了一桌，9起案件的资料堆成小山。
窗外阳光明媚，但办公室里的气氛却很凝重。
墙上挂着幸福派出所的辖区地图，9起案件的地点被红圈标出，散落各处。
```

### 场景二：分头调查（800字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 展示两种调查方法的具体操作 |
| **情绪曲线** | 紧张→专注 |
| **出场人物** | 陆行舟、秦墨寒（分头行动） |
| **场景时长** | 约3小时（故事时间） |

#### 详细情节

1. **秦墨寒的数据分析**（400字）
   - 秦墨寒回到工位，打开笔记本电脑
   - 建立9起案件的数据表格：作案时间、地点、被盗物品、受害者信息
   - **作案时间分析**：下午2:30、晚上7:00、晚上9:15、中午12:45...看起来很分散
   - **地点分析**：幸福小区3栋、6栋、12栋、幸福花园5栋...分布在整个辖区
   - **被盗物品分析**：现金、金首饰、笔记本电脑、平板...无规律
   - 秦墨寒皱眉：数据太分散，暂时找不到规律

2. **陆行舟的现场走访**（400字）
   - 陆行舟带着笔记本，开始走访受害者
   - **第1起案件受害者**：一对年轻夫妻，"我们下午2点半出门买菜，回来发现被盗"
   - **第2起案件受害者**：一位退休老人，"我晚上7点出门散步，回来发现家里被翻过"
   - **第3起案件受害者**：一家三口，"我们中午12点多出去吃饭，回来就..."
   - 陆行舟一边记录，一边观察：每个受害者家都有人在某个时间段外出
   - 他问每个受害者："你们外出的时候，是固定时间吗？"
   - 大部分人说"差不多"，但说不清具体规律

#### 对话设计

**秦墨寒自言自语**：
```
"作案时间：下午2:30、晚上7:00、晚上9:15、中午12:45..."
"分散，太分散了。"
"地点：幸福小区3栋、6栋、12栋...分布在整个辖区，无聚集特征。"
"被盗物品：现金、金首饰、电子产品...无规律。"
"数据量还不够，需要更多案件才能找出规律。"
```

**陆行舟走访对话**：
```
陆行舟："你们外出的时候，是固定时间吗？"
受害者A："差不多吧，下午两点半左右出门买菜。"
受害者B："晚上7点散步，差不多那个时间。"
受害者C："中午12点多出去吃饭，差不多每天都是那个点。"
陆行舟："差不多...差不多..."
```

#### 环境描写

**秦墨寒视角**：
```
电脑屏幕上，Excel表格密密麻麻，每个单元格都是一条数据。
秦墨寒用不同颜色标注作案时间、地点、物品，试图找出规律。
但数据像一盘散沙，暂时聚不起来。
```

**陆行舟视角**：
```
幸福小区的楼道里，陆行舟一家家敲门，询问受害者。
笔记本上记满了"差不多""大概""应该"这类模糊的词。
但他注意到一个细节：每个受害者都说"差不多那个时间外出"。
差不多...是什么意思？
```

### 场景三：各自进展（1000字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 两人都有发现，但都不是关键突破 |
| **情绪曲线** | 专注→困惑→期待 |
| **出场人物** | 陆行舟、秦墨寒 |
| **场景时长** | 约2小时（故事时间） |

#### 详细情节

1. **秦墨寒的发现**（500字）
   - 继续分析数据，秦墨寒发现一个现象
   - 作案时间虽然分散，但集中在两个时段：**下午2-6点**和**晚上8-11点**
   - "下午时段5起，晚上时段4起，没有凌晨或早上的案件。"
   - 秦墨寒在笔记本上写下结论：**嫌疑人选择白天和傍晚作案，避开深夜和清晨**
   - 但这能说明什么？大部分入室盗窃都是白天作案，因为家里没人
   - 这个发现太普通了，不是关键线索
   - 秦墨寒皱眉：数据分析还需要更多维度

2. **陆行舟的发现**（500字）
   - 走访完6起案件的受害者，陆行舟发现一个规律
   - **每个受害者家都有人在饭点外出**
   - "下午2点半买菜"——接近午饭时间
   - "晚上7点散步"——接近晚饭时间
   - "中午12点多吃饭"——午饭时间
   - 陆行舟在笔记本上写下：**所有案件都发生在饭点前后**
   - 但这能说明什么？饭点外出是很多人的习惯
   - 这个发现太笼统了，不是关键线索
   - 陆行舟挠头：需要更精确的数据

#### 对话设计

**秦墨寒思考**：
```
"下午2-6点，5起案件。晚上8-11点，4起案件。"
"没有凌晨或早上的案件。"
"嫌疑人选择白天和傍晚作案。"
"但这是常识，大部分入室盗窃都是白天作案。"
"这个发现...太普通了。"
```

**陆行舟思考**：
```
"下午2点半买菜——午饭时间。"
"晚上7点散步——晚饭时间。"
"中午12点多吃饭——午饭时间。"
"所有案件都发生在饭点前后。"
"但饭点外出是很多人的习惯，这能说明什么？"
"需要更精确的数据..."
```

#### 环境描写

```
派出所里，秦墨寒和陆行舟各占一边，各自忙碌。
秦墨寒的电脑屏幕上，数据图表不断变化，他在尝试不同的分析角度。
陆行舟的笔记本上，歪歪扭扭的字迹记录着走访收获，他在寻找模糊中的规律。
两人偶尔抬头对视，又迅速移开目光，各自继续。
```

### 场景四：第一次交锋（600字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 汇报进展，互相试探，暗流涌动 |
| **情绪曲线** | 期待→紧张→悬念 |
| **出场人物** | 陆行舟、秦墨寒、周明远、苏晚 |
| **场景时长** | 约20分钟（故事时间） |

#### 详细情节

1. **下午5点汇报**（200字）
   - 周明远办公室，两人按时汇报
   - 秦墨寒先说："作案时间集中在下午2-6点和晚上8-11点，嫌疑人避开深夜和清晨。"
   - 周明远点头："这个发现有用吗？"
   - 秦墨寒："暂时只是常识性结论，还需要更多分析。"

2. **陆行舟汇报**（200字）
   - 陆行舟："我发现所有受害者家都有人在饭点外出。"
   - 周明远："饭点？"
   - 陆行舟："对，午饭或晚饭时间前后，受害者外出，家中无人。"
   - 周明远："这个发现有用吗？"
   - 陆行舟："暂时只是模糊规律，还需要更精确的数据。"

3. **互相试探**（200字）
   - 秦墨寒看向陆行舟："饭点外出...你有具体数据吗？"
   - 陆行舟："走访了6起案件，都是这样。你呢？时间段分析有更细的吗？"
   - 秦墨寒："暂时只有这两个时段，还需要更多案件验证。"
   - 两人对视，都在试探对方是否找到关键线索，但都没有明说
   - 苏晚在旁边观察，心想：第一次交锋，平局

#### 对话设计

**汇报对话**：
```
秦墨寒："作案时间集中在下午2-6点和晚上8-11点。"
周明远："这个发现有用吗？"
秦墨寒："暂时只是常识性结论。"

陆行舟："所有受害者家都有人在饭点外出。"
周明远："饭点？"
陆行舟："午饭或晚饭时间前后，受害者外出。"
周明远："这个发现有用吗？"
陆行舟："暂时只是模糊规律。"
```

**互相试探**：
```
秦墨寒："饭点外出...你有具体数据吗？"
陆行舟："走访了6起案件，都是这样。你呢？"
秦墨寒："暂时只有这两个时段。"
```

**苏晚内心**：
```
第一次交锋，平局。
两人都有发现，但都不是关键突破。
接下来，看谁能先找到真正的规律。
```

## 📝 写作策略

### 开头策略

**承接第21章**：
- 第21章末尾：竞争第一案开启，9起案件，谁能破局？
- 第22章开头：第二天上午，周明远分配案件，竞争正式开始
- 用"接案"场景承接，体现从"竞争确立"到"竞争开始"的过渡

### 中间策略

**场景二重点**：
- 秦墨寒的数据分析要写得专业、系统，让读者感受到逻辑推理的力量
- 陆行舟的现场走访要写得生动、接地气，让读者感受到直觉推理的温度
- 两种方法形成鲜明对比

**场景三重点**：
- 两人都有发现，但都不是关键突破
