## 📝 详细场景设计

### 场景一：歪理突破（1000字）⭐核心场景

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 陆行舟歪理推理，突破僵局 |
| **情绪曲线** | 困境→思考→突破→兴奋 |
| **出场人物** | 陆行舟、秦墨寒、周明远 |
| **场景时长** | 约30分钟（故事时间） |

#### 详细情节

**开头设计（承接第17章）**：
```
时间：上午9点
地点：赵先生别墅客厅
氛围：两人分头查安达信息，气氛紧张
状态：秦墨寒查安达科技背景，陆行舟查安达家政注册
```

**情节展开**：

1. **秦墨寒查安达科技**（200字）
   - 秦墨寒用笔记本查安达科技官网
   - 安达科技：监控设备制造商，成立于5年前
   - 主营业务：家用监控系统、智能安防
   - 服务范围：本市及周边城市

2. **陆行舟查安达家政**（200字）
   - 陆行舟用手机查安达家政注册信息
   - 安达家政：家政服务公司，成立于1年前
   - 注册资本：50万
   - 股东信息：安达科技控股80%

3. **关键发现**（200字）
   - 陆行舟："安达科技控股安达家政！"
   - 秦墨寒："两家公司是一家人？"
   - 陆行舟："那小张……不，张伟，他不是园丁！"
   - 陆行舟："他是安达科技的人！"

4. **歪理推理**（400字）⭐高潮点
   - 陆行舟开始推理：
     - 监控凌晨3点维护，维护期间暂停录制
     - 张伟是安达科技技术员，能控制监控
     - 张伟提前录了一段"无人"的画面
     - 在维护时替换播放，监控显示假画面
     - 实际有人进入，拿走花瓶
   - 秦墨寒质疑："监控说谎？不可能。"
   - 陆行舟坚持："监控设备有维护商，维护商能控制监控。"

#### 对话设计

**陆行舟歪理推理**：
```
陆行舟盯着监控屏幕，脑子飞速运转。

"监控凌晨3点维护，维护期间暂停录制……"
"张伟是安达科技的人，他能控制监控……"

突然，一个念头闪过脑海。

"我知道了！"

秦墨寒和周明远同时看向他。

"花瓶没有消失。"陆行舟一字一顿，"是监控说谎了。"

秦墨寒皱眉："监控说谎？不可能。监控设备是最新的，没有故障。"

"我不是说设备故障。"陆行舟说，"我是说，监控显示的画面，是假的。"

周明远不解："假的？"

"监控设备有维护商，维护商能控制监控。"陆行舟语速加快，"张伟是安达科技的技术员，他负责这个区域的监控维护。"

"他提前录了一段'无人'的画面，在凌晨3点维护时替换播放。"

"所以监控显示的，是假画面。实际上，有人进入了！"

秦墨寒愣住："这……"

陆行舟继续："张伟辞职前频繁进客厅，不是修剪盆栽，是在踩点！他问过监控设备的情况，是在确认维护时间！"

"昨天他辞职离开，实际上是作案后逃跑！"

客厅里，一片寂静。
```

**秦墨寒质疑**：
```
秦墨寒沉默了一会儿："你的推理……有逻辑漏洞。"

陆行舟："什么漏洞？"

秦墨寒："就算监控显示假画面，那报警器呢？报警器未触发，说明无人闯入。"

陆行舟："报警器也是安达科技的产品，张伟能控制。"

秦墨寒："门禁呢？门禁显示只有主人进出。"

陆行舟："张伟有安达科技的工牌，能复制门禁卡。"

秦墨寒皱眉："这些都是推测，没有证据。"

陆行舟："那就验证一下。"
```

#### 环境描写

```
客厅里，阳光透过落地窗洒进来，照亮了每一个角落。
陆行舟站在监控屏幕前，目光炯炯，语速飞快。
秦墨寒靠在沙发上，眉头紧锁，显然在思考陆行舟的推理。
周明远站在一旁，神情凝重，但眼中闪过一丝希望。
```

#### 人物心理

**陆行舟心理**：
```
监控说谎了。
张伟是安达科技的人，他能控制监控。
他提前录了假画面，在维护时替换播放。
这就是为什么监控显示无人进入，但花瓶消失了。

我的歪理，是对的！
```

**秦墨寒心理**：
```
监控说谎……这个角度，我确实没想到。
但推理需要证据。
如果陆行舟是对的，那张伟就是真凶。
我需要验证。
```

### 场景二：验证推理（800字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 秦墨寒验证陆行舟的推理 |
| **情绪曲线** | 质疑→验证→震惊→认可 |
| **出场人物** | 陆行舟、秦墨寒、周明远 |
| **场景时长** | 约20分钟（故事时间） |

#### 详细情节

**情节展开**：

1. **查询张伟身份**（200字）
   - 秦墨寒用笔记本查询安达科技员工信息
   - 输入：张伟，28岁
   - 结果：张伟，安达科技技术员，入职1年
   - 职责：负责城北别墅区监控维护

2. **查询安达科技与安达家政关系**（200字）
   - 秦墨寒查询两家公司的股权关系
   - 安达科技控股安达家政80%
   - 张伟通过安达家政进入赵先生家
   - 目的：踩点，为作案做准备

3. **震惊与认可**（200字）
   - 秦墨寒："张伟确实是安达科技的技术员。"
   - 秦墨寒："你的推理……是对的。"
   - 陆行舟笑了："我就说，歪理有用。"
   - 秦墨寒沉默，不得不承认陆行舟的能力

4. **追踪张伟**（200字）
   - 秦墨寒查询张伟的行踪
   - 张伟昨天下午离开本市
   - 消费记录显示在邻市酒店入住
   - 准备实施抓捕

#### 对话设计

**秦墨寒验证**：
```
秦墨寒打开笔记本，登录公安系统。
"我查一下张伟的真实身份。"

键盘敲击声响起，屏幕上显示查询结果。

"张伟，28岁，安达科技技术员，入职1年前。"
"职责：负责城北别墅区监控设备维护。"

秦墨寒抬起头，神情复杂。

"你的推理……是对的。"
```

**陆行舟反应**：
```
陆行舟笑了，嘴角上扬。

"我就说，歪理有用。"

秦墨寒瞥了他一眼："别得意，还没抓到人。"

陆行舟："抓人是你的强项，我负责推理，你负责抓捕。"

秦墨寒沉默了一下，不得不承认："……嗯。"
```

**追踪张伟**：
```
秦墨寒继续操作电脑。

"张伟昨天下午离开本市，消费记录显示他在邻市酒店入住。"

周明远："邻市？哪个酒店？"

秦墨寒："邻市国际酒店，昨天下午入住，现在应该还在。"

周明远："联系邻市警方，协助抓捕。"
```

#### 环境描写

```
客厅里，气氛从紧张变得兴奋。
陆行舟的推理被验证，真相终于浮出水面。
秦墨寒虽然不情愿，但不得不承认陆行舟的能力。
周明远拿起电话，准备联系邻市警方。

歪理有用。

这种感觉……很爽。

### 场景三：锁定真凶（700字）

#### 场景定位
| 项目 | 内容 |
|------|------|
| **场景功能** | 确认张伟是真凶，准备抓捕 |
| **情绪曲线** | 紧张→期待→准备 |
| **出场人物** | 陆行舟、秦墨寒、周明远 |
| **场景时长** | 约10分钟（故事时间） |

#### 详细情节

**情节展开**：

1. **作案手法还原**（200字）
   - 陆行舟详细解释作案手法：
     - 张伟通过安达家政进入赵先生家，伪装成园丁
     - 辞职前频繁进客厅踩点，确认花瓶位置
     - 提前录制"无人"画面
     - 凌晨3点维护时替换播放，监控显示假画面
     - 实际进入别墅，拿走花瓶
     - 辞职离开，逃避追查

2. **确认赃物位置**（200字）
   - 秦墨寒查询张伟的消费记录
   - 张伟在邻市国际酒店入住
   - 房间号：808
   - 赃物应该在酒店房间

3. **联系邻市警方**（200字）
   - 周明远联系邻市警方
   - 请求协助抓捕张伟
   - 邻市警方同意配合
   - 准备实施抓捕

4. **等待抓捕结果**（100字）
   - 周明远挂断电话
   - "邻市警方已经出发，很快就有结果。"
   - 众人等待

#### 对话设计

**作案手法还原**：
```
陆行舟站起身，走到白板前，开始画图。

"张伟的作案手法是这样的："

"第一步，通过安达家政进入赵先生家，伪装成园丁。"
"第二步，辞职前频繁进客厅踩点，确认花瓶位置和监控盲区。"
"第三步，提前录制一段'无人'的画面。"
"第四步，凌晨3点维护时，替换播放假画面。"
"第五步，实际进入别墅，拿走花瓶。"
"第六步，辞职离开，逃避追查。"

陆行舟放下笔："这就是为什么监控显示无人进入，但花瓶消失了。"

周明远点头："逻辑清晰。"
```

**联系邻市警方**：
```
周明远拿起电话，拨打邻市警方的号码。

"喂，邻市刑警队吗？我是幸福派出所周明远。"

"我们有个案子，嫌疑人张伟现在在你们辖区，国际酒店808房间。"

"对，涉嫌盗窃，价值两百万。"

"好的，麻烦你们协助抓捕。"

"赃物应该在房间，一起起获。"

"好，等你们消息。"

周明远挂断电话。

"邻市警方已经出发，很快就有结果。"
```

#### 环境描写

```
客厅里，气氛紧张而期待。
陆行舟站在白板前，上面画着作案流程图。
秦墨寒靠在沙发上，目光落在白板上，显然在思考。
周明远站在窗边，等待邻市警方的消息。
```

#### 人物心理

**陆行舟心理**：
```

张伟是真凶。
现在就等抓捕结果了。
```

```
陆行舟的推理很清晰。
