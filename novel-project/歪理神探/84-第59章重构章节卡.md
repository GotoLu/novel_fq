## 五、主场景设计

### 场景一：秦墨寒的逻辑推导——不是事故现场的

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，秦墨寒在白板上画逻辑链 |
| 空间压力 | 所有人都已经猜到"取样钢管不是事故现场的"，但需要一个逻辑确认 |
| 镜头顺序 | 秦墨寒画逻辑链 -> "如果取样钢管不是事故现场的" -> "那么鉴定意见书的结论就没有意义" |
| 动作节拍 | 秦墨寒用三段论推导：第一步，鉴定意见书结论是"脚手架钢管壁厚不足国标"；第二步，这个结论基于城东仓库取样的钢管；第三步，城东仓库的钢管不是事故现场的；结论：鉴定意见书不能证明事故现场的脚手架有问题 |
| 功能道具 | 白板、逻辑链 |
| 主导感官 | 白板笔写字声、沉默 |
| 推进作用 | 用逻辑推导确认鉴定意见书基础不成立 |
