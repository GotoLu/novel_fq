## 五、主场景设计

### 场景一：复盘室，秦墨寒逐项拆解证据链

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室白板，秦墨寒把旧案证据链一项项列出来 |
| 空间压力 | 每一项单独看都没有问题——挑战在于"组合方式"和"选择逻辑" |
| 镜头顺序 | 现场照片 -> 目击证言 -> 鉴定意见书 -> 勘验笔录 -> 结案报告 |
| 动作节拍 | 秦墨寒逐项确认"这个没问题""这个也合法"，然后停下来——"证据本身没有问题。但有一个地方不对。" |
| 功能道具 | 旧案卷宗、鉴定意见书、白板 |
| 主导感官 | 白板笔写字声、翻纸声 |
| 推进作用 | 确认"证据本身没问题"，同时引出组合方式问题 |

## 十、原创性风险边界

| 风险点 | 处理 |
|--------|------|
| "完美旧案"是常见推理桥段 | 不写"有隐藏证据推翻一切"，而是写"证据本身没问题，问题是取样时间和选择逻辑" |
| 周明远回忆可能变成闪回 | 不闪回，只用对话推进，保持当下感 |
| "取样时间异常"可能太技术性 | 用陆行舟的日常比喻承载——"七天足够让很多东西变得很合理" |
| 联系当事人可能太顺利 | 当事人可能不配合、不在本地或已去世 |

风险结论：低风险，可继续。正文阶段应重点刻画周明远的心理转折和取样时间异常的具体化。
