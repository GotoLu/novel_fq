# 《歪理侦探正着破案》人物压力测试与群像轮转

执行日期：2026-06-04

阶段：全流程重构优先级 2

调用技能链：`idea-generator` 提供高概念承接，`character-designer` 主导人物重构，`plot-architect` 局部反查，`quality-evaluator` 验收 P2/P13，`progress-tracker` 记录状态。

## 一、阶段结论

本阶段选择的最优人物方案是：

> 以陆行舟“急于证明自己不是骗子”为人物发动机，以秦墨寒“证据体系被异常直觉挑战”为对抗压力，以苏晚“程序正义与异常直觉之间的守门选择”为现实边界，以周明远“保护异类与旧案隐情”为长线伏笔，建立四人互相需要、互相伤害、互相校正的核心群像。

核心理由：

- 可行性：保留旧版主角、苏晚、秦墨寒、周明远四个核心人物，不推翻既有资产。
- 效果：每个人都获得自己的欲望、恐惧、错误倾向和代价，不再只是主角功能挂件。
- 风险：修复“主角永远对、配角只震惊”的爽文扁平化风险。
- 一致性：承接 `09-创意重构方案.md` 的“表层歪理，底层异常捕捉，证据链补完”。
- 扩展性：四人关系能自然制造案件推进、程序冲突、竞技压力、旧案主线和卷级反转。

## 二、依据区分

### 2.1 事实依据

- 旧版 `02-人物设计.md` 中，陆行舟仍保留“歪打正着体质”“逻辑扭曲场”“反向直觉系统”等偏金手指表达。
- 旧版苏晚核心功能偏“歪理翻译器”，容易退化为主角外挂解释器。
- 旧版秦墨寒核心功能偏“精密推理验证器”和“被打脸对象”，容易退化为固定爽点工具。
- `09-创意重构方案.md` 已明确陆行舟的新能力不是幸运，而是异常捕捉；直觉只能指出异常，必须回到证据闭环。
- `08-全流程重构计划.md` 要求人物必须通过失去、羞辱、误解、利益冲突和道德两难测试。

### 2.2 合理推断

- 如果陆行舟没有真实误判和代价，读者会把“歪理破案”理解成作者偏袒，而不是人物能力。
- 如果秦墨寒只负责被打脸，他越聪明，世界越显得配合主角；因此他必须有胜利、有反击、有合理的价值观。
- 如果苏晚只负责吐槽，她无法承担“程序正义守门人”功能；因此她必须在关键时刻阻止陆行舟。
- 周明远若只是宽容所长，长线主线会缺乏人物锚点；因此他必须与旧案隐情、陆行舟能力来源或制度压力产生关联。

### 2.3 创作观点

- 本书群像的最佳状态不是“所有人都围着陆行舟转”，而是“所有人都用自己的正确，逼陆行舟承认自己的错误”。
- 陆行舟的魅力不在于永远赢，而在于他每次差点用错误伤人后，还愿意把荒唐直觉磨成能保护人的证据。

## 三、旧人物问题诊断

| 人物 | 旧版功能 | 核心问题 | 重构方向 |
|------|----------|----------|----------|
| 陆行舟 | 歪打正着的喜剧侦探 | 能力太像好运，失败不够痛 | 误判会伤人，成长靠证据化直觉 |
| 苏晚 | 搭档、吐槽、翻译器 | 缺少自己的底线和主动选择 | 程序正义守门人，必要时阻止主角 |
| 秦墨寒 | 精英对手、被打脸对象 | 工具化，缺少胜利和恐惧 | 证据体系代表，既压迫主角也校正主角 |
| 周明远 | 所长、导师、保护伞 | 太安全，缺少隐秘代价 | 保护异类，同时背负旧案隐情 |
| 钱凤英 | 案件来源、粉丝 | 可保留但不宜进入核心群像 | 阶段三作为社区情报资产处理 |

本阶段核心群像限定为陆行舟、秦墨寒、苏晚、周明远。钱凤英暂不升级为主线人物，避免早期群像过散。

## 四、陆行舟重构

### 4.1 人物定位

| 维度 | 新设定 |
|------|--------|
| 表层身份 | 派出所编外协查员，被全警局当成会说怪话的笑料 |
| 核心能力 | 捕捉人性和现场异常，但初期无法正确解释异常 |
| 外在目标 | 成为被正式认可的案件顾问 |
| 内在需求 | 证明自己不是靠运气蒙对，更不是会伤害无辜者的骗子 |
| 核心恐惧 | 下一次歪理误判会毁掉真正无辜的人 |
| 错误倾向 | 被质疑后急于证明自己，先下结论后补证据 |
| 成长终点 | 能把荒唐直觉转化为可验证线索链 |

### 4.2 核心矛盾

陆行舟真正的矛盾不是“逻辑错但结果对”，而是：

> 他总能看见别人忽略的异常，却总急着把异常包装成结论。

这个矛盾必须贯穿每案：

- 异常捕捉让他有价值。
- 急着下结论让他伤人。
- 证据转化让他成长。

### 4.3 压力测试

| 压力类型 | 测试问题 | 人物反应 | 必须付出的代价 |
|----------|----------|----------|----------------|
| 失去 | 如果协查权限被暂停，他还如何证明自己？ | 私下追查，试图找回价值 | 被苏晚警告，关系信任下降 |
| 诱惑 | 如果一个荒唐判断能立刻让他赢过秦墨寒，他会不会先说出口？ | 会，尤其在公开质疑场合 | 误伤嫌疑人或受害者家属 |
| 误解 | 如果异常细节指向无辜者，他会怎样？ | 先被异常吸引，忽略证据不足 | 必须公开道歉，承受羞辱 |
| 羞辱 | 如果秦墨寒当众说他是骗子，他会怎样？ | 用更夸张的歪理反击 | 把案件讨论变成自尊之争 |
| 利益冲突 | 如果证明真相会让自己失去名声，他会不会继续？ | 初期犹豫，中期选择真相 | 失去群众崇拜或短期机会 |
| 道德两难 | 如果程序不允许追查，但直觉提示有人会受害，他怎么办？ | 试图越界行动 | 需要苏晚替他承担程序风险，形成情绪债 |

### 4.4 成长弧

| 阶段 | 章节范围 | 起点状态 | 关键压力 | 阶段变化 |
|------|----------|----------|----------|----------|
| 被嘲期 | 1-5 | 用歪理证明自己 | 第一案误判小王，伤及治疗款危机 | 学会公开道歉，但仍不懂证据化 |
| 试证期 | 6-20 | 开始补证据 | 秦墨寒连续质疑证据链 | 明白直觉只能提供方向 |
| 失灵期 | 21-40 | 过度依赖异常捕捉 | 第二卷遭遇被人为制造的假异常 | 第一次主动否定自己的直觉 |
| 拆解期 | 41-60 | 学会拆分直觉来源 | 旧案压力逼近，周明远隐瞒真相 | 形成“异常清单”和“验证顺序” |
| 成熟期 | 61-100 | 能证据化歪理 | 终极案件同时挑战直觉和证据体系 | 建立可被他人复核的方法 |

### 4.5 保留、删除、增强、禁止破坏项

| 类型 | 内容 |
|------|------|
| 保留 | 一本正经胡说八道、歪理语言、善良热心、被质疑后的喜剧反差 |
| 删除 | “歪打正着体质”“逻辑扭曲场”“结果永远对”的绝对好运 |
| 增强 | 误判代价、公开道歉、证据转化、对受害者情绪的愧疚 |
| 禁止破坏 | 陆行舟不能变成装疯卖傻的硬核天才；他的荒唐必须真荒唐，但命中点必须真实 |

## 五、秦墨寒重构

### 5.1 人物定位

| 维度 | 新设定 |
|------|--------|
| 表层身份 | 海归精英侦探，证据体系的信徒 |
| 外在目标 | 证明现代侦探方法比陆行舟的歪理可靠 |
| 内在需求 | 接受“无法解释的异常”也可能是证据链入口 |
| 核心恐惧 | 自己信奉的严密体系被一个荒唐的人击穿 |
| 错误倾向 | 过度相信可量化证据，忽略人性异常和低概率细节 |
| 成长终点 | 不放弃证据原则，但学会利用陆行舟的异常视角补全盲区 |

### 5.2 深层动机

秦墨寒不是讨厌陆行舟本人，而是讨厌陆行舟代表的“不受训练、不尊重方法、可能伤人却被崇拜”的破案方式。

他的质疑必须合理：

- 他见过错误直觉导致冤案。
- 他相信证据体系是保护无辜者的唯一底线。
- 他认为陆行舟的粉丝化崇拜会鼓励危险模仿。

### 5.3 压力测试

| 压力类型 | 测试问题 | 人物反应 | 必须付出的代价 |
|----------|----------|----------|----------------|
| 失去 | 如果他的证据链被证明漏掉关键异常，他会怎样？ | 表面冷静，私下复盘到失眠 | 专业自尊受损，公开权威下降 |
| 诱惑 | 如果可以用程序漏洞压死陆行舟，他会不会做？ | 不会造假，但会利用规则限制陆行舟 | 被苏晚质疑动机不纯 |
| 误解 | 如果所有证据都指向错误嫌疑人，他会怎样？ | 坚持证据优先，直到异常无法解释 | 错过救援窗口或被主角反超 |
| 羞辱 | 如果陆行舟公开赢过他，他会怎样？ | 不承认歪理，只承认证据结果 | 关系继续恶化，竞争升级 |
| 利益冲突 | 如果承认陆行舟价值会损害自己的名声，他会不会承认？ | 初期不承认，中期承认部分方向 | 精英人设出现裂缝 |
| 道德两难 | 如果证据不足但直觉提示危机，他该不该行动？ | 先拒绝，后设计合法验证路径 | 学会为异常直觉找程序入口 |

### 5.4 成长弧

| 阶段 | 章节范围 | 起点状态 | 关键压力 | 阶段变化 |
|------|----------|----------|----------|----------|
| 否定期 | 1-5 | 公开否定陆行舟 | 第一案被证据链翻盘 | 开始正视异常，但拒绝承认方法 |
| 竞技期 | 6-20 | 以胜负压制主角 | 多次比主角慢半步 | 把陆行舟列为有效变量 |
| 反击期 | 21-40 | 抓主角误判漏洞 | 主角因误判付代价 | 成为必要校正者，不只是对手 |
| 互补期 | 41-60 | 共同遭遇失灵案件 | 证据和直觉同时被操控 | 学会主动请求异常视角 |
| 并肩期 | 61-100 | 保留原则的合作者 | 终极案件需要双体系闭环 | 承认真相需要多种方法互证 |

### 5.5 保留、删除、增强、禁止破坏项

| 类型 | 内容 |
|------|------|
| 保留 | 精英感、证据洁癖、与陆行舟的竞技关系 |
| 删除 | 单纯“这不科学”的固定反应和固定被打脸模式 |
| 增强 | 合理质疑、阶段胜利、反制能力、对冤案的恐惧 |
| 禁止破坏 | 秦墨寒不能为了衬托主角而降智；他输必须输在盲区，不输在低级错误 |

## 六、苏晚重构

### 6.1 人物定位

| 维度 | 新设定 |
|------|--------|
| 表层身份 | 派出所民警，陆行舟的调查搭档 |
| 深层功能 | 程序正义守门人，防止陆行舟用歪理伤人 |
| 外在目标 | 在现实规则内把案子办扎实，不让任何人被舆论或直觉误伤 |
| 内在需求 | 学会在程序与救人之间承担选择，而不是只躲在规则后面 |
| 核心恐惧 | 自己一次“相信他”会变成一次程序事故或冤案 |
| 错误倾向 | 为了稳妥过度压制异常方向，或为了保护陆行舟替他背程序风险 |
| 成长终点 | 既守住程序底线，也能为异常线索找到合法路径 |

### 6.2 与主角的真实张力

苏晚不是陆行舟的翻译器，而是他的刹车。

她对陆行舟的价值不是“让别人听懂歪理”，而是：

- 当陆行舟急于证明自己时，她提醒他还有无辜者。
- 当秦墨寒用程序压死异常线索时，她寻找合法入口。
- 当周明远想保护陆行舟而越线时，她指出制度后果。

### 6.3 压力测试

| 压力类型 | 测试问题 | 人物反应 | 必须付出的代价 |
|----------|----------|----------|----------------|
| 失去 | 如果她因配合陆行舟被处分，她还会不会相信他？ | 不会立刻放弃，但会重设边界 | 与陆行舟关系降温 |
| 诱惑 | 如果相信陆行舟能快速破案但程序不允许，她会怎么办？ | 找合法替代路径，不让他硬闯 | 错过最佳时机的风险 |
| 误解 | 如果她把陆行舟的异常判断当胡闹，导致线索延误？ | 会自责，但不会放弃规则 | 学会区分直觉和证据入口 |
| 羞辱 | 如果外界说她被陆行舟带偏，她会怎样？ | 以案件事实回应，不情绪化辩护 | 承受同事疏离 |
| 利益冲突 | 如果保护陆行舟会伤害自己职业前途？ | 第一卷保护一次，第二卷开始要求他承担后果 | 关系从兜底转为契约 |
| 道德两难 | 如果程序合规但明显会让受害者再次受伤？ | 寻找边界内的主动行动 | 逼她从执行者变成决策者 |

### 6.4 成长弧

| 阶段 | 章节范围 | 起点状态 | 关键压力 | 阶段变化 |
|------|----------|----------|----------|----------|
| 戒备期 | 1-5 | 把陆行舟当风险源 | 第一案误判伤人 | 不再只吐槽，开始设边界 |
| 守门期 | 6-20 | 严格控制陆行舟越界 | 主角多次碰到程序红线 | 学会把异常转为合法调查项 |
| 选择期 | 21-40 | 在程序和救人之间摇摆 | 一次延误造成情绪债 | 形成自己的办案判断 |
| 对抗期 | 41-60 | 敢于同时反驳陆行舟和秦墨寒 | 旧案涉及内部压力 | 从搭档变成共同决策者 |
| 定型期 | 61-100 | 程序与异常的桥梁 | 终极案件需要合法闭环 | 成为团队底线，而非附属角色 |

### 6.5 保留、删除、增强、禁止破坏项

| 类型 | 内容 |
|------|------|
| 保留 | 干练、吐槽、执行力、与陆行舟的搭档喜感 |
| 删除 | 只负责翻译歪理、无条件支持、单纯无语反应 |
| 增强 | 程序底线、职业风险、主动反对、对无辜者的保护 |
| 禁止破坏 | 苏晚不能变成恋爱挂件或主角粉丝；她必须有权说“不” |

## 七、周明远重构

### 7.1 人物定位

| 维度 | 新设定 |
|------|--------|
| 表层身份 | 派出所所长，给陆行舟机会的保护者 |
| 深层功能 | 旧案隐情的保管人，主线伏笔入口 |
| 外在目标 | 保护陆行舟这个异类，让他不被制度过早碾碎 |
| 内在需求 | 面对过去一次错误判断造成的后果 |
| 核心恐惧 | 陆行舟重走自己旧案中的错误道路 |
| 错误倾向 | 以保护为名隐瞒关键信息，替年轻人做选择 |
| 成长终点 | 不再替陆行舟挡掉真相，而是让他承担真相 |

### 7.2 旧案隐情方向

周明远曾参与一桩旧案：当时所有证据都指向一个嫌疑人，但一个“不合逻辑”的异常细节被忽视，导致真正凶手逃脱或无辜者受损。

这个旧案不在阶段二展开案件细节，只确定人物功能：

- 他保护陆行舟，不是因为盲目信任，而是因为他知道“异常细节被忽略”的代价。
- 他害怕陆行舟，也害怕秦墨寒。前者可能无证据伤人，后者可能有证据却看不见人性漏洞。
- 他隐瞒旧案，既是保护团队，也是逃避自己的失败。

### 7.3 压力测试

| 压力类型 | 测试问题 | 人物反应 | 必须付出的代价 |
|----------|----------|----------|----------------|
| 失去 | 如果陆行舟因误判被停职，他还保不保？ | 初期继续保，中期选择让他承担 | 失去陆行舟短期信任 |
| 诱惑 | 如果隐瞒旧案能维持团队稳定，他会不会隐瞒？ | 会，而且会用善意包装 | 旧案反噬，团队关系破裂 |
| 误解 | 如果他把陆行舟当成旧案补偿对象？ | 过度宽容主角错误 | 苏晚质疑他偏袒 |
| 羞辱 | 如果上级翻旧账，他会怎样？ | 先沉默，后承认责任 | 权威受损 |
| 利益冲突 | 如果保护陆行舟会影响派出所和自己前途？ | 会拖延，但不能永远挡 | 组织压力升级 |
| 道德两难 | 如果公开旧案会伤害仍在生活的人？ | 必须选择公开边界 | 推动主线进入沉重区 |

### 7.4 成长弧

| 阶段 | 章节范围 | 起点状态 | 关键压力 | 阶段变化 |
|------|----------|----------|----------|----------|
| 保护期 | 1-20 | 给机会、挡压力 | 陆行舟误判伤人 | 从保护转向立规矩 |
