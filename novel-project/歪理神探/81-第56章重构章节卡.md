## 五、主场景设计

### 场景一：派出所复盘室，周明远拿出旧案卷

| 项目 | 内容 |
|------|------|
| 场景空间 | 派出所复盘室，C011 结案材料还在桌上，周明远从抽屉深处拿出一个档案袋 |
| 空间压力 | 其他人以为周明远在整理 C011 余料，结果他拿出的是一个已经结案的旧案 |
| 镜头顺序 | 档案袋封口 -> 旧案目录 -> 证据清单 -> 结案报告 -> 周明远"我当年漏掉了什么" |
| 动作节拍 | 周明远从档案袋里取出卷宗，放在桌上。沉默两秒。"这个案子，我当年判断错了。" |
| 功能道具 | 旧案卷宗承担全部信息入口 |
| 主导感官 | 档案袋摩擦声、纸张翻动声、周明远的低语 |
| 推进作用 | 用最短篇幅建立旧案存在感 |

### 场景二：旧案证据链复盘——太合理的拼图

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室白板，秦墨寒和周明远一起重排旧案证据链 |
| 空间压力 | 每一项证据单独看都没有问题——但组合在一起形成了一个"所有人都愿意相信"的结论 |
| 镜头顺序 | 物证 -> 证人证言 -> 鉴定意见 -> 勘验笔录 -> 结案报告 |
| 动作节拍 | 秦墨寒逐项确认证据合法性——每一项都合法。周明远说"当年我就是停在了这一步，因为合法就够了"。陆行舟说"太合理了，反而奇怪" |
| 功能道具 | 白板上每一项都打勾——合法、合规、可复核。但整体结论的合理性本身就是一个问题 |
| 主导感官 | 白板笔写字声、翻页声、沉默 |
| 推进作用 | 建立 C012 的核心谜题：证据链本身没有问题，但"为什么所有人都愿意接受这个合理结论" |

### 场景三：陆行舟的直觉异常——太合理的案子

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室外走廊或楼梯间，陆行舟单独消化旧案信息 |
| 空间压力 | 所有人在用专业方法确认"证据链没问题"，只有陆行舟的直觉在报警——因为太完美了 |
| 镜头顺序 | 陆行舟站在走廊 -> 回想旧案关键证据 -> "太合理了"这句话反复出现 -> 他意识到什么 |
| 动作节拍 | 陆行舟回到复盘室，说一句："如果一个案子太合理了，那是不是说明——有人帮他们把合理拼好了？" |
| 功能道具 | 无，纯靠对话和直觉推进 |
| 主导感官 | 走廊回声、脚步回声 |
| 推进作用 | 将周明远的"漏掉了什么"升级为"有人制造了太合理" |

### 场景四：苏晚的程序判断——能否重启？

| 项目 | 内容 |
|------|------|
| 场景空间 | 复盘室，所有人等待苏晚的程序判断 |
| 空间压力 | 旧案结案多年，证据完整，没有程序漏洞——按常规程序不能重启 |
| 镜头顺序 | 苏晚翻阅旧案材料 -> 逐项确认程序合法性 -> 沉默 -> 给出判断 |
| 动作节拍 | 苏晚确认旧案程序完全合法，但引用 C011 的原则——"程序合法不等于结论唯一"。给出启动复核的可能性 |
| 功能道具 | 旧案卷宗、C011 结案协查意见（作为类比参照） |
| 主导感官 | 翻纸声、苏晚低沉的声音、短暂的沉默 |
| 推进作用 | 给团队一个程序出口——虽然困难，但不是不可能 |

## 十、原创性风险边界

| 风险点 | 处理 |
|--------|------|
| "完美旧案"是常见推理桥段 | 不写"有隐藏证据推翻一切"，而是写"证据本身没问题，问题是为什么所有人都愿意接受" |
| 周明远旧案可能变成角色回忆杀 | 不闪回，只用卷宗和对话推进，保持当下感 |
| "太合理就是异常"可能抽象 | 用具体证据链展示"每一项都合法但组合可疑" |
| 重启旧案可能显得儿戏 | 苏晚的程序判断必须有法理依据，不能是"为了推进而推进" |

风险结论：低风险，可继续。正文阶段应重点刻画周明远的心理转折和"太合理"这个抽象概念的具象化。

## 十一、正文写作策略

| 模块 | 要求 |
|------|------|
| 开头 500 字 | 周明远从抽屉深处拿出档案袋——不是 C011 余料，是另一个案子 |
| 场景重心 | 复盘室证据链复盘（60%）、走廊直觉（20%）、苏晚程序判断（20%） |
| 对话刀口 | 周明远："我当年判断错了。"秦墨寒："每一项都合法。"陆行舟："太合理了。"苏晚："合法不够。" |
| 信息密度 | 本章不急于揭秘旧案真相，重点是建立"太合理就是异常"的主题 |
| 幽默边界 | 低频冷幽默——陆行舟可能说"一个案子太合理了，合理到像是拼出来的" |
| 章末句群 | 落在陆行舟的直觉判断——"如果太合理了，那是不是有人帮他们把不合理拼掉了？" |

候选章末句：

> 秦墨寒把最后一份证据放回去。
>
> "每一项都合法。"
>
> "每一份证言都自洽。"
>
> "鉴定意见的时间线没有断点。"
>
> "勘验笔录覆盖了所有现场。"
>

>
> 他看着那叠材料。
>
> "当年我觉得，每一项都没问题，所以整体也没问题。"
>
> "然后呢？"陆行舟说。
>
> "然后——"周明远停了两秒。
>
> "然后我没有再追问。"
>
> "为什么？"
>
> "因为太合理了。"
>
> 陆行舟看着那叠材料。
>
> 太合理了。
>
> 合理到像是——有人帮他们把不合理拼掉了。

## 十二、通过标准

- 必须有周明远主动拿出旧案卷的场景——不是别人来查，是他自己翻出来。
- 必须有秦墨寒确认旧案证据链"每一项都合法"的场景。
- 必须有陆行舟直觉报警的场景——"太合理了"。
- 必须有苏晚对"能否重启"的程序判断。
- 必须有周明远承认"当年判断错了"的心理转折。
- 章末必须落在"太合理就是异常"的主题上。
- 本章不揭秘旧案真相——只是建立问题。
