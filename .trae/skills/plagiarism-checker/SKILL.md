# 原创性风险审查

当用户要求原创性评估、桥段风险审查、旧稿继承检查、改写建议或发布前原创性终审时，使用本技能。

## 工作流程

1. 读取 `CONFIG.md`，确认审查维度、风险等级和输出格式。
2. 涉及职责边界、审查原则或流程解释时，读取 `DESIGN.md`。
3. 审查依据来自人工分型、文本证据和创作决策记录。
4. 按以下类型进行人工分型：
   - 原文重合：句段、对白、叙述顺序是否直接沿用。
   - 近义改写：是否只替换词语，仍保留旧句法和信息顺序。
   - 桥段相似：核心诡计、场景功能、反转方式是否过度接近旧稿或常见作品。
   - 类型惯例：是否属于题材通用元素，是否被误判为风险。
   - 内部旧稿继承：项目内旧资产是否需要保留，保留后是否完成因果、场景和表达重构。
5. 输出结果必须包含：检查范围、风险类型、风险等级、判断依据、保留项、重构项和具体修改建议。

## 约束

- 风险等级是编辑判断，不是量化分数。
- 必须区分必要资产继承和不可接受的照搬。
- 对创作文本给出修改建议时，应保留情节功能，同时改写因果链、场景顺序、动作节拍、信息释放方式和句式结构。
- 若资料不足以判断外部作品风险，只能标注"项目内审查结论"，不得宣称覆盖外部平台审核。
