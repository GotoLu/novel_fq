# 原创性风险审查设计文档

## 一、系统概述

本技能为小说创作流程提供原创性风险审查。它帮助判断创意、设定、桥段、场景、正文和发布材料是否存在项目内旧稿继承过重、桥段撞车或表达复用风险。

## 二、流程定位

```text
生产技能产出
  -> 原创性风险审查
  -> 标注保留项与重构项
  -> 质量评估或问题修复
  -> 进度记录
```

审查结论不替代质量评估，也不替代正式版权或平台审核。它用于创作过程中的风险预警和改写决策。

## 三、审查对象

| 对象 | 重点 |
|------|------|
| 创意和高概念 | 是否只复述旧设定，是否具备新的代价、冲突和读者承诺 |
| 人物设定 | 人物欲望、恐惧、错误倾向是否有独立性 |
| 案件和大纲 | 谜题、误导、反转、证据闭环是否过度沿用旧稿 |
| 章节正文 | 场景顺序、动作节拍、对白目的和叙述表达是否复用 |
| 发布材料 | 书名、简介、标签是否过度贴近已有内部方案或外部常见包装 |

## 四、风险判断方法

1. 先确认必要资产：书名、主角、核心卖点、必须保留的案件物件。
2. 再确认新增差异：因果链、人物代价、证据路径、场景调度、表达风格。
3. 最后判断风险等级：低、中、高、严重。

风险判断必须写出证据，不使用分数替代理由。

## 五、与其他技能的协作

| 技能 | 协作方式 |
|------|----------|
| `idea-generator` | 对高概念、卖点和题材差异做风险审查 |
| `character-designer` | 检查人物是否只继承功能设定 |
| `plot-architect` | 检查桥段、案件、伏笔和反转是否需要重构 |
| `content-writer` | 检查正文是否复用旧场景顺序和表达 |
| `problem-solver` | 将高风险项转成可执行修复任务 |
| `quality-evaluator` | 将原创性风险纳入质量闸门 |
| `progress-tracker` | 记录审查结论、决策依据和后续任务 |

## 六、输出原则

- 先说明检查范围和对比依据。
- 再列风险分型和等级。
- 明确哪些资产允许保留，哪些必须重构。
- 给出可执行建议，不输出量化分数。
- 对外部风险资料不足时，明确说明审查范围有限。
