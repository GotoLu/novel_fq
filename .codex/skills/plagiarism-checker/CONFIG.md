# 原创性风险审查配置

## 一、审查原则

- 本技能只做原创性风险审查，依据人工分型、文本证据和创作决策记录。
- 审查结论以人工证据链为依据：文本片段、桥段功能、信息顺序、场景调度、人物决策和项目旧资产来源。
- 项目内旧稿继承不自动判为失败；关键在于是否完成因果、场景、表达和人物代价的实质重构。
- 没有外部语料或平台数据库时，只能给出项目内风险结论。

## 二、风险等级

| 等级 | 含义 | 处理 |
|------|------|------|
| 低 | 仅保留题材惯例或必要项目资产，表达和因果已明显区分 | 可通过，记录依据 |
| 中 | 保留核心资产较多，但已有新增因果、场景或人物代价 | 有条件通过，进入后续正文时继续重构 |
| 高 | 桥段骨架、信息顺序或表达方式与旧稿接近 | 必须重排场景、重写表达或改造因果 |
| 严重 | 存在大段原文重合、近义搬运或关键桥段照搬 | 不通过，回退到对应生产技能重做 |

## 三、审查维度

| 维度 | 检查问题 |
|------|----------|
| 原文重合 | 是否直接沿用旧句段、对白、叙述节奏或描述顺序 |
| 近义改写 | 是否只替换词语而没有改变信息组织和场景动作 |
| 桥段相似 | 核心诡计、误导、反转和爽点释放是否过度接近旧稿 |
| 类型惯例 | 双侦探、公开打脸、内鬼、诱捕等元素是否属于题材通用资产 |
| 内部继承 | 必须保留的书名、人物、案件物件和主线伏笔是否完成重构说明 |
| 表达新鲜度 | 是否加入新的空间压力、动作节拍、情绪投注和证据呈现 |

## 五、重构建议库

| 风险 | 优先处理 |
|------|----------|
| 桥段骨架接近 | 改变因果链、误导层级、证据闭环或人物代价 |
| 场景顺序接近 | 更换开场位置、空间压力、动作节拍和信息释放顺序 |
| 表达方式接近 | 重写句式、感官焦点、对白目的和叙述视角 |
| 人物功能接近 | 增加新的欲望、错误决策、道德压力或关系交易 |
| 必要资产继承 | 明确保留理由，并记录新增差异点 |

## 六、记录要求

- 重要原创性决策必须写明依据，便于后续追溯。
- “有条件通过”必须列出下一阶段的具体重构任务。
- 不使用量化标签作为验收依据。
