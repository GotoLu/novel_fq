# 查重检查

当用户要求文本对比、相似度检测、原创性评估或调整查重阈值时，使用本技能。

## 工作流程

1. 读取 `CONFIG.md`，确认阈值和运行设置。
2. 涉及架构调整或模块职责解释时，读取 `DESIGN.md`。
3. 优先使用内置 Python 模块进行可复现检查：
   - `similarity.py`：相似度算法。
   - `threshold.py`：阈值计算和判定。
   - `retry.py`：重试行为。
   - `logger.py`：日志支持。
4. 输出结果时必须包含匹配范围、相似度分数、风险等级和具体修改建议。

## 约束

- 相似度分数只能作为证据，不能当作绝对结论。
- 必须区分原文重合、近义改写、桥段相似和类型惯例。
- 对创作文本给出修改建议时，应保留情节功能，同时改写表达、细节顺序和句式结构。
