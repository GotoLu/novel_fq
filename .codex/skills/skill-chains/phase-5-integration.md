# 阶段五：连载、发布与完结

本阶段目标是让长篇持续稳定，并在发布和完结时完成所有承诺。它必须整合全部技能。

## 调用链

`progress-tracker` → `quality-evaluator` → `problem-solver` → 按问题回调生产技能 → `plagiarism-checker` → `market-analyzer` 发布适配 → `progress-tracker` 归档

## 技能分工

| 技能 | 职责 |
|------|------|
| `progress-tracker` | 汇总节点、反馈、版本、资源账本和完稿状态 |
| `quality-evaluator` | 做周期审计、全书终审、版本对比和硬性淘汰检查 |
| `problem-solver` | 分诊残留问题，明确终稿保护项 |
| `market-analyzer` | 校准书名、简介、标签、前三章卖点和发布适配 |
| `idea-generator` | 检查核心承诺是否兑现，必要时强化差异化表达 |
| `character-designer` | 检查人物归宿、群像轮转和关系清算 |
| `plot-architect` | 检查主线偿付、伏笔回收、主题落点和续作空间 |
| `content-writer` | 统一终稿风格，修订关键章节和收束段落 |
| `plagiarism-checker` | 做终稿、简介、关键设定和发布材料原创性检查 |

## 必须交付

- 周期审计报告。
- 读者反馈复盘。
- 长篇资源账本更新。
- 群像轮转状态。
- 发布材料：书名、简介、标签、前三章卖点。
- 全书质量报告。
- 终稿修订清单。
- 完结清单：主线偿付、人物归宿、情绪债、伏笔回收、主题落点、续作空间。
- 原创性终审。
- 项目归档。

## 通过标准

- 读者反馈已被记录、解释并转化为调整动作。
- 连载资源没有断账，伏笔、情绪债、设定消耗和人物资源可追踪。
- 发布材料没有虚假承诺，能准确包装正文卖点。
- 终稿风格统一，不像多本书拼接。
- 完结偿付核心承诺，不把主线债务丢给番外或续作。
- 终审原创性风险可控。

## 回退规则

| 问题 | 回退 |
|------|------|
| 反馈恶化 | `progress-tracker` 触发周期复盘，`problem-solver` 分诊 |
| 资源断账 | `plot-architect` 和 `progress-tracker` 补账 |
| 发布材料不准 | `market-analyzer` 重做发布适配 |
| 完结无力 | `plot-architect` 重查主线偿付和人物归宿 |
| 风格割裂 | `content-writer` 做终稿风格统一 |
| 终稿原创性风险 | `plagiarism-checker` 定位后回调对应生产技能重构 |
