# 阶段三：结构与长篇资产

本阶段目标是建立能跑长篇的骨架。大纲不是剧情列表，而是目标、阻碍、代价、变化、伏笔、资源和回报的调度系统。

## 调用链

`character-designer` → `plot-architect` → `plagiarism-checker` → `quality-evaluator` → `problem-solver` 必要分诊 → `progress-tracker`

## 技能分工

| 技能 | 职责 |
|------|------|
| `character-designer` | 提供人物欲望、弱点、关系压力和群像轮转限制 |
| `plot-architect` | 设计结构、世界观、大纲、伏笔、资源账本、资产库和完结方向 |
| `plagiarism-checker` | 检查世界观、设定、桥段和核心场景原创性风险 |
| `quality-evaluator` | 验收 P1、P5、P6、P8、P10、P11、P14、P16、P19 |
| `problem-solver` | 对结构松散、章节无变化、资源失控做分诊 |
| `progress-tracker` | 记录大纲版本、资源状态、伏笔状态和卷级风险 |

## 必须交付

- 分卷大纲。
- 分章大纲。
- 世界观规则和类型机制。
- 场景调度卡。
- 章节接力卡。
- 爽点链卡。
- 伏笔清单。
- 长篇资源账本。
- 小说资产库。
- 卷级防塌卡。
- 完结与续作设计。
- 原创性检查结论。

## 通过标准

- 每章都有目标、阻碍、代价、变化和下一章接力点。
- 每卷都有主问题、阶段高潮、阶段结算和下一卷发动机。
- 爽点不是孤立奖励，而是铺垫、代价、兑现和回响。
- 资源账本能追踪伏笔、设定、人物、情绪债和奖励。
- 结局方向提前存在，伏笔回收和留白边界清楚。

## 回退规则

| 问题 | 回退 |
|------|------|
| 主线散 | `plot-architect` 重做结构 |
| 章节像流水账 | `plot-architect` 重做章节接力卡 |
| 爽点无效 | `plot-architect` 重做爽点链和情绪债 |
| 设定相似 | `plot-architect` 和 `idea-generator` 重构世界观规则 |
| 长篇资源混乱 | `progress-tracker` 补资源账本，再由 `plot-architect` 修大纲 |
