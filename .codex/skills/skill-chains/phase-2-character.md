# 阶段二：人物与群像

本阶段目标是建立能被情节持续逼出选择的人物体系。人物不是标签堆叠，而是压力、欲望、关系和代价的发动机。

## 调用链

`idea-generator` → `character-designer` → `plot-architect` 局部反查 → `quality-evaluator` → `problem-solver` 必要分诊 → `progress-tracker`

## 技能分工

| 技能 | 职责 |
|------|------|
| `idea-generator` | 提供高概念、核心冲突和人物差异化来源 |
| `character-designer` | 设计主角、反派、配角、关系网络和群像轮转 |
| `plot-architect` | 反查人物是否能支撑主线、分卷冲突和类型机制 |
| `quality-evaluator` | 验收 P2、P13 和人物一致性 |
| `problem-solver` | 对人物扁平、动机弱、关系散做分诊 |
| `progress-tracker` | 记录人物版本、关系变化和后续风险 |

## 必须交付

- 主角档案：欲望、恐惧、弱点、能力、代价、弧光。
- 反派档案：目标、资源、压迫方式、价值观和升级路径。
- 核心配角档案：功能、私线、记忆点、与主角的关系张力。
- 人物压力测试。
- 关系网络。
- 群像轮转表。
- 人物一致性报告。

## 通过标准

- 主角必须有想要的东西，也必须为此付代价。
- 反派不能只是障碍物，必须有主动性和持续压迫。
- 配角不能只负责解释设定或捧主角。
- 人物关系能自然制造冲突、诱惑、背叛、扶持或选择。
- 群像轮转能服务情节推进，不让重要人物长期失踪。

## 回退规则

| 问题 | 回退 |
|------|------|
| 主角无压力 | `character-designer` 重做压力测试 |
| 反派弱 | `character-designer` 提升反派目标、资源和压迫方式 |
| 配角工具化 | `character-designer` 补私线和记忆点 |
| 人物撑不起大纲 | `plot-architect` 反调主线冲突，必要时重设人物关系 |
