# 阶段三点五：作者性格定标

本阶段位于“结构与资产”之后、“正文生产”之前。目标不是给作者贴抽象标签，而是为这本小说建立一个符合题材、平台和正文气质的“落笔人格”，让后续章节的叙述态度、幽默刀口、同情对象、愤怒对象和句群选择保持一致。

## 触发时机

- 新项目：完成市场定位、高概念、人物体系、分卷/分章大纲和小说资产库后，开始正文前必须执行。
- 已有项目：若已存在正文，先抽样读取代表章节，反推作者性格，再用反推结果约束后续章节。
- 改稿/续写项目：若章节被评为“风格漂移”“沉浸感弱”“像说明书/评估摘要”，必须回到本阶段校准。

## 调用链

新项目：

`market-analyzer` 题材与读者校准 → `idea-generator` 高概念气质校准 → `character-designer` 主角观察方式校准 → `plot-architect` 类型节奏校准 → `content-writer` 作者性格声明 → `quality-evaluator` 验收 → `progress-tracker` 记录

已有项目：

`progress-tracker` 定位代表章节 → `quality-evaluator` 反推文本气质 → `content-writer` 形成作者性格声明 → `problem-solver` 标记风格漂移风险 → `progress-tracker` 入库

## 新项目输出：作者性格声明

必须产出一份可被正文直接使用的作者性格声明，建议写入项目资产库或单独文档。

| 字段 | 要求 |
|------|------|
| 作者性格核心 | 3-5 个稳定性格词，必须贴合题材和目标读者，不用泛词堆叠 |
| 叙述态度 | 作者怎么看世界、看主角、看反派、看普通人 |
| 幽默刀口 | 笑什么，不笑什么；笑方法、制度、荒唐逻辑，还是笑受害者 |
| 同情对象 | 章节情绪默认站在哪类人身边 |
| 鄙视对象 | 作者稳定反感的行为、话术或权力姿态 |
| 迷恋对象 | 作者愿意反复描写的物件、秩序、场景或心理动作 |
| 句群偏好 | 常用观察方式、比喻来源、句长节奏、对白锋利度 |
| 禁用表达 | 与作者性格冲突的口吻、词汇、煽情方式、上帝视角提示 |
| 落笔示例 | 3-5 句符合本书气质的样句，用于后续章节对齐 |

## 已有项目反推方法

从已有正文中选择样本：

- 优先选开篇章、最近 3 章、质量评分最高的 2 章、读者反馈最正向的章节。
- 若项目有明显风格漂移，再选 1-2 章问题章节做反例。
- 不用逐章全读；只需抓取开头、关键对抗场景、章末钩子和高辨识句群。

反推维度：

| 维度 | 反推问题 |
|------|----------|
| 观察方式 | 作者习惯从物件、制度漏洞、人情压力、动作细节还是心理独白切入 |
| 道德站位 | 作者天然保护谁，审判谁，对谁保持复杂理解 |
| 幽默来源 | 幽默来自身份错位、语言反差、荒唐比喻、程序严肃性还是现实讽刺 |
| 情绪底色 | 章节底色偏轻喜、冷峻、怜悯、愤怒、克制、热血还是酸涩 |
| 信息处理 | 作者喜欢白板拆解、现场动作、对话逼问、内心推演还是旁白解释 |
| 句群气味 | 标志性比喻、短句节拍、反问方式、判断句形态是什么 |

反推结论不能只写“幽默、犀利、温暖”。必须写成可执行约束，例如：“笑荒唐逻辑，不笑受害者；用生活物件比喻证据链；重大结论必须先被角色压回待证栏。”

## 正文落笔约束

后续每章正文必须检查：

- 叙述是否符合作者性格声明，而不是只符合章节卡功能。
- 人物对白是否像本书作者会写出的对抗，不像通用剧本台词。
- 幽默是否落在作者允许的刀口上，不能破坏受害者情绪和案件重量。
- 情绪是否继承作者的稳定同情对象，不能为爽点牺牲基本道德站位。
- 比喻、观察和章末句群是否保持项目辨识度，不能每章换一种作者。
- 若章节功能需要临时改变气质，必须在评估中说明“偏离原因”和“回归方式”。

## 章节审查新增项

章节评估必须单列“作者性格一致性审查”：

| 检查项 | 合格标准 | 不合格表现 |
|--------|----------|------------|
| 性格一致 | 本章叙述态度、幽默刀口、情绪站位符合作者性格声明 | 章节像换了作者，口吻突变 |
| 题材适配 | 作者性格服务题材风格和平台读者预期 | 轻喜题材写得过度阴冷，严肃题材乱抖机灵 |
| 落笔执行 | 具体句群、对话、比喻和场景注意力能体现作者性格 | 只有声明，正文没有体现 |
| 偏离记录 | 必要偏离有剧情理由，并说明后续回归方式 | 为赶剧情随意变口吻 |

未通过时，章节最多判定为“有条件通过”；若作者性格完全缺失或与题材冲突，必须先回本阶段重定标，再继续正文。

## 通过标准

- 作者性格声明已形成文档或入库资产。
- 新项目能说明该性格为什么适合题材、平台和主角观察方式。
- 已有项目能引用已有章节证据反推性格，而不是凭空重设。
- 正文生产阶段能把作者性格转化为具体句群、幽默边界、情绪站位和禁用表达。
- `progress-tracker` 已记录定标依据、适用范围和后续审查要求。
