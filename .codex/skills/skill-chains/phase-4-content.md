# 阶段四：正文生产

本阶段目标是把设计落成读者愿意继续读的章节。正文不是扩写大纲，而是用场景、动作、冲突、情绪和节奏兑现前期承诺。

## 调用链

`plot-architect` 章节卡 → `character-designer` 人物状态 → `content-writer` → `quality-evaluator` → `problem-solver` 必要分诊 → `plagiarism-checker` → `progress-tracker`

## 技能分工

| 技能 | 职责 |
|------|------|
| `plot-architect` | 提供章节目标、阻碍、代价、变化、伏笔和接力点 |
| `character-designer` | 校准人物当前欲望、情绪、关系和行为边界 |
| `content-writer` | 写开篇、日常章、高潮段落和统一风格正文 |
| `quality-evaluator` | 验收 P0、P5、P6、P7、P8、P9、P15 |
| `problem-solver` | 对不追读、人物失真、场景无力和语言问题分诊 |
| `plagiarism-checker` | 检查正文、对话、场景和表达复用风险 |
| `progress-tracker` | 记录章节状态、问题、修订和下一章接力 |

## 必须交付

- 章节卡。
- 人物当前状态。
- 章节正文。
- 章节质量报告。
- 必要改稿分诊记录。
- 原创性检查结论。
- 下一章接力点。
- 进度记录。

## 通过标准

- 第一屏有钩子，不慢热自辩。
- 单章有目标、阻碍、代价和变化。
- 场景参与冲突，不只是背景。
- 情绪投注明确，读者知道为什么要在乎。
- 爽点有铺垫、有兑现、有回响。
- 章末留下下一章必须打开的理由。
- 风格稳定，句群有作者辨识度。

## 回退规则

| 问题 | 回退 |
|------|------|
| 开头不抓人 | `content-writer` 重写开头钩子 |
| 单章没变化 | `plot-architect` 重做章节卡 |
| 人物不像自己 | `character-designer` 校准人物状态 |
| 场景无力 | `content-writer` 重写场景调度 |
| 文本相似 | `content-writer` 重构表达、场景组织和对话 |
