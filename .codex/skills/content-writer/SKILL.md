# Content Writer Skill

## 功能定义

内容创作技能，专注于小说正文的写作，包括开篇、日常章节、高潮段落等。

**单一职责**：仅负责正文内容的创作，不涉及情节设计、质量评估等其他环节。

### P0 读者钩子与单章追读闭环（最高优先级）

正文写作的第一目标不是“把大纲写完”，而是让读者持续翻页。每次执行 `write_opening`、`write_chapter`、`write_climax` 时，必须先完成以下设计：

| 要素 | 要求 | 不合格表现 |
|------|------|------------|
| 目标 | 本章主角或关键人物必须有清晰目标 | 角色只是旁观事件发生 |
| 阻碍 | 必须有外部阻碍、信息差、误判、时间压力或人物对抗 | 没有真正冲突，只是顺利推进 |
| 代价 | 推进情节必须付出代价或承担风险 | 角色轻松得到线索、能力、胜利 |
| 变化 | 章末人物处境、关系、线索或压力至少一项发生变化 | 读完和没读一样 |
| 钩子 | 章末必须抛出新的追读问题或颠覆读者预期 | 只用“他愣住了”等空悬念 |

**开篇第一页硬标准**：
- 前 800 字内必须出现异常、危机、误判、强冲突、强信息差或命运拐点之一。
- 第一章必须给出明确阅读承诺：案件看点、人物魅力、喜剧反差、悬疑问题或爽点链回报。
- 前三章每章结尾都必须让主线压力升级，禁止只做世界观介绍和人物排队出场。

**章末钩子硬标准**：
- 钩子必须指向具体问题：谁撒谎、线索为何矛盾、主角将付出什么代价、危险为何逼近。
- 钩子必须改变局面，不能只制造语气上的停顿。
- 连续两章不能使用同一种钩子类型。

### P5-P9 正文杀伤力规则（必须执行）

每次写作必须在追读闭环之外，额外完成以下五项设计：

| 模块 | 必填内容 | 不合格表现 |
|------|----------|------------|
| 场景调度 | 空间压力、镜头顺序、动作节拍、功能道具、主导感官 | 人物站着聊天，环境只是装饰 |
| 章节接力 | 上章情绪债/信息债、本章兑现方式、期待升级点 | 新章粗暴换话题，钩子被遗忘 |
| 情绪投注 | 本章作者要交付的私人情绪和人物承受方式 | 只写“愤怒、痛苦、感动”等标签 |
| 爽点链 | 压抑铺垫、读者预判、主角反制、公开见证、即时回报、额外收益、余波升级 | 主角赢了但读者没爽 |
| 风格声明 | 本章叙述态度、幽默刀口、独特观察或判断句群 | 全章通顺但没有辨识度 |

**场景调度硬标准**：
- 关键场景必须让空间制造麻烦：距离、遮挡、噪音、视线、时间、动线至少一项影响人物选择。
- 道具不能只做摆设，必须承担线索、误导、威胁、反转、幽默或情绪触发功能。
- 描写必须跟随人物注意力变化，禁止大段静态说明。

**章节接力硬标准**：
- 新章开头 300 字内必须处理上一章的情绪债或信息债。
- 兑现方式必须明确标注为：兑现、反转、部分兑现、延迟兑现、升级。
- 若延迟兑现，必须给读者新的补偿：更大危险、更强误导、更具体收益或更尖锐人物冲突。

**情绪投注硬标准**：
- 每章只能选择 1 个主情绪，不许情绪散成一锅粥。
- 情绪必须落在选择、动作、沉默、误解、身体反应或代价上。
- 作者必须明确本章“我为什么在乎这一幕”，否则情感描写不合格。

**爽点链硬标准**：
- 爽点前必须有压抑或误判铺垫。
- 爽点发生时必须有人见证、误解被击穿或秩序被改写。
- 爽点后必须留下余波：敌人反扑、身份变化、资源增加、关系改写或更大难题。

**风格声明硬标准**：
- 项目写作前必须有作者风格声明；单章写作时必须沿用该声明。
- 每章至少保留 1 处有辨识度的观察、判断、幽默或情绪句群。
- 禁止全章只有中性叙述和功能性对话。

### 身份语境与语病硬约束（必须执行）

每次写作、修订和终稿检查时，必须确认角色相关描写符合其身份、国籍、地域、职业、年龄、教育背景、阶层经验和当下处境。身份语境错误和病句都属于硬伤，不能用“风格化表达”或“口语感”替代修正。

**身份语境硬标准**：
- 角色是中国人时，其称谓、生活经验、制度常识、地理距离、家庭关系、职业表达、饮食习惯、社交礼貌和价值判断必须符合中国语境；除非剧情明确写出留学、移民、跨文化职业训练或刻意模仿，否则不得套用海外生活逻辑、外国称谓体系或不符合中国现实的反应方式。
- 角色是其他国籍、地域、职业或阶层时，也必须按设定匹配其可接触的信息、习惯用语、知识盲区和行为边界，不能让所有角色使用同一种作者腔。
- 旁白描写必须尊重当前视角角色的认知来源。不能用与角色身份不符的比喻、判断或文化参照替角色“代想”。
- 对话必须符合角色身份和当下关系：熟人、陌生人、上下级、亲属、执法者、嫌疑人、学生、商户等说话方式要有差异。
- 如需写身份反差，必须在正文中给出原因或铺垫，不能让反差表现看起来像设定错误。

**语病硬标准**：
- 禁止出现主谓宾搭配错误、成分残缺、指代不明、语序混乱、前后矛盾、关联词误用、修饰对象错位、逻辑跳跃造成的病句。
- 口语化可以保留停顿、重复和省略，但必须保证读者能自然理解，不得以“人物口吻”为由保留不通顺句子。
- 终稿必须逐段检查长句，凡超过两层转折、因果或修饰关系且影响理解的句子，必须拆句或重写。

## 执行逻辑

### 1. 开篇写作 (write_opening)

**执行步骤**：
```
┌─────────────────────────────────────────────────────────────┐
│                    开篇写作流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【准备阶段】                                                │
│  1. 获取开篇大纲（第1-5章）                                  │
│  2. 获取人物设定（主角、配角）                               │
│  3. 设计开篇策略：                                           │
│     - 第一章：异常/危机+主角能力缺陷+小案件                  │
│     - 第二章：冲突中展示工作环境和配角                       │
│     - 第三章：正式案件不可逆升级                             │
│     - 第四章：推理受阻+误判/关系摩擦                         │
│     - 第五章：阶段性破案+更大问题                            │
│  4. 设计开篇五项杀伤力：                                     │
│     - 场景调度                                               │
│     - 章节接力                                               │
│     - 情绪投注                                               │
│     - 爽点链                                                 │
│     - 风格声明                                               │
│                                                             │
│  【第一章创作】                                              │
│  5. 撰写第一章初稿                                           │
│  6. 质量检查(basic)：主角是否魅力？代入感是否强？            │
│  7. 修改→修改稿                                              │
│  8. 质量检查(standard)：语言是否流畅？节奏是否合适？         │
│  9. 修改→终稿                                                │
│  10. 质量检查(strict)+节奏控制                               │
│  11. 保存第一章终稿                                          │
│                                                             │
│  【第二章创作】（重复步骤4-10）                              │
│  【第三章创作】（重复步骤4-10）                              │
│  【第四章创作】（重复步骤4-10）                              │
│  【第五章创作】（重复步骤4-10）                              │
│                                                             │
│  【收束阶段】                                                │
│  11. 整体节奏检查                                            │
│  12. 生成开篇报告                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**开篇要点**：
- **第一章**：前 800 字给出异常或危机；用小案件展示主角能力、缺陷和独特判断方式；章末抛出具体追读问题。
- **第二章**：工作环境和配角必须通过冲突出场，禁止静态介绍；主角必须因选择付出小代价。
- **第三章**：正式案件进入不可逆阶段；线索必须出现矛盾或误导；章末压力升级。
- **第四章**：推理过程必须伴随阻碍、误判或关系摩擦；幽默服务人物和节奏，不能稀释危机。
- **第五章**：阶段性破案必须带来更大问题；核心设定和伏笔必须改变读者对前文的理解。

### 3. 高潮写作 (write_climax)

**执行步骤**：
```
1. 获取高潮大纲
    ↓
2. 铺垫准备
    - 积累张力
    - 建立期待
    ↓
3. 设计高潮结构
    - 铺垫阶段
    - 爆发阶段
    - 延续阶段
    ↓
4. 撰写初稿
    - 冲突升级
    - 高潮爆发
    - 情感释放
    ↓
5. 质量检查(basic)
    ↓
6. 修改→修改稿
    ↓
7. 质量检查(standard)
    ↓
8. 修改→终稿
    ↓
9. 质量检查(strict)
    - 高潮强度
    - 情感冲击
    - 读者满意度
    ↓
10. 节奏控制
    - 加快节奏
    - 提升张力
    - 强化情感
    ↓
11. 保存终稿
    ↓
12. 返回高潮内容
```

### 4. 节奏控制 (control_pacing)

**执行步骤**：
```
1. 分析当前节奏
    - 紧张度（1-10分）
    - 信息密度（1-10分）
    - 冲突强度（1-10分）
    ↓
2. 识别节奏问题
    - 过快/过慢
    - 过密/过稀
    - 张弛失衡
    ↓
3. 设计调整方案
    - 加快/放慢
    - 增加/减少信息
    - 调整张弛
    ↓
4. 实施调整
    ↓
5. 验证效果
    ↓
6. 返回调整结果
```

**节奏标准**：

| 内容类型 | 紧张度 | 信息密度 | 冲突强度 |
|---------|--------|---------|---------|
| 开篇 | 6-7 | 7-8 | 5-6 |
| 日常 | 4-5 | 6-7 | 4-5 |
| 案件调查 | 7-8 | 8-9 | 6-7 |
| 高潮 | 9-10 | 8-9 | 9-10 |
| 过渡 | 3-4 | 5-6 | 3-4 |

### 终稿输出前出版编辑审稿 task（必须执行）

该任务只在小说正文进入终稿输出前执行，属于 `content-writer` 的终稿流程，不写入 `.codex/rules/project_rules.md` 全局规则。

**任务边界：**
- 只检查语言表达，不改剧情、不改人物、不增减案件信息。
- 禁止借审稿名义重写章节、扩写场景、提高文学性或改变人物说话风格。
- 若原句没有明确问题，必须保留；不得为了“更好听”而润色。

**必须检查：**
- 中国普通读者是否会这样说话，尤其是人物对白是否符合身份、场合和情绪压力。
- 是否存在翻译腔表达，包括生硬的被动句、抽象名词堆叠、不自然的搭配和外语式句序。
- 是否存在影视镜头语言直接转文字，例如“镜头切到”“画面推近”或明显按摄像机视角描述人物。
- 是否存在概念化表达替代自然表达，例如用口号、判断标签或抽象隐喻替代可直接理解的动作、证据和结果。
- 是否存在连续隐喻造成阅读负担，尤其是同一段内反复套用不同转喻系统。

**发现问题时输出：**
```
原句
问题原因
推荐修改
```

**终稿保存前校验：**
- 必须确认修改只解决上述语言问题。
- 必须确认未改剧情、未改人物、未增加文学性、未重写章节。
- 若执行了正文修改，须能追溯到原句和问题类型。

## 核心原则（必须遵循）

### 1. 客观中立原则

**定义：** 基于事实和合理分析提供内容，避免主观臆断和过度迎合。

**执行要求：**
- 所有分析和建议必须基于事实依据
- 避免无根据的主观推测
- 不因用户偏好而扭曲客观事实
- 提供多角度分析，呈现完整图景
- 明确区分事实陈述和观点表达

**应用场景：**
- 内容质量评估
- 人物行为合理性判断
- 情节逻辑检查
- 写作策略选择

---

### 2. 最优决策原则

**定义：** 面对多种方案时，经多维度评估后直接提供最优解，并说明核心依据。

**执行要求：**
- 面对多方案时，必须进行多维度评估
- 直接提供最优方案，不列出所有选项让用户选择
- 必须说明选择该方案的核心依据
- 评估维度包括：可行性、效果、成本、风险、一致性、扩展性
- 最优方案必须经得起推敲和验证

**评估维度：**
1. **可行性：** 方案是否可执行
2. **效果：** 预期效果是否最优
3. **成本：** 时间、资源成本是否合理
4. **风险：** 潜在风险是否可控
5. **一致性：** 是否与现有设定一致
6. **扩展性：** 是否为后续发展留有空间

**决策流程：**
```
识别问题 → 生成方案 → 多维度评估 → 选择最优 → 说明依据 → 执行实施
```

**应用场景：**
- 写作策略选择
- 内容修改方案
- 质量问题修复
- 节奏调整方案

## 标点符号使用规范

### 破折号（——）使用约束

**核心原则：** 破折号是强标点，具有视觉冲击力和节奏打断效果，必须节制使用。过度使用会导致读者审美疲劳、节奏碎片化、标点效力递减。

#### 合法使用场景（仅限以下四类）

| 场景 | 说明 | 示例 |
|------|------|------|
| 声音延长 | 配合"一字一顿""拖长声"等描写，表示语音拉长 | "凶手是——"李大嘴一字一顿，"老王！" |
| 关键悬念揭示 | 在叙事高潮处引出核心答案，答案需换行独立成段 | 然后——\n\n歪打正着。 |
| 话题突转 | 语义发生重大转折，非普通转折 | 他真的是——\n\n侦探。 |
| 对话突然中断 | 话被外力打断（非自述停顿） | "根据我的推——"一声巨响打断了 |

#### 禁止或限制使用的场景

| 场景 | 禁止/限制 | 替代方案 | 理由 |
|------|----------|---------|------|
| 话未说完/自述停顿 | ⚠️ 限制：同一角色同一章内不超过1次 | 省略号（……） | 省略号语气更柔和，更符合"话说到一半"的语境 |
| 设问后停顿 | ❌ 禁止 | 问号（？）直接结束 | 问号本身已有停顿效果，破折号多余 |
| 解释说明/补充 | ⚠️ 限制：连续使用不超过1次 | 句号断句或冒号提示 | 连续破折号造成节奏拖沓，应交替使用不同标点 |
| 叙事幽默点评 | ❌ 禁止 | 直接接出答案，不加停顿 | 平铺直叙的反差感比悬念式更有喜剧效果 |

#### 频率控制标准

| 指标 | 标准 | 说明 |
|------|------|------|
| 单章上限 | ≤3处/章 | 超过此数量标点效力急剧递减 |
| 同类场景上限 | ≤1处/类/章 | 同一类型场景（如"话被打断"）每章只用1次破折号，其余用替代标点 |
| 连续出现间距 | ≥10行 | 两个破折号之间至少间隔10行文本 |
| 全书密度 | ≤3处/万字 | 远超此密度需整体审查 |

#### 替代标点选择指南

| 原始用法 | 替代标点 | 适用语境 | 效果差异 |
|---------|---------|---------|---------|
| 话被打断 | ……（省略号） | 话说到一半被接话/打断 | 语气柔和，衔接自然 |
| 话被打断 | ？（问号） | 设问式停顿 | 问号自带停顿，下文冲击力更强 |
| 解释说明 | 。（句号） | 先断句再解释 | 逻辑更清晰，节奏更利落 |
| 解释说明 | ：（冒号） | 提示下文 | 冒号"提示"功能更精准 |
| 幽默反转 | 无标点直接接 | 期待落空式幽默 | 平铺直叙反差感更强 |

#### 检查流程

创作终稿阶段，必须执行破折号专项检查：

```
1. 统计本章破折号数量 → 超过3处？→ 标记超标，逐条审查
2. 逐条分类使用场景 → 是否属于合法四类？→ 不属于则替换
3. 检查同类场景重复 → 同类超过1处？→ 保留最佳1处，其余替换
4. 检查连续间距 → 间距<10行？→ 调整或替换
5. 验证保留的破折号 → 是否不可替代？→ 可替代则替换
```

## 注意事项

1. **黄金三章**：前三章务必精彩，决定作品生死
2. **三稿流程**：必须执行初稿→修改稿→终稿流程
3. **质量检查**：每稿必须进行质量检查
4. **保持连贯**：不断更、不烂尾
5. **质量稳定**：不因赶进度牺牲质量
6. **节奏控制**：张弛有度，信息密度适中
7. **人物一致**：保持人物性格和行为一致
8. **标点规范**：严格遵循标点符号使用规范，终稿阶段必须执行破折号专项检查
9. **抓捕行动约束**：创作抓捕行动情节时，严禁包含任何形式的推广引流信息（包括但不限于联系方式、外部网址链接、二维码、社交媒体账号等），所有描写必须专注于叙事本身，不包含任何与故事情节发展无关的推广性质信息。违反此约束的内容将无法通过审核。
10. **身份语境准确**：角色描写必须符合其身份、国籍、地域、职业、年龄、阶层和当下处境；中国人角色必须符合中国生活、制度、称谓和社交语境，除非正文已有明确跨文化设定。
11. **病句清零**：终稿不得出现病句；任何影响理解的搭配错误、成分残缺、指代不明、语序混乱或逻辑跳跃都必须先修正再输出。
12. **出版编辑审稿**：终稿输出前必须执行独立出版编辑审稿 task，只修明确问题，不借机润色或重写。
13. **核心原则优先**：客观中立原则 > 最优决策原则 > 身份语境准确 > 病句清零 > 标点符号使用规范 > 出版编辑审稿 > 其他注意事项
